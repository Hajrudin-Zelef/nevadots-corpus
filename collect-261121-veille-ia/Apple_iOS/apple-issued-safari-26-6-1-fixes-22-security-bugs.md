Apple released several minor updates to its operating systems on Monday and has now also released details about Safari 26.6.1. And if you're using a Mac running macOS Sonoma or macOS Sequoia, this is definitely not an update you should skip. Apple in the new version, it fixed 22 security vulnerabilities related to WebKit, on which Safari it costs

updates Safari 26.6.1 was released on August 18th and is intended for macOS Sonoma and macOS Sequoia. Apple As part of it, it fixed a total of 22 different CVEs, several of which could lead to memory corruption when processing specially crafted web content.

## **Some errors could lead to memory corruption**

This is where we need to be more careful. Security issues in WebKit are not just a theoretical issue. WebKit processes the content of web pages, so a maliciously crafted page can pose a real risk to users in the event of an exploitable bug.

Apple Several of the bugs fixed stated that specially crafted web content could cause memory corruption. Others, for example, posed a risk of unexpected termination. Safari or the entire process. In addition, one of the fixed bugs in WebKit History could have led to the leakage of sensitive data when visiting a maliciously crafted page. It is also interesting to see who was involved in finding these issues. The list of security researchers includes nine people: OpenAI Codex Security. This is another example of how artificial intelligence tools are becoming increasingly used in finding security vulnerabilities.

## **The update mainly affects older macOS**

If you are using the latest macOS Tahoe, Safari 26.6.1 does not apply to you as a separate update according to the published information. Apple released it for macOS Sonoma and macOS Sequoia, i.e. older supported versions of the system. Of course, this doesn't mean that users of these systems can ignore the update. Quite the opposite. Safari is one of the applications that has access to the Internet practically all the time, and security flaws in its rendering engine are therefore among those that make sense to fix as soon as possible.

If you have a Mac with Sonoma or Sequoia, you can check for the update in System Preferences → General → Software Update. Safari In the case of these systems, it is updated through system updates.
