# Bluetooth SIG announces High Data Throughput standard

The Bluetooth Special Interest Group (SIG) has officially introduced High Data Throughput (HDT), an optional feature within the Bluetooth Core 7.0 specification. This new standard increases the maximum data rate from 2 Mbps to 7.5 Mbps, nearly a fourfold increase over current Bluetooth LE 2M capabilities.

The increased bandwidth is expected to enable true lossless audio streaming by reducing the need for heavy data compression. Beyond audio, the technology is designed to support high-demand applications including spatial computing, extended reality (XR), augmented reality (AR), virtual reality (VR), and AI-powered wearable devices.

Industry leaders, including representatives from Samsung and Nordic Semiconductor, noted that the update also aims to improve energy efficiency. By transmitting larger volumes of data more quickly, wireless radios can return to low-power states sooner. Qualcomm has already announced that its FastConnect 8800 connectivity system provides hardware support for Bluetooth 7 and HDT capabilities.
