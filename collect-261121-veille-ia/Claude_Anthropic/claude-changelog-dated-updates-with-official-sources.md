FEATURE

Claude Code 2.1.329: Trust Dialogs, MCP Fixes, Memory Improvements

This release adds new trust-dialog and hook warnings, expands /tasks and /mcp with more status detail, and fixes a long list of reliability issues in Claude Code including sign-outs, memory growth, Code Mode, and the VS Code extension.

Claude Code 2.1.328: Auto Mode Expands, Code Mode Gets Faster

This release adds auto mode for Claude Opus 4.6 and Sonnet 4.6 across Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and the Claude apps gateway, alongside dozens of fixes and speed improvements to Code Mode, the terminal interface, Remote Control, and self-hosted runners.

Linked billing launches in beta for Claude API apps

Developers can now let their customers pay for Claude usage in their app through the customer's own Claude organization, using the user-profiles-billing-2026-10-01 beta header.

Claude Code 2.1.327: New Safety Checks, Faster Startup, Broad Bug Fixes

This release adds a confirmation step before `/install-github-app` touches a repo, a way to pass MCP server JSON via stdin to keep tokens off the command line, and a `/status` list of broken configuration files. It also fixes dozens of issues across sessions, hooks, artifacts, MCP servers, and the VS Code extension, plus speeds up startup on Windows.

Claude Opus and Sonnet/Haiku 4.5/4.6 outputs now carry a text watermark

Text generated by Claude Opus 4.6, Opus 4.5, Sonnet 4.5, and Haiku 4.5 now carries Anthropic's text watermark on supported platforms, unless the request changes temperature, top_p, or top_k from their defaults.

Claude Code 2.1.326: Code Mode + agent teams, tighter sandboxing, live Remote Control

This release lets Code Mode run alongside agent teams, tightens Bash and PowerShell permission checks and sandbox protections, streams Remote Control replies live to your phone or browser, and fixes a large number of terminal, MCP, and session-reliability bugs.

Claude Code 2.1.325: Security Fix Plus Wide Reliability Cleanup

This release fixes a security issue in how zstd-compressed responses are decoded and makes dozens of reliability, permission, and sandbox fixes across git, MCP, VS Code, Windows, and Linux.

You can now run the entire Managed Agents service on your own infrastructure, storing agents, sessions, and session history there, with model requests still routed to your chosen provider (Anthropic by default).

Claude Code 2.1.323: Code Mode and plugin safeguards

Claude Code 2.1.323 adds an experimental opt-in Code Mode where Claude writes JavaScript to call its tools, plus new plugin version checks, a usage-credit options menu, and a long list of fixes across permissions, MCP, Remote Control, and the web app.

Anthropic launched Claude Fable 5.2 for demanding reasoning and long-horizon agentic work, with Claude Mythos 5.2 offering the same capabilities to verified organizations. Both have a 1M token context window, 128k max output tokens, always-on adaptive thinking, and lower per-token pricing than the 5.1 models.

Claude Fable 5.2 launches with 1M context and lower pricing

Claude Fable 5.2 (and the verification-gated Claude Mythos 5.2) brings a 1M token context window, 128k max output, and always-on adaptive thinking, at $8/$40 per MTok—cheaper than Fable 5.1. A new fast mode offers up to 2.5x higher output speed at a premium price.

Claude Code 2.1.321: Fable 5.2 becomes default, remote-control settings file

Claude Code 2.1.321 adds Claude Fable 5.2 as the new default Fable model (1M context, $8/$40 per Mtok, $0.20/Mtok cache reads) and a `--settings <file>` option for `claude remote-control`, alongside a large batch of bug fixes and smaller improvements.

The advisor tool now supports a `max_tokens` parameter to limit how much output the advisor model generates per call, cutting latency and token cost for workloads that don't need full-length responses.

SDKs add support for code_execution_20260120 tool version

The Python, TypeScript, Go, Java, Ruby, PHP, and C# SDKs now support the code_execution_20260120 version of the code execution tool, which adds REPL state persistence and is required for programmatic tool calling. No beta header is needed to use it.

Anthropic has retired the claude-sonnet-4-20250514 and claude-opus-4-20250514 models; API requests to them now return errors. Anthropic recommends upgrading to Claude Sonnet 4.6 and Claude Opus 4.8 respectively.

Code execution tool version 20260521 discloses 90-sec cell limit

The code execution tool now supports `code_execution_20260521`, which states the 90-second per-cell execution time limit directly in the tool description so Claude can plan long-running cells accordingly. No beta header is required.

Claude Opus 4.1 deprecation announced, retires August 5, 2026

Anthropic announced that Claude Opus 4.1 (claude-opus-4-1-20250805) will be retired from the Claude API on August 5, 2026, and recommends migrating to Claude Opus 4.8.

Fast mode has been removed for Claude Opus 4.6; requests that set speed to fast now run at standard speed and standard pricing instead of returning an error. Fast mode remains available by migrating to Claude Opus 4.8.

Claude Sonnet and Haiku now get the same rate limits as Opus at every usage tier, and tiers have been consolidated into three: Start, Build, and Scale. Most organizations move to a higher tier and no action is required.

Claude Code 2.1.319: background MCP tasks, deny-instead-of-prompt, and dozens of fixes

This release lets MCP tool calls run as background tasks in the terminal, adds a setting to auto-deny rather than prompt for permissions, and fixes a long list of bugs across auto mode, diffs, slash commands, and cloud/VSCode sessions.

IP allowlisting for organizations in the Claude Console (beta)

You can now restrict which IP addresses are allowed to reach your organization's covered services in the Claude Console. Requests from addresses not on the list are refused, limiting where a leaked API key could be used.

When creating an API key or Admin API key in the Claude Console, you can now set an expiration using a preset, a custom duration, or Never. Existing keys are unaffected.

Set an effort level on a Claude Managed Agents agent's model config

You can now pass an `effort` level inside the `model` object when creating a Claude Managed Agents agent. The Effort levels docs explain what each level does.

Legacy Workbench and experimental prompt APIs sunset August 17, 2026

The legacy Workbench in the Claude Console is being retired, along with the experimental prompt generation, improvement, and templatizing APIs. Access to both ends on August 17, 2026; saved prompts, variables, and evals won't carry over to the updated Workbench.

Mid-conversation system messages now available, no beta header needed

Mid-conversation system messages are available on Claude Fable 5, Claude Mythos 5, and Claude Opus 4.8 via the Claude API, Amazon Bedrock, and Google Cloud (Google managed), with no beta header required. This update corrects earlier availability notes.

Claude Mythos 5, Opus 4.7, Sonnet 4.6 text now watermarked

Text generated by Claude Mythos 5, Claude Opus 4.7, and Claude Sonnet 4.6 now carries Anthropic's text watermark on supported platforms. On Sonnet 4.6, requests that set a non-default temperature, top_p, or top_k may not carry the watermark.

Inference hooks are now in beta for Claude Enterprise organizations

Enterprise orgs can now route governed prompts across claude.ai, Cowork, and Claude Code through their own AI security server for an allow/deny decision before inference runs. Denials are logged in the compliance Activity Feed.

Compliance API now returns transcripts of Cowork sessions on claude.ai

The Compliance API can now retrieve transcripts of Cowork sessions started on claude.ai web or mobile, in beta for Claude Enterprise organizations. Two new endpoints list sessions and return their message transcripts using your existing Compliance Access Key.

Claude Code 2.1.318: sign-in expiry warnings, AWS role support, dozens of fixes

This release adds visibility into when a stored claude.ai sign-in expires, AWS role assumption for per-developer cost tracking, a per-job model effort override, and a long list of fixes for session stability, network-home configuration handling, and cloud/remote sessions.

Message Threads (beta): smaller requests, faster first token

A new beta feature called message threads lets long conversations and agent loops on the Messages API send only new messages instead of the full history, lowering time to first token. It's available via a beta header on the Claude API and several cloud platforms.

Set a spend budget on Claude Managed Agents sessions

You can now set a hard spending cap on a Claude Managed Agents session, priced at public list rates; the session pauses with a budget_reached stop reason once it hits the cap.

Claude Code 2.1.317: Exit hint now repeats your launch flags

The "Resume this session with" hint shown when you exit Claude Code now repeats the flags you originally launched with (like --chrome --debug) before --resume, so you don't have to remember or retype them.

Claude Code 2.1.317: email-exposure checks, blocking hook failures, cost reports

Claude Code 2.1.317 adds a check before tool calls send your account email over the network, a new 'block' option for failing Agent SDK hooks, and a cost report endpoint in the gateway admin API, alongside a large set of fixes across sessions, Windows, VSCode, and cloud/self-hosted runners.

ant CLI 1.30.0 adds `ant apply` for managing resources as code

The `ant` CLI can now create and update agents, environments, skills, memory stores, and deployments from files in your repo, with a lockfile that keeps re-runs updating the same resources instead of duplicating them.

SDK updates align beta Files/Skills APIs; new personal & service account keys

Several SDKs now have `client.beta.files` and `client.beta.skills` return the same shapes as the non-beta clients by default, and the Claude Console adds personal and service account API keys for easier usage tracking.

Workbench renamed to playground in the Claude Console

Workbench is now called playground, and it supports every Messages API parameter plus templates showing features like code execution and web search. It also displays the full SDK request and API response for each run.

Claude Sonnet 5 pricing stays at $2/$10 per MTok, no September hike

The introductory price for Claude Sonnet 5 ($2 / $10 USD per MTok) is now the permanent standard price. The previously announced increase to $3 / $15 USD per MTok on September 1, 2026 will not happen.

Cache diagnostics responses now always include a diagnostics field

When using the cache-diagnosis-2026-04-07 beta header, API responses now always include a `diagnostics` field, set to `null` if the request had no `diagnostics` object. Previously, the field was left out entirely in that case.

Messages API adds on-demand conversation compaction (beta)

The Claude API can now compact a conversation on demand: send the new compaction parameter and get back a signed summary block to swap in for the original messages on later requests, available in beta with the compact-2026-09-04 header.

Managed Agents add `auto` permission mode for tool calls

Claude Managed Agents permission policies now support `auto`, where the server decides per call whether to run, deny, or pause for your approval. Event logs now include an `evaluation` field showing how each call was handled.

Cache diagnostics now requires the diagnostics object on every turn

The API only stores a request's fingerprint when the request includes the diagnostics object; sending just the beta header no longer stores a fingerprint, so later turns referencing it will fail.

Fast mode for Claude Opus 4.8 is deprecated and will be removed on November 30, 2026, after which requests using speed: "fast" will error. Users who need fast mode should migrate to Claude Opus 5.5.

Billing resumes for certain pre-output refusals (bio, frontier_llm, reasoning_extraction)

Claude now bills for refusals that happen before any output when the stop reason category is "bio", "frontier_llm", or "reasoning_extraction", charged at the normal rate for the model used. Refusals before output in other categories remain unbilled, and fallback credit is unchanged.

Cache diagnostics exits beta, no beta header required

Cache diagnostics is now generally available on the Claude API. Opt in by including a `diagnostics` object on a Messages request instead of the old beta header, which still works if you're already using it.
