### Long-horizon coding

Engineering teams that need a model to inspect a codebase, use tools, make coordinated changes and keep a detailed implementation brief in view.

Independent tool overview

Claude Fable 5.1 is Anthropic’s high-capability model for coding, knowledge work and long-running problem solving across Claude apps, developer tools and the API.

Overview

Anthropic positions Claude Fable 5.1 as a model for sustained, multi-step work rather than only short chat responses. It is designed to plan, use tools, work through large tasks and preserve instructions across coding and knowledge-work workflows.

The model is available through Claude’s consumer and work surfaces, Claude Code, Claude Cowork, the Claude API and supported cloud platforms. Developers can select the claude-fable-5-1 API model, while Claude products choose an effort level suited to the experience.

Use cases

The strongest fit depends on the job you need the product to complete, not the size of its feature list.

Analysts and operators working through complex source material, structured reasoning and multi-part deliverables that benefit from sustained attention.

Developers building tool-using workflows where the model needs to plan, execute, check its work and continue across a longer task.

Organizations already using Claude Code, Claude Cowork or Anthropic’s API and cloud integrations that want the flagship Fable model in the same ecosystem.

Capabilities

Built for tasks that require multiple steps, tool calls and revisions instead of a single prompt-and-response exchange.

Targets software-development work that spans code understanding, implementation, debugging and verification across a larger task.

Claude experiences can vary the amount of reasoning effort, with higher defaults in Claude Code and medium defaults in Cowork and claude.ai.

Works in Anthropic’s agentic products and through the API for workflows that combine model reasoning with external tools and application context.

Available across Anthropic products and through AWS, Google Cloud and Microsoft Azure in addition to the direct Claude API.

Anthropic lists cache reads at $0.25 per million tokens, which can reduce repeated-input cost in workflows with a stable prompt prefix.

Process

Step 1

Use claude.ai or Cowork for knowledge work, Claude Code for repository tasks, or the API and cloud platforms for an application workflow.

Step 2

Describe the outcome, constraints, source material and permissions clearly so the model can plan the work without guessing at consequential choices.

Step 3

Use greater effort for difficult, high-value work and a lighter setting when latency and token use matter more than maximum depth.

Step 4

Check generated code, research claims and external actions before they become production changes or business decisions.

Bottom line

Claude Fable 5.1 is a strong fit for teams that value sustained coding and knowledge-work performance and already operate in Anthropic’s ecosystem. Its broad availability and cache-read economics help agent builders, but the premium output-token price makes task-level cost testing important. Teams optimizing first for lower unit cost should compare Gemini 3.8 Flash or Muse Spark 1.3, while specialized security work may call for Claude Opus.
