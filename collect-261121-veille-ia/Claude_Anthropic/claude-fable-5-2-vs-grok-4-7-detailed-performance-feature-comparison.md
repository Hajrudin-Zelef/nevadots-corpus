# Claude Fable 5.2 vs Grok 4.7

Get a detailed comparison of AI language models Anthropic's Claude Fable 5.2 and xAI's Grok 4.7, including model features, token pricing, API costs, performance benchmarks, and real-world capabilities to help you choose the right LLM for your needs.

Claude Fable 5.2 is Anthropic's latest generally available Mythos-class model for demanding reasoning and long-horizon agentic work. It improves coding, reasoning, and vision, generates output up to 30% faster than Fable 5.1, and supports adaptive thinking with configurable effort. The Claude API model ID is claude-fable-5-2.

Grok 4.7 is xAI's frontier model for coding, agentic tasks, and knowledge work. It is designed for longer-running work with stronger self-checking and context management, and supports text and image input, configurable reasoning through xhigh, function calling, web and X search, code execution, prompt caching, and a 500K-token context window.
