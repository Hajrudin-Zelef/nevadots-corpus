# Claude Haiku 5.5 vs Claude Sonnet 5.5

Get a detailed comparison of AI language models Anthropic's Claude Haiku 5.5 and Anthropic's Claude Sonnet 5.5, including model features, token pricing, API costs, performance benchmarks, and real-world capabilities to help you choose the right LLM for your needs.

Claude Haiku 5.5 is Anthropic’s fastest and most cost-efficient current model for high-volume, latency-sensitive work such as classification, extraction, routing, and subagent tasks. It supports adaptive thinking with adjustable effort, a 1M-token context window, and up to 128K output tokens. It is especially suited to real-time customer support, browser use, summarization, and compaction.

Claude Sonnet 5.5 is Anthropic's latest Sonnet model for coding, everyday agentic tasks, computer use, and professional knowledge work. It supports a 1M-token context window, up to 128K output tokens, adaptive thinking with high effort by default on the Claude Platform, and text and image input. Anthropic reports that it generates output 30%+ faster than Sonnet 5 and can cost up to 30% less per task.
