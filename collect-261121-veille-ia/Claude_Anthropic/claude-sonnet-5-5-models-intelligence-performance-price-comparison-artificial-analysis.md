# Claude Sonnet 5.5: Intelligence, Performance & Price Analysis

### Model summary

Claude Sonnet 5.5 (Max, Default Fallback) is amongst the leading models in intelligence and reasonably priced when comparing to other models of similar price. It's also notably slow per task and very verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Claude Sonnet 5.5 (Max, Default Fallback) scores 55 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 44). When evaluating the Intelligence Index, it generated 335M tokens, which is very verbose in comparison to the median of 65.4M.

Pricing for Claude Sonnet 5.5 (Max, Default Fallback) is $2.00 per 1M input tokens (moderately priced, median: $2.00) and $10.00 per 1M output tokens (moderately priced, median: $10.00). On average, it costs $10.02 per task to evaluate Claude Sonnet 5.5 (Max, Default Fallback) on the Intelligence Index.

At 33.0 minutes per Intelligence Index task, Claude Sonnet 5.5 (Max, Default Fallback) is notably slow compared with the median of 12.7 minutes for comparable models (lower is better).
