## Claude Sonnet 5.5 vs GPT-6 Sol FAQ

### Which is cheaper, Claude Sonnet 5.5 or GPT-6 Sol?

Both cost $2 per 1M input tokens. For 10M input and 2M output tokens, Claude Sonnet 5.5 costs $40 and GPT-6 Sol $40 at standard rates.

### Which is cheaper with prompt caching, Claude Sonnet 5.5 or GPT-6 Sol?

Claude Sonnet 5.5 charges $0.10 per 1M cached input tokens, 95% below its standard input rate, and GPT-6 Sol $0.20, 90% below. With 9M of 10M input tokens cached and 2M output tokens, Claude Sonnet 5.5 costs $22.90 and GPT-6 Sol $23.80.

### Which scores higher on independent benchmarks, Claude Sonnet 5.5 or GPT-6 Sol?

Claude Sonnet 5.5 leads on Arena Text, 1473 Elo to 1457 Elo; Claude Sonnet 5.5 leads on Arena WebDev, 1772 Elo to 1673 Elo; Claude Sonnet 5.5 and GPT-6 Sol are level on the Epoch Capabilities Index, 166.6 points and 163.8 points, inside overlapping 90% credible intervals (163.8 to 169.6 and 161.3 to 166.4). Scores are independent evaluations, not either vendor's launch figures.

### Which has the larger context window, Claude Sonnet 5.5 or GPT-6 Sol?

GPT-6 Sol has the larger context window, 1,050,000 vs 1,000,000 tokens. Both return up to 128,000 tokens per response.
