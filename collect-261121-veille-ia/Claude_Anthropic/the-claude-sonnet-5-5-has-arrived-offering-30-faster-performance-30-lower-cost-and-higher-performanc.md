# The 'Claude Sonnet 5.5' has arrived, offering 30% faster performance, 30% lower cost, and higher performance than the GPT-6 Sol compared to its predecessor.


Anthropic has released its AI model, ' **Claude Sonnet 5.5** .' Compared to the previous generation model, Claude Sonnet 5, it boasts improved performance and is said to be 30% faster. In benchmark tests, it has surpassed the GPT-6 Sol score.

 **Introducing Claude Sonnet 5.5 \ Anthropic**

 

The Claude series is offered in four main models: the flagship 'Fable/Mythos,' the high-performance 'Opus,' the balanced 'Sonnet,' and the lower-priced 'Haiku.' The newly released Claude Sonnet 5.5 is positioned as an updated version of

**the Claude Sonnet 5,**which was released at the end of June 2026.

The table below shows the benchmark results for 'Claude Sonnet 5.5,' 'Claude Sonnet 5,' 'Claude Opus 5.5,' and 'GPT-6 Sol.' Claude Sonnet 5.5 outperformed the previous generation model, Claude Sonnet 5, in all tests and recorded scores that surpassed GPT-6 Sol in knowledge work and chart comprehension performance.


The graph below shows the results of running the agent performance benchmark 'Terminal-Bench 4.0' on 'Claude Sonnet 5.5,' 'Claude Opus 5.5,' 'Claude Sonnet 5,' and 'GPT-5.6 Sol,' with the horizontal axis representing the cost per task and the vertical axis representing the score. Claude Sonnet 5.5 not only outperformed GPT-5.6 Sol but also demonstrated performance comparable to the higher-end model, Claude Opus 5.5.

 


Claude Sonnet 5.5 is 30% faster and 30% cheaper for most tasks compared to Claude Sonnet 5. In the following video of solving a puzzle cube, Claude Sonnet 5.5 completes the process faster and cheaper.

 Sonnet 5.5 is smarter, more efficient, and 30% faster than Sonnet 5. It costs up to 30% less for most work, so your Claude Code usage goes further too.

 Use it for well-scoped everyday tasks like fixing bugs and quickly iterating on features. 



 Anthropic has published examples of how early users are using Claude Sonnet 5.5 in the following thread, where you can see practical examples such as 'falling leaves simulator,' '3D model design,' and 'animation creation with JavaScript.'

 Third-party organization **Artificial Analysis** has also published its test results for Claude Sonnet 5.5. Based on multiple test results, **the Artificial Analysis Intelligence Index v4.3.2** calculates an overall performance index for the model, resulting in a score of '56,' which is 3 points higher than the flagship model, Claude Fable 5.1.

 


On the other hand, the high token usage when the inference level is set to maximum has also been pointed out. The graph below shows the token usage per task during testing with Artificial Analysis, and it can be seen that Claude Sonnet 5.5 uses more tokens than Claude Opus 5.5.

 


The graph below shows the cost per task on the horizontal axis and the performance score on the vertical axis, revealing that Claude Sonnet 5.5 is 'lower performing and more expensive' than Claude Opus 5.5. Although the cost per token is cheaper for Claude Sonnet 5.5 than for Claude Opus 5.5, the cost reverses at the maximum inference level due to the larger token usage.

 


Anthropic advises, 'For large-scale projects, we recommend using Opus, and when you need a balance between quality, speed, and cost, we recommend using Sonnet.' They also state, 'Setting Sonnet's inference level to Max may cause an imbalance, in which case we recommend considering the use of Opus.'

We recommend starting with Opus for large projects and Sonnet for tasks where you need to balance quality with speed and cost. Claude apps default to medium effort, while Platform is at high. Cranking Sonnet to max loses some of the balance (and you might want to consider Opus).

 Claude Sonnet 5.5 is already available for use with various Anthropic services. The default model for the free plan has also been switched to Claude Sonnet 5.5.

 


API fees are the same as for Claude Sonnet 5. The fees per million tokens are $0.20 (approximately 31.5 yen) for cache reads, $2.50 (approximately 393 yen) for cache writes, $2 (approximately 315 yen) for inputs, and $10 (approximately 1574 yen) for outputs.

 Claude Sonnet 5.5 incorporates the same safeguards as the Fable and Opus series, which interrupt processing and fall back to another model if a conversation is deemed to contain dangerous content related to cyberattacks or other threats.

 On our automated behavioral audit, Sonnet 5.5 improves on or matches Sonnet 5 on most measures of alignment and honesty.

 It's also the first Sonnet model with cyber safeguards and fallbacks like those on our most capable models. Routine software development is unaffected.



 Furthermore, it has been announced that Claude Haiku 5.5 will be released within the next few weeks.
