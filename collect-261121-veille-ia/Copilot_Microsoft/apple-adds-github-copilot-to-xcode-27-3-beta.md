Apple released the first Xcode 27.3 beta on Nov. 4, adding GitHub Copilot to the development environment’s built-in coding assistant.

The release notes list GitHub Copilot as available in Coding Intelligence under identifier 185837709. Developers can use the service directly within Xcode alongside existing AI coding integrations.

Apple introduced ChatGPT integration in Xcode 26 and later added Anthropic’s Claude. Xcode 26.3 expanded those integrations with agentic coding capabilities through OpenAI’s Codex and Anthropic’s Claude Agent.

Xcode 27 added Google Gemini support, a redesigned interface, interactive planning and multi-turn conversations. Developers have been able to integrate AI coding agents directly into Xcode since Xcode 26.3.

Xcode 27.3 beta includes Swift 6.4 and software development kits for iOS 27.3, iPadOS 27.3, tvOS 27.3, watchOS 27.3, macOS 27.3 and visionOS 27.3. It supports on-device debugging on iOS 17 or later, tvOS 17 or later, watchOS 10 or later, and visionOS.

The beta requires a Mac running macOS Tahoe 26.6 or later.

Device Hub now lets developers drag an.app or.ipa file onto a device to install an app, or drag a link to open it. On iOS simulators, other files can be dropped onto a device for saving through the Files app.

Device Hub now supports option-drag to simulate two-finger touch gestures on iPhones and iPads. It also accepts keyboard and mouse input for operating system simulators earlier than iOS 18.0, tvOS 18.0, watchOS 11.0 and visionOS 2.0.

CarPlay support in Device Hub requires a device connected physically through a USB cable and does not support iOS Simulator. When Device Hub runs through Sidecar or on a Mac with Touch, it can send only two touches to the target device; Apple advises turning off touch gestures in Touch Display settings as a workaround.

The RenderPreview MCP tool now adds applied overrides to snapshot filenames and metadata and supports interactive delayed snapshots for macOS previews. Xcode also now supports UI tests written with Swift Testing and XCUIAutomation.

XCUIAutomation adds an XCUIHinge class that can set the hinge angle on iPhone Duo. Xcode 27.3 is expected to be released in December alongside macOS 27.3 and related operating system updates.
