Apple has released a beta of Xcode 27.3, adding three new features.

They are: GitHub Copilot support within the built-in coding assistant, the ability for developers to test Siri AI integration in their apps, and additional APIs for developers to optimize their apps for the upcoming MacBook Pro with PROLED XDR Display.

Xcode is a free developer tool for Apple’s various operating systems. You can learn more here.

Available on Apple silicon Macs running macOS 26.6 or later, version 27.1 includes updated SDKs for the iPhone Duo, and a simulator that supports the device’s new poses and orientations.
