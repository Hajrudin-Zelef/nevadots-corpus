From the source


- GitHub has deprecated several models across most Copilot experiences, including Copilot Chat, inline edits, ask and agent modes, and code completions, as of November 16, 2026.
- The deprecations were announced on October 15, 2026, and GitHub says no action is required to remove the deprecated models.
- Claude Opus 4.8 remains available to individual Copilot subscribers on annual plans, while Claude Opus 5 has been removed from the model picker but stays available for runtime refusal fallback through existing authorized access.
- Under default model enablement, suggested alternatives are automatically enabled for Copilot Enterprise and Copilot Business customers unless an administrator has turned off the global default or explicitly disabled the model.
- Administrators who turned off the global default can enable the alternatives through their model policies in Copilot settings, after which users see the model in the Copilot Chat model selector in supported experiences.
- GitHub encourages enterprise customers with questions to contact their account manager.
