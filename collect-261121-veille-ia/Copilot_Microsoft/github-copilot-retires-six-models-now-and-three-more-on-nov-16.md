*Catch-up item covering GitHub notices from Oct 15 and Oct 19.*

On Oct 19 GitHub deprecated six Copilot models: Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini and Grok 4.5. GitHub suggests Grok 4.7 in place of Grok 4.5.<sup>4</sup>

On Nov 16 GitHub will retire Claude Opus 4.8 and Claude Opus 5 (it suggests Opus 5.5) and GPT-5.6 Terra (it suggests GPT-6.1 Sol or GPT-6 Luna). Individual subscribers on annual plans keep Opus 4.8.<sup>5</sup>

Separately, on Oct 22 GitHub began enforcing its global default policy for generally available Copilot features on Business and Enterprise plans, rolling out through Oct 26. Eligible features an administrator hasn't configured will follow the global policy; admins can still set individual features.<sup>6</sup>

What to do: check custom instructions, agent configs and org policies that pin a retiring model. Our GitHub Copilot review tracks the Nov 16 change.
