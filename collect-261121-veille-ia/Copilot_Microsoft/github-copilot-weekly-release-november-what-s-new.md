# GitHub Copilot weekly releases: *November 2*

GitHub's November 2 Copilot update brings Copilot to JetBrains Air and Xcode's coding assistant, plus new pull request, settings, and session tools.

**GitHub Copilot's November 2 weekly update brings the assistant to JetBrains Air and to Xcode's built-in coding assistant, alongside new options for pull requests, settings, and agent sessions.** GitHub posted the changes in its weekly releases changelog on November 6, 2026.

## What changed

Here is what the changelog covers, tool by tool.

- **Copilot app.** Agent Merge can now be set up straight from a pull request, and it stays switched on while required checks or rules are still pending. You can also see where reviewers stand, ask for more reviews, and highlight comment text to quote it or talk it over with Copilot.
- **Copilot app, context limits.** When a chat hits its context limit, you can now shrink the conversation or see what is taking up space, right from the error message.
- **Copilot app, sessions.** Dropping files onto "New" in the sidebar starts a session, and CSV and TSV files open as tables with sticky headers and a way to view the raw source. You can archive pinned sessions whose pull requests have merged or closed, pin or unpin several sessions at once, and split nested chats without losing the thread. My Work now holds more than ten saved custom views.
- **Copilot app, approvals.** A new opt-in setting lets you give Copilot standing guidance on which tool requests it may approve on its own. It applies to local sessions.
- **Copilot CLI.** The /settings command now opens a single dashboard for plugins, MCP servers, and more, with search across all of your settings.
- **JetBrains.** Copilot is now available in JetBrains Air, a new way to use it in JetBrains IDEs. You can follow several agent sessions at once and run tasks either on your machine or in the cloud through Air Teams, with the Copilot subscription you already have.
- **Xcode.** Copilot now works inside Xcode's built-in coding assistant, so it fits into your normal Xcode workflow. This is a public preview and starts with Xcode 27.3 beta.
- **VS Code 1.145.** New experimental chat view modes let you fold away or expand reasoning and tool calls in an ongoing conversation. The Agents window, now in preview, can show remote apps and interactive canvases, and remote browser support can be turned on in settings. Local automations accept cron expressions and custom agents from your workspace. You can attach screenshots, mockups, and other files to chat through Add Context > Files without moving them into your workspace, though cloud sessions only take images. In long chats, past terminal output now renders as you expand or reveal it instead of loading all at once.

## What this means for you

If you write code on a Mac, the changelog says Copilot now works directly in Xcode's built-in coding assistant. If you use JetBrains IDEs, Air gives you a choice between running tasks locally or in the cloud, and the changelog says your current Copilot subscription covers it.

In the Copilot app, Agent Merge can be set up from a pull request and stays enabled while required checks or rules are pending. When a chat reaches its context limit, you can compact it or review what is using the space. In VS Code, files you attach through Add Context no longer have to sit inside your workspace.

## How to try it

The changelog has install and getting-started links for the Copilot app, Copilot CLI, Copilot in JetBrains Air, and Copilot in Xcode. The Xcode preview is available starting with Xcode 27.3 beta. The JetBrains Air integration works with your existing Copilot subscription, and Copilot is also listed on the plans page as available across Xcode and JetBrains IDEs.

## What it costs

On the official Copilot plans page, as of November 5, 2026, the individual plans are Free at $0 USD, Pro at $10 USD per user per month, Pro+ at $39 USD per user per month, and Max at $100 USD per user per month. The Free plan includes 2,000 completions per month, and verified students have access to the GitHub Copilot Student plan.

For a deeper look at the plans, see our GitHub Copilot price breakdown, the Copilot hub page, or our guide on whether GitHub Copilot is free. If you want more on the Xcode preview, read Copilot comes to Xcode's coding assistant.

## Questions people ask

### What is in the GitHub Copilot weekly release for November?

The November 2 batch adds Copilot to JetBrains Air and, in public preview, to Xcode's built-in coding assistant. It also brings updates for pull requests, settings, and agent sessions across the Copilot app, CLI, and VS Code.

### Do I need a paid plan to use Copilot in Xcode or JetBrains Air?

The changelog says you can use your existing Copilot subscription for the JetBrains Air integration. The Xcode integration is in public preview starting with Xcode 27.3 beta.

### How much does GitHub Copilot cost?

As of November 5, 2026, the plans page lists Free at $0, Pro at $10 per user per month, Pro+ at $39 per user per month, and Max at $100 per user per month.

### What is Agent Merge in the Copilot app?

Agent Merge lets you set up a pull request so Copilot merges it when it is ready. The November update keeps it enabled while required checks or rules are still pending, and adds reviewer status checks and review requests.

### Which editors does GitHub Copilot work in?

The pricing page lists GitHub, VS Code, Visual Studio, Xcode, JetBrains IDEs, Neovim, Eclipse, Raycast, SQL Server Management Studio, and Zed. The November 2 update adds the new JetBrains Air and Xcode coding assistant options.

### What is new in Copilot CLI this week?

The /settings command now opens one dashboard where you can manage plugins, MCP servers, and other settings, and you can search across all of them in one place.
