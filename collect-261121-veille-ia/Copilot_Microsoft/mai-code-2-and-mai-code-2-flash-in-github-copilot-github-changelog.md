The next generation of Microsoft AI (MAI) coding models has arrived in GitHub Copilot. Introducing **MAI Code 2** and **MAI Code 2 Flash**, two new models that represent a major step forward for the MAI-Code family, expanding from lightweight coding assistance to complex, agentic software engineering.

- **MAI Code 2:** A powerful, general purpose coding model built to help developers get from request to result with focused responses, practical code changes, and less unnecessary back and forth. Ideal for complex tasks like deep debugging, multi-file implementation, refactoring, and repository-wide reasoning.
- **MAI Code 2 Flash:** A lightweight, cost-efficient coding model optimized for everyday development workflows. Well suited for code explanations, targeted edits, routine fixes, and rapid iteration.

Both models are designed for agentic coding workflows, giving developers more flexibility to choose the model that best fits their task.

Read the MAI Code 2 and MAI Code 2 Flash announcement for a deeper look at the model’s vision support, coding performance improvements, and efficiency gains.

These models are billed under usage-based billing. For more details, see Models and pricing for GitHub Copilot.

- **MAI Code 2:** Copilot Pro, Pro+, Max, Business, and Enterprise
- **MAI Code 2 Flash:** Copilot Free, Student, Pro, Pro+, Max, Business, and Enterprise

Both models are available to eligible GitHub Copilot subscribers on annual plans.

You can select the models in the model picker in:

- Visual Studio Code
- Visual Studio
- Copilot CLI
- GitHub Copilot cloud agent
- GitHub Copilot app
- github.com
- GitHub Mobile iOS and Android
- JetBrains
- Xcode
- Eclipse

Copilot Enterprise and Copilot Business plan administrators can manage access to MAI models through the model policy in Copilot settings. Under default model enablement, new models are enabled automatically unless an administrator has turned off the global default or explicitly disables the model.

To learn more about the new models, see the MAI Code 2 page.

To explore all models available in GitHub Copilot, see our documentation on supported models and get started with Copilot.

We’d love to hear about your experience using MAI Code 2 and MAI Code 2 Flash. Join the GitHub Community to share your feedback and help us continue improving these models.
