# Microsoft announces new AI programming model 'MAI Code 2' and its high-speed version 'MAI Code 2 Flash,' delivering performance comparable to GPT-6.1 Sol at 40% of the cost.


 Microsoft announced the programming AI models 'MAI Code 2' and 'MAI Code 2 Flash' on November 17, 2026. MAI Code 2 is said to offer performance comparable to OpenAI's 'GPT-6.1 Sol' at a lower cost, and both models are available for use with the AI programming support tool 'GitHub Copilot'.

 AI-powered programming assistance is used for a wide range of tasks, from code generation to bug fixing. However, a challenge arises: frequent use of high-performance AI models increases processing costs. This is especially true for businesses, where a large volume of daily correction work occurs, making it crucial to balance the performance and cost of AI models.

 Microsoft announced the compact programming model 'MAI-Code-1-Flash' in June 2026, and released an improved version, 'MAI-Code-1.1-Flash,' in October of the same year. The newly announced MAI Code 2 series also offers high-performance models for complex development tasks and high-speed models for handling everyday tasks at a low cost.**Microsoft releases local AI 'MAI-Code-1.1-Flash' and proposes 'hybrid intelligence' combining local and cloud AI - GIGAZINE** 


 MAI Code 2 supports the implementation of features spanning multiple files, the investigation of complex bugs, and code modifications that take into account the overall software structure. It also excels at creating user interfaces such as management screens and graphs, and places a strong emphasis on generating code of a quality that can be integrated into actual products.

 To verify the performance of MAI Code 2, Microsoft conducted four benchmark tests measuring programming ability. The average success rate, which indicates the percentage of tasks correctly solved, was 63.2% for MAI Code 2, 64.1% for GPT-6.1 Sol, and 65.3% for Anthropic's 'Claude Opus 5.5'. The average cost to complete one task was approximately 40% for MAI Code 2 compared to GPT-6.1 Sol and approximately 5% compared to Claude Opus 5.5.

 


 Furthermore, in tests where humans compared screen design and functionality, 64% rated the results generated by MAI Code 2 as superior to those of 'GPT-6 Sol.' 258 people participated in the evaluation, comparing both the appearance and functionality of the screens.

 MAI Code 2 Flash, on the other hand, is a model designed for quickly handling code explanations, partial modifications, and common bug fixes. It is designed to reduce processing costs when performing repetitive modifications or dealing with large amounts of code.

 In three benchmark tests conducted by Microsoft, MAI Code 2 Flash achieved an average success rate of 61.0%. For comparison, OpenAI's 'GPT-6 Luna' achieved 55.1%, and Anthropic's 'Claude Haiku 5.5' achieved 53.9%, with MAI Code 2 Flash outperforming both models in terms of average success rate. The average processing cost was also reduced to 65% of GPT-6 Luna and approximately 20% of Claude Haiku 5.5.

 


 Please note that the benchmark results use a 50% discount promotional price for MAI Code 2 and MAI Code 2 Flash. The promotional price is valid until May 17, 2027, after which it will revert to the regular price.

 Microsoft has also developed a model called 'MAI Work Flash' based on MAI Code 2 Flash. MAI Work Flash is optimized for business products such as Excel, Word, PowerPoint, and Teams, and internal testing has reported that it performs at a level comparable to the GPT-6 series for some tasks.

 


 MAI Code 2 and MAI Code 2 Flash are available on GitHub Copilot. Additionally, a preview of MAI Code 2 Flash is being offered to select users through Microsoft Foundry, an AI model development and operation service. Microsoft has stated that it plans to offer MAI Code 2 Flash on OpenRouter, Vercel, Hermes, OpenCode, and Kilo in the future.
