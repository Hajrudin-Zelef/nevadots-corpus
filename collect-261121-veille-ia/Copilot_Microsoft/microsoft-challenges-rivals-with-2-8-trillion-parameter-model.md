# Microsoft challenges rivals with 2.8 trillion parameter model

Completion of MAI-Base-2 pretraining signals direct competition for enterprise foundation model licensing.

## In a nutshell

Microsoft has concluded the 38-day pretraining run of MAI-Base-2, a 2.8 trillion parameter artificial intelligence system built on 16,000 Nvidia GB200 processors. By adopting a mixture-of-experts design that fires 80 billion parameters per pass, the company aims to curb operating costs while establishing internal frontier capabilities independent of external partners. Unverified internal benchmarks claim the system runs four to twelve times more efficiently than DeepSeek V4 Pro on programming tests, setting up a direct commercial contest as Microsoft prepares to license the model weights to corporate clients.

## Highlights

- Microsoft finished pretraining the 2.8 trillion parameter MAI-Base-2 model in 38 days.
- The training cluster utilized 16,000 Nvidia GB200 processors on the Azure cloud network.
- The model activates 80 billion parameters per forward pass to reduce running costs.

## Who's involved

## In short

Microsoft has built its own top-tier artificial intelligence system, breaking its reliance on outside vendors to supply the core software powering modern automation. The software giant completed the initial training of MAI-Base-2, a foundation program that contains 2.8 trillion settings or parameters. By proving it can train a system of this scale in-house, Microsoft positions itself to sell foundational code straight to major corporate buyers rather than merely hosting tools built by external research groups.

The direct outcome is an escalation in commercial price and performance competition for corporate software contracts. This outcome is likely because Microsoft has officially committed to licensing the underlying model weights directly to enterprise clients, directly taking on rival suppliers.

Whether the system delivers on early efficiency claims remains uncertain because Microsoft has yet to publish a peer-reviewed technical paper or provide verifiable third-party testing.

## How it unfolded

## Mustafa Suleyman Announces MAI-Base-2 Pretraining Completion

Mustafa Suleyman announced that Microsoft AI finished pretraining its flagship MAI-Base-2 model on October 15, 2026. The run established Microsoft as an independent builder of frontier systems, using an architecture of 2.8 trillion total parameters with 80 billion active per calculation. The division completed the run in 38 days by deploying 16,000 Nvidia GB200 processing chips linked within its Azure data centers.

## Benchmarking Claims and Commercial Licensing Rollout

The announcement quickly shifted from technical milestone to commercial rivalry as internal performance metrics circulated among industry analysts on October 16. The claims asserted that MAI-Base-2 operates with four to twelve times greater computing efficiency than DeepSeek V4 Pro when evaluated on organic coding tests. By October 18, Microsoft turned those efficiency claims into a market strategy, officially confirming plans to license the model weights directly to corporate buyers. The move directly challenges open-weight competitors by converting proprietary engineering into a licensed business product.

## Where things stand

Core pretraining of the base weights is complete, and Microsoft has formally committed to licensing the model weights directly to commercial customers.

A full technical paper covering academic evaluations, safety alignment, and public availability has not been released. Industry analysts are waiting for public documentation and independent benchmark replication against rival systems before verifying Microsoft's efficiency claims.
