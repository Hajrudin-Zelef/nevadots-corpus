Microsoft's updated decision model gains 6 points on the benchmark, runs more than twice as fast, and keeps its price unchanged

Microsoft has released Microsoft-Decision-1.1, a specialized AI model built to make business decisions. It scored 68 on the Artificial Analysis Decision Index v2.1 and runs more than twice as fast as the version before it.

The first version only entered public preview in October 2026. So Microsoft shipped a faster, higher-scoring sequel within weeks.

## What changed between versions

The new model launched on November 17, 2026. Its benchmark score climbed to 68, up from the 62 that its predecessor, Microsoft-Decision-1, posted on the same index.

Speed is the bigger headline. Decision-1.1 completes a task in 123 milliseconds, compared with 274 milliseconds for the earlier model.

Pricing did not move. The model still costs $0.042 per million input tokens, the same rate as Decision-1.

## How the model actually works

Under the hood, Decision-1.1 is a post-trained version of Qwen3.5-9B. It carries 9 billion parameters and handles a context window of roughly 32k-33k tokens.

It is tuned for single-pass probability scoring: give it a question, and it returns a calibrated estimate of how likely each answer is.

Microsoft built it to handle several formats. These include yes/no answers, multiple-choice questions, and rubric-based assessments.

Microsoft says it has been using the model internally. The company also reports that more than 4,000 customers have used it since the public preview began.

## Where it sits on the leaderboard

Artificial Analysis, which runs independent benchmark assessments, ranks Decision-1.1 eighth among decision models on its v2.1 index. That places it ahead of several recognizable names, including Jev 1.14, Google’s Gemini Decision 1, and OpenAI’s GPT-6 Luna.

Microsoft has also made its own accuracy claims. The company says the model leads on average accuracy across 102 blind benchmarks, with more than 385,000 questions evaluated.

That figure comes from Microsoft rather than from Artificial Analysis.

## What this means

Microsoft held its token price flat while cutting task time from 274 milliseconds to 123 milliseconds, so customers effectively get more throughput for the same spend.

Decision-1.1 is built on Qwen3.5-9B, a relatively compact base model, and it still outranks entries from Google and OpenAI on the Artificial Analysis index.

Seven models remain ahead of Decision-1.1 on the v2.1 index, so Microsoft is competitive rather than dominant on that particular scoreboard.

Microsoft’s broader accuracy claim across 102 benchmarks has not been framed as an independent result. Buyers evaluating the model will want to test it against their own data before trusting it with decisions that carry real consequences.
