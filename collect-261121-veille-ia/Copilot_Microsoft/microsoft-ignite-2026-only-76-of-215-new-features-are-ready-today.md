Microsoft Ignite 2026 brought 59 announcements, but look closer and they hold 215 separate features. Only 76 are generally available today, and most of those are for Azure, not Word, Excel or Outlook. For Microsoft 365 users, the real arrivals are Office in Copilot and the new Home in the Copilot app. The Copilot features getting the headlines, like Autopilot, Copilot Workspaces and Copilot Code, need Microsoft’s Frontier early access program, an extra license, or both. Here’s what you can use now, what costs extra and what to wait for.

Microsoft’s Ignite 2026 Book of News is a long list with 59 announcements. Dig into each item and there are really **215 separate features**, each with its own release status. Only **76 of them (35%) are generally available** today. More than half, **109**, are previews or limited to Microsoft’s **Frontier early access program**.

That gap matters because Microsoft’s headlines blur it. “Introducing” and “new” can mean anything from ready today to a private preview for a handful of customers or a nebulous promise. A single item often mixes them: one feature generally available, three more in preview.

It’s “déjà vu all over again” for customers because Microsoft has already “introduced” some of these “new” features many times..

We went through every item and sorted each “Book of News” feature by what you can actually use.

## The Ignite 2026 scorecard

Add the 8 features that are live but cost extra, and **84 features (39%) are usable today**. The other 131 are previews, dated promises or vague plans. As usual, some of Microsoft’s promises are so vague that they make astrologers look good.

## What you can use now

**For most Microsoft 365 users, very little changes this week.** Office in Copilot and the new Home are the practical arrivals, but they’ve been announced before.

The Copilot features getting the attention need Frontier, a Microsoft 365 license you may not have, or both.

- **Read past the headline.** “Generally available” or “GA” doesn’t mean all customers get the feature. Often “GA” covers one part of an item while the rest is still preview. The Microsoft 365 license and Copilot entitlement matter a lot.
- **Check licensing before you plan.** Microsoft rarely says which license a new Copilot feature needs. Several features that sound included need Copilot Credits, Defender for Endpoint P2 or an Agent 365 license.
- **Want Autopilot, Workspaces or Copilot Code now?** Ask your IT department whether your organization is in the Frontier program. If not, wait for general availability.
- **IT admins: start testing the agent controls.** Most of the agent governance in Entra, Intune, Purview and Agent 365 is in preview. Try it in a test tenant now, so you’re ready when it ships.
- **Put December in your calendar** . Copilot Code is due for general availability and the Agent 365 action center enters private preview. January brings the AI Readiness Initiatives in Perception.

### Believe Copilot when you see it

Our best advice for coping with Microsoft’s messy messaging for Copilot is simple “Believe Copilot when you see it”. Don’t get too excited about features Microsoft promises; they might not reach you soon, or at all.

In other words, wait until the option appears for you or your IT admin gives their virtual green light.

## Available now: 76 features, mostly for Azure

Most of the 76 generally available features are aimed at Azure customers and developers, not people working in Word, Excel and Outlook. Two thirds of them (51) are Azure, Fabric, Foundry, GitHub or Microsoft IQ platform features.

### For Microsoft 365 and Copilot users

Most of these “Book of News” mentions have already been announced by Microsoft, some ad nauseam.

- **Office in Copilot** : Word, Excel and PowerPoint inside the Microsoft Copilot app, so you can go straight from a chat to a document. Files save to OneDrive and keep their sensitivity labels.
- **Home** in the Copilot app, which brings Chat and Cowork together, is rolling out worldwide.
- **Auto** now suggests moving from Chat to Cowork for complex tasks, and carries your context across.
- **Microsoft IQ** is generally available with “no new SKU or subscription.” Work IQ for organizations adds richer context, memory and more actions for Copilot and agents.
- **Fabric IQ** and**Power BI semantic models** inside Copilot.

**Microsoft doesn’t say which license the Copilot app features need.** Don’t assume they’re free until Microsoft says so.

### For Dynamics 365 customers

- **Dynamics 365 Sales plugin** and**ERP apps plugin** in Copilot, Cowork and Excel.
- **Dynamics 365 Activate** : Salesforce migration is generally available. SAP ECC migration tools start rolling out now and continue over the coming weeks.
- **Salesforce Data Federation** with Fabric, for customers who have both Salesforce Data 360 and Fabric.

### For IT admins and security teams

- **Microsoft Perception** (formerly Project Perception) is generally available. Its Triage Agent now covers about 80% of alerts in a typical Defender queue.
- **Integrated Security Operations Center** : the core capabilities are generally available.
- **Agent 365 usage insights** for Microsoft agents are now open to all admins, whatever their Agent 365 licensing.
- **Microsoft MCP Server for Enterprise** in Entra.
- **Edge for Business extension safety** , with Akamai and Spin.AI risk scores for every extension.
- **Windows Endpoint Security Platform** , plus a learning and permissive mode for building agent policies safely.
- **Windows 365** : Direct Stream improvements, context based redirections, and Cloud PCs up to 32 vCPU with GPUs for running AI models locally.

### For Azure customers and developers

- **Azure Cobalt 200 VMs** : up to 50% faster than Cobalt 100, in 11 regions now and 24 by the end of the year.
- **Azure HorizonDB** , a managed PostgreSQL compatible database.
- **Azure Catalyst** , for AI assisted migration and modernization.
- **Web IQ** for all Azure customers, at a lower price.
- **Microsoft Copilot SDK 2.0** , the Microsoft Decision 1.1 model, and MAI Code 2 in GitHub.
- A long tail of Cosmos DB, SQL and PostgreSQL updates.

## Available, but it costs extra: 8 features

**Eight features are live now but need an extra license or are billed by usage.** Read the small print before you switch them on.

| Feature | What you need | 
| Defender runtime protection for local AI agents such as Claude Code, GitHub Copilot, ChatGPT and Ollama (2 features) | **Defender for Endpoint P2** | 
| Agent 365 plugin and skill governance for Copilot and Cowork | **Agent 365 or ME7 license** (E7 plan with Copilot). | 
| Copilot Managed Runtime, plus its optional Fabric data backend (2 features) | **Metered** : Microsoft lists the runtime as a usage based service | 
| Windows 365 for Agents billing, and its computer use tool in Copilot Studio (2 features) | **Copilot Credits** , paid per use | 
| Entra Global Secure Access agentic traffic acquisition. | **Global Secure Access licenses** (our reading; Microsoft doesn’t say) | 

The license strings don’t stop there. Several previews come with them attached:

- **Today Brief** is included with a Microsoft 365 Copilot license, but**Today Feed** , which refreshes through the day,**needs Copilot credits** .
- **Agent 365 Business Analytics** needs at least one Microsoft 365 Copilot license in the tenant, and an Agent 365 license for insights on non Microsoft agents.
- **Viva Insights** will drop its Agent 365 requirement for agent insights, but still needs**at least 50 assigned Copilot licenses** .
- **Power BI custom data apps** are a preview for**Power BI Pro** customers.

## Preview or Frontier only: 109 features

**More than half of Ignite 2026 is in preview.** Of the 109, 87 are public previews, 9 are private previews, 11 are Frontier only and 2 are pilot or early access programs.

### Frontier: the Copilot features you’ve been reading about

Frontier is Microsoft’s opt in early access program. **If your organization isn’t enrolled, you won’t see any of these:**

- **Autopilot** , the long running personal agent that follows up and runs recurring work on its own.
- **Copilot Workspaces** , the renaming of Copilot Notebooks, for teams working together with Copilot.
- **Copilot Code** , for building apps and dashboards in plain language.**Microsoft promises general availability in December.**
- **Today Brief** and**Today Feed** , the new daily priorities view in Copilot and Outlook (private preview through Frontier).
- **Cowork using your existing declarative agents** (private preview through Frontier).
- **Auto in Cowork** choosing how hard to think using the Microsoft Decision 1.1 model.
- **Business plugins** in Microsoft IQ.
- **Agent 365 Business Analytics** and**Agent 365 cost forecasting** .
- **Persistent Cloud PCs** for always on agents in Windows 365 for Agents.

### Public previews worth watching

- **Windows Server 2028** , through the Windows Server Insider Program.
- **Copilot on Windows** : managing local files in plain language, PC diagnostics, and Copilot in the new Windows Search (opt in, and IT can manage it by policy).
- **Purview** : stronger Copilot data loss prevention that blocks unlabeled sensitive files and covers attachments and linked files.
- **Fabric IQ in Excel** : ask governed semantic models questions in Edit with Copilot and build live PivotTables.
- **Salesforce in Copilot** , with more than 38 prebuilt sales skills.
- **Edge for Business** : the skills recorder, managed agent browsing and extension leak control.
- **Defender** : vulnerability shielding, 90 days of included data retention, and a new view of zero day and emerging threats.
- **Entra** : 13 of its 15 announcements are previews, including Conditional Access policy plans, MCP Firewall and Agent ID for local agents.

### Private previews

These go to selected customers only. Most are Windows and Intune management features: **Windows baseline protection**, Intune and Autopatch support for **Windows Server 2028**, **automatic updates for all Windows apps**, **experience controls** for new Windows features, and **OS reliability reporting**. The rest are Web IQ Commerce, Azure Workload Center for Oracle and SAP, Perception’s secure AI agents playbooks, and Windows Server 2025 with Azure Virtual Desktop (AVD) Hybrid.

## How we counted

- **One feature, one announcement.** Each separately named feature with its own stated status counts once, which turns 59 Book of News items into 215.
- **Repeats count once.** Agent 365 Business Analytics appears twice, and the Microsoft IQ section repeats Foundry’s training news.
- **Perception features with no preview label count as available** , because Microsoft’s heading says they are “now available.”
- **Two calls are ours:** the Global Secure Access licensing and Copilot Managed Runtime billing. Microsoft doesn’t spell either out.
