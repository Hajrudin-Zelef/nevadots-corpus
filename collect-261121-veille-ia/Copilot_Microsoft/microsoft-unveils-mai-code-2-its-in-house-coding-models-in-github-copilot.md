# Microsoft Unveils MAI Code 2, Its In-House Coding Models, in GitHub Copilot

Microsoft unveiled MAI Code 2 and MAI Code 2 Flash at Ignite 2026 on November 17, its first in-house coding model family, live in GitHub Copilot now. Microsoft claims Code 2 delivers 98% of GPT-6.1 Sol's coding performance at 40% of the cost and 96% of Claude Opus 5.5 at 5%, on its own benchmarks and promotional pricing, with MAI Cyber 2 Flash, Microsoft-Decision-1.1, new image and transcription models, and licensable Azure weights completing the lineup.

- **01** THE LAUNCH — Microsoft unveiled MAI Code 2 and MAI Code 2 Flash at Ignite 2026 on November 17, its first in-house general-purpose coding models, live in GitHub Copilot from day one.
- **02** THE PRICE CLAIM — On Microsoft's own benchmarks, Code 2 reaches 98% of GPT-6.1 Sol at 40% of the cost and 96% of Claude Opus 5.5 at 5%; the cost figures use a 50% promotional price.
- **03** THE REST OF THE FAMILY — MAI Cyber 2 Flash, Microsoft-Decision-1.1, new image and transcription models, and MAI Work Flash for Microsoft 365 apps round out a seven-model lineup, with licensable weights for Azure enterprise customers.

## WHAT HAPPENEDWhat Happened

Microsoft used Ignite 2026 on November 17, 2026 to unveil MAI Code 2, the first generation of its in-house coding models, alongside a smaller sibling, MAI Code 2 Flash. The two models are live in GitHub Copilot now, billed on usage, and they mark the company's clearest move yet to compete with OpenAI and Anthropic on its own models rather than renting theirs. Microsoft AI chief Mustafa Suleyman told Reuters the launch is a system, not a single model: "This isn't just one model. It's not a flash in the pan. This is a system, a hill-climbing machine that we have built, which co-optimizes performance and price."

The pitch is price. Averaged across four coding benchmarks in Microsoft's own testing, the company says MAI Code 2 delivers 98 percent of the performance of OpenAI's GPT-6.1 Sol at 40 percent of the cost, and 96 percent of Anthropic's Claude Opus 5.5 at 5 percent of the cost. MAI Code 2 Flash, the lighter model for high-volume work such as explaining code, making quick edits and fixing routine bugs, is presented as comparable to GPT-6 Luna and Claude Haiku 5.5 at 65 percent and 20 percent of their cost. In blind tests of front-end apps, Microsoft says reviewers preferred MAI Code 2's output over GPT-6 Sol 67 percent of the time. One footnote matters: Microsoft says the cost figures use the models' 50 percent promotional price, so the gap will narrow once the promotion ends.

The coding pair is only part of the family. Microsoft also introduced MAI Cyber 2 Flash, which it calls its most capable security model, with 12 billion active parameters, offered to a limited group of customers as AI tools surface more software vulnerabilities. Microsoft-Decision-1.1, a small, fast model for the routine choices agents make, routing, flagging and verification, joins the lineup alongside new image-generation and transcription models. A tuned variant, MAI Work Flash, serves Microsoft 365 apps such as Word, Excel, PowerPoint and Teams, plus Fabric IQ. Enterprise customers will also be able to license model weights to customize with their own data, as long as they deploy on Azure.

Availability is broad from day one. MAI Code 2 is in GitHub Copilot for Pro, Pro+, Max, Business and Enterprise plans; MAI Code 2 Flash adds Free and Student, and is in limited-access preview in Microsoft Foundry. Microsoft says both models are coming to OpenRouter, Vercel, Hermes, OpenCode and Kilo. The company is also clear about the limits: the models are not yet tuned for the hardest problems, such as fundamental science research or very long-running agent tasks. Suleyman said the cybersecurity reckoning illustrated by OpenAI agents' hacking of the Hugging Face platform had pushed him to focus on safeguards, calling alignment his top priority.

## WHY IT MATTERSMicrosoft stops renting its best coding models

For years Microsoft's strongest coding offering ran on OpenAI's models, with the MAI line confined to a lightweight Flash tier. MAI Code 2 changes the structure: Microsoft now fields a general-purpose coder of its own, priced to undercut the frontier on the bulk of everyday work, debugging, multi-file changes and repo-wide reasoning, while keeping the premium models for the hardest tasks. The comparison targets are named, GPT-6.1 Sol and Claude Opus 5.5, which is the point: this is a direct challenge to the two labs Microsoft has partnered with and competed against at once.

The pricing is the strategy, not a side effect. A 50 percent promotional price underwrites the headline cost gaps, and Microsoft is explicit that the figures come from its own benchmarks, so independent testing will decide whether the claim survives contact with real codebases. But the direction is unmistakable: the company that owns the developer's editor is now also selling the model inside it, and the margin it used to pass to OpenAI stays in-house.

## WHAT TO WATCHSecurity is the second front, not an afterthought

MAI Cyber 2 Flash arrives in the same week the industry is still absorbing the OpenAI agent breaches, and Suleyman tied the two together in his Reuters interview, saying the Hugging Face incident pushed him to prioritize safeguards. A security model offered first to a limited group of customers is a controlled experiment, and its real test will be whether it catches the vulnerabilities that agentic coding tools are now surfacing faster than humans can review.

Watch three things next: whether independent benchmarks confirm Microsoft's 98 and 96 percent claims once the promotional pricing is stripped out; whether developers on the free and student tiers, who get Flash first, adopt it widely enough to move Copilot's default; and whether the licensable-weights offer pulls enterprises that want their own tuned models onto Azure. Rivals have already been warned: cheaper frontier-adjacent coding is now the price of staying in the race.

## SIGNAL JUDGMENT — ANALYSISThe editor now sells its own engine

Tokenta Signal's judgment: MAI Code 2 is Microsoft's most important model announcement since it started building its own AI, because it changes who captures the value of coding assistance. The company is no longer only the distribution channel for OpenAI's models; it is a model maker competing on price in its own editor, and the benchmark claims, if they hold up independently, make the expensive frontier models a harder sell for everyday work. The caveats are real and Microsoft states them itself: the cost figures rest on promotional pricing, the benchmarks are its own, and the models are not tuned for the hardest tasks. Even discounted for all of that, the direction is set. Expect OpenAI and Anthropic to answer on price, and expect the next round of this fight to be fought in independent benchmarks rather than launch slides.
