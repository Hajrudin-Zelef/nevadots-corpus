Microsoft's AI division (MAI) unveiled seven new models at its Ignite conference, released together rather than spread across the year. The lineup covers code, IT security, image editing, speech and workflow routing. Microsoft compares the models against OpenAI's and Anthropic's systems and stresses cost over raw capability.

According to Microsoft, MAI Code 2 averages 98 percent of GPT-6.1 Sol's performance across four benchmarks at 40 percent of the cost, and reaches 96 percent of Claude Opus 5.5's performance at 5 percent of the cost. Those figures use a promotional price that Microsoft says includes a 50 percent discount. MAI Cyber 2 Flash scores 92.3 percent on the CyberGym-E2E benchmark, slightly above GPT-6 Astra at 91.5 percent, and is listed at $0.10 per million input tokens against $10 for Astra.

Decision 1.1, a routing model built on Google's Gemma 4 26B A4B, returns calibrated confidence scores and can abstain when information is incomplete. Microsoft charges $0.042 per million input tokens for it, with output tokens free. MAI Realtime 1, a speech-to-speech model, is compatible with the OpenAI Realtime API, so existing voice apps can switch over.

## Why it matters if you build agents

Developers running always-on agents can compare these models on cost per task, and several are available now in GitHub Copilot, Foundry and OpenRouter. Teams with voice pipelines built on the OpenAI Realtime API could test MAI Realtime 1 without rewriting their integration. Promotional pricing for MAI Code 2 is time-limited, and MAI Cyber 2 Flash is restricted to Microsoft's security products and selected customers.
