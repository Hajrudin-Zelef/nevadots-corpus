NVIDIA and Microsoft are deepening their collaboration to advance artificial intelligence (AI) capabilities across cloud, local, and edge environments. Announced at Microsoft Ignite, the partnership introduces expanded access to NVIDIA technologies on Azure, enhanced customization tools for enterprise AI, and new deployment options for Windows PCs and industrial systems.

## Azure Powered by NVIDIA Vera Rubin NVL72 Systems

Microsoft Azure now supports NVIDIA Vera Rubin NVL72 systems, which are optimized for large-scale model training, inference, and agentic applications. These systems enable demanding AI workloads, including reasoning and data processing, while incorporating NVIDIA Confidential Computing to protect sensitive data and models. Azure’s infrastructure achieved notable performance benchmarks, scaling to 10,240 NVIDIA GPUs in MLPerf Training v6.1 and leading cloud submissions in MLPerf Inference v6.1 with over 10% higher throughput on the DeepSeek-R1 model, according to Signal65.

## Enterprise AI Customization Through Microsoft Foundry

The companies are expanding Microsoft Foundry’s capabilities to help enterprises customize and deploy AI models. Foundry’s Programmed Training offering allows developers to refine post-training workflows, while Foundry Managed Compute supports deploying custom model weights. For example, EY used these tools to adapt NVIDIA Nemotron open models for corporate purchasing classification, achieving a 55% accuracy improvement and reducing costs by 15x compared to proprietary models.

The Nemotron 3.5 lineup now includes specialized models for diverse applications. Nemotron Super supports long-running tasks, Lightning focuses on fast responses, and Embed and Rerank assist in information retrieval. Additional models, such as Nemotron Bolt for low-latency reasoning and Transcribe for speech recognition, are set to launch soon.

## AI Deployment Beyond the Cloud

To bring AI closer to enterprise data, NVIDIA and Microsoft are expanding support for local and edge deployments. Azure Local environments now support Nemotron 3.5 models and NVIDIA RTX PRO 6000 Blackwell GPUs, enabling on-premises AI operations. Additionally, NVIDIA Jetson platforms, including Thor and Orin, are being integrated for industrial applications like robotics and machine vision.

On Windows PCs, NVIDIA RTX Spark-powered devices will allow developers to run large language models locally. For organizations using Windows 365 Cloud PCs, GPU-accelerated Direct Stream capabilities are being introduced, supporting high-performance graphics applications with up to two 4K streams at 60 frames per second. A limited preview is currently available, with a public preview expected in early 2027.

## Scientific AI Advancements

In the scientific domain, NVIDIA BioNemo Agent Toolkit and ALCHEMI Toolkit are being integrated into Microsoft Discovery. These tools enable researchers to use natural language for workflows in computational biology, drug discovery, and materials science. An initial application involves the RFD4-Proteina model, developed with the University of Washington, to generate protein structures for laboratory validation.

## Accelerating Microsoft’s AI Services

Microsoft is leveraging NVIDIA technologies to enhance its own AI services. NVIDIA Dynamo inference software and RTX PRO 6000 Blackwell GPUs are being used to accelerate models for Bing search and other applications. This integration underscores the companies’ commitment to advancing AI capabilities across diverse platforms and industries.
