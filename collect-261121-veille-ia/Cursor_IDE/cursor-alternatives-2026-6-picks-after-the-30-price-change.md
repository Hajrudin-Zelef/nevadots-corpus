**Cursor’s $20 Pro plan is gone.** SpaceX’s purchase of Anysphere, Cursor’s maker, closed on 14 August 2026, and Cursor is now sold on the Grok ladder. The $8 Plus plan runs only Grok models. Premium costs $30, and Claude or GPT usage on it is billed separately at API list price.

## Quick Verdict

- **Most Claude and GPT credit for $10:** GitHub Copilot Pro ($15 of credits; Zed Pro has $5), or Business at $19 a seat with 1,900 credits per user.
- **Closest editor to Cursor for one developer:** Devin Desktop Pro at $20, a VS Code fork whose quota covers OpenAI, Anthropic and Google models.
- **Best if your team already pays for Claude:** Claude Code, included in every Claude Team seat ($25 monthly).
- **Stay on Cursor if** Grok models are enough, or you rely on cloud agents, Bugbot and Origin.

## Why People Leave Cursor

The Cursor pricing page changed in three ways.

**The cheap plan runs one vendor’s models.** Plus is $8 a month, and its own footnote says “only Grok models are available on this plan.”

**Premium doesn’t include third-party usage.** At $30 you get four times Plus usage of Grok, cloud agents, Bugbot code reviews and Origin code hosting. Claude, GPT and Gemini work in the editor, but the page says that usage “must be purchased separately” at API list price.

**Part of the bill buys social perks.** A premium X checkmark, a reply boost and ad-free scrolling: dead weight if you only wanted autocomplete.

## Six Alternatives, One by One

### GitHub Copilot: Claude and GPT included for $10

Copilot Pro costs $10 a month and includes $15 of GitHub AI Credits, which pay for agent mode, code review, Copilot in the cloud and the CLI. The plans page lists Claude Opus 5.5, GPT-6.1 and Gemini 4 models. Business is $19 a seat with 1,900 credits per user, pooled across the organisation, plus IP indemnity and budget controls. **Fits:** anyone who left Cursor because Claude and GPT stopped being included. **Limitation:** Copilot adds AI to editors you already run, with no dedicated agent editor like Cursor’s. ### Devin Desktop: the nearest editor for one developer

Devin Desktop, formerly Windsurf, is the other agent-first VS Code fork, so extensions carry over. Pro is $20 and its quota covers frontier models from OpenAI, Anthropic, Google and SpaceXAI, plus free use of Cognition’s SWE-2. **Fits:** a solo developer who wants Cursor’s workflow with multi-vendor models included, for $10 less than Premium. **Limitation:** Teams costs $80 a month plus $40 per developer seat, so five developers pay $280, more than Cursor’s $150. See our Devin Desktop alternatives guide. Visit Devin Desktop →

### Claude Code: included in every paid Claude plan

Pro is $20 a month, or $17 on annual billing. A Team standard seat is $25 a month ($20 annual) for teams of 2 to 150, and premium seats with five times the usage are $125. **Fits:** teams already buying Claude seats, where coding adds no new line item. **Limitation:** it runs Anthropic models only, and long agent sessions draw on the same limits as everyday chat. See Claude Code vs Cursor and our Claude Code listing. Visit Claude →

### Zed: reads a legacy Cursor rules file

Zed is an open-source editor built for speed and live multiplayer editing. Personal is free with your own API keys. Pro is $10 with $5 of hosted tokens, then usage at API list price plus 10%. Business is $30 a seat with org-wide model policies but no bundled credits. Its instructions docs list `.cursorrules` among the files it reads. **Fits:** developers who want to choose which model they pay for. **Limitation:** Zed isn’t a VS Code fork, so extensions and keybindings don’t transfer, and its pricing page says SSO, SAML and SCIM are not available yet. See our Zed listing. Visit Zed →

### Cline: no subscription, only inference

Cline is an open-source agent that runs as a VS Code extension and a CLI. The individual version has no subscription and no seat fee. You bring your own model key, or buy inference through Cline at cost. Enterprise (custom pricing) adds SSO and centralised billing. **Fits:** developers who would rather pay the model vendor directly than pay Cursor’s $30 on top. **Limitation:** nothing caps spend except the limits you set with your provider, so a long session on an expensive model is billed in full. See our Cline listing. Visit Cline →

### OpenHands: self-hosted agents, any model

OpenHands replaces Cursor’s cloud agents rather than its editor. Agent Canvas is MIT-licensed and free to self-host for a single user, with your own LLM key. Teams is $500 a month for up to 10 users, self-hosted, with SSO, role-based access and budgeting controls, capped at 5,000 sessions a month, with a 30-day trial. **Fits:** teams that want background coding agents on their own infrastructure. **Limitation:** the pricing page also shows “+$50/mo per seat” next to the 10-user cap without saying when it applies, so ask before budgeting. You also run the servers. See our OpenHands listing. Visit OpenHands →

## What You Lose in the Switch

**What goes:** Cursor’s cloud agents and automations, Bugbot reviews, code hosting via Origin and, on Teams, the marketplace for internal rules, skills and plugins. So do the Grok bundle and the X perks.

**What breaks first: your agent instructions.** Each tool reads its own files: `.github/copilot-instructions.md` for Copilot, `CLAUDE.md` for Claude Code, and Cline’s rules for Cline. Zed’s docs list a legacy `.cursorrules` file among the files it reads; check the others’ docs before assuming the same.

**What it costs to overlap.** We haven’t timed a migration. A five-person team keeping Cursor Teams for a month while trialling Copilot Business pays $150 + $95 = $245; with Claude Team, $150 + $125 = $275.

**Reversibility is high.** Code stays in Git and Cursor keeps a free tier, so you can come back.

## Who Should Switch, and Who Should Stay

**Switch if** you write most of your code with Claude or GPT. On Cursor that usage is billed on top of $30; on Copilot Pro, Devin Pro or Claude Pro it comes inside a $10 to $20 plan. Switch if you buy seats for a team of five or more and don’t use Cursor’s cloud agents: Copilot Business saves $55 a month at five seats and $110 at ten.

**Stay if** Grok models do the job, because Premium includes four times Plus usage and the cloud agents, Bugbot and Origin with it. Stay if you use Grok Chat or X anyway, since the bundle replaces those subscriptions.

## Final Verdict

Cursor changed what it sells: at $30 you buy a Grok subscription with an editor, cloud agents and X perks attached, and non-Grok models cost extra. For a developer who wants Claude or GPT, it’s the dearest individual plan here.

Solo developers should try Copilot Pro at $10, or Devin Desktop Pro at $20 to keep a VS Code fork. ## FAQ

### Does Cursor still have a $20 Pro plan?

No. On 7 November 2026 cursor.com/pricing lists Free, Plus at $8, Premium at $30, Super at $100 and Ultra at $200, with Teams from $30 a user. Plus runs only Grok models. On the paid plans, Claude, GPT and other third-party model usage is billed separately at API list price.

### What is the cheapest Cursor alternative with Claude and GPT models?

GitHub Copilot Pro and Zed Pro, both $10 a month. Copilot includes $15 of AI credits for Claude, GPT and Gemini models; Zed includes $5 of tokens. For teams, Copilot Business is $19 a seat with 1,900 credits per user. Cline has no seat fee; you pay the model vendor per token.

### Who owns Cursor now?

SpaceX. Its Form 8-K reports the merger with Anysphere, Cursor’s maker, effective on 14 August 2026, after an agreement signed on 16 June. Cursor is now sold on one ladder with Grok and X.

### Can I move my Cursor rules to another tool?

Partly. Zed’s documentation says it reads a legacy .cursorrules file. Copilot uses .github/copilot-instructions.md and Claude Code reads CLAUDE.md, so for those you copy the text into the new format by hand. Your code stays in Git either way, unless you moved repositories onto Cursor’s Origin hosting.
