# Cursor Projects is now multiplayer

Cursor rebuilt Projects for multiplayer, so you can invite teammates into a Project and plan, build and ship together alongside everyone's agents.

Projects arrived in September as a way for one engineer to direct a fleet of agents through a single coordinator. In a shared Project, each teammate still has a one-to-one chat with their own coordinator and worker agents, and that chat runs and bills as them. A shared task board shows who is doing what, what everyone's agents are working on, and the PR behind each task. Shared context holds requirements docs, diagrams, tech specs and mockups, so a decision made in one chat is available to every agent, and a newly invited teammate starts with that context in place.

Coordinators can also message each other. Those messages are labeled as agent input and treated as untrusted. They open a side chat you can read, stop or archive but not message, and it never shares secrets, credentials or tokens.

It's rolling out in beta. Projects need a plan that includes Cloud Agents, which means Premium and higher, Teams, Enterprise and legacy paid plans, not Free or Plus. Sharing a Project requires a team account and Cursor 3.26.13 or later, and only people on that Cursor team with access to the Project's repository can join.
