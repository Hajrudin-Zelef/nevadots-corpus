# Anysphere: *Voice Chat with Agents*

Cursor added voice chat with agents on November 6, 2026. Here is how the new feature works, where to find it, and what it means for your work.

**Cursor now lets you talk with your agents in a realtime voice call, and the feature arrived on November 6, 2026.** You can describe a change out loud, ask what an agent is doing, and hear updates as the work moves forward, according to the Cursor changelog.

## What changed

Voice chat is a two-way conversation. The voice agent listens, replies, and hands coding work to the agent in your chat. You can keep talking while that agent runs, ask what changed in a diff, check on a run, search earlier messages and calls, or switch between workers in a Project.

The coding agent also speaks up on its own. While it works, it gives short spoken progress notes, and when it finishes you usually hear a short update instead of the full written reply.

Voice chat works in the Agents Window, the IDE, on web, and in Cursor for iOS. It runs on Grok Voice, and you can pick from several voices in Voice settings, including Ara, Eve, Leo, Rex, and Sal. With Privacy Mode on, voice chat runs with zero data retention.

This is separate from dictation, which earlier releases called Voice Mode. Dictation still turns speech into text in the chat input, and Cmd+Shift+Space still toggles it in the IDE.

## What this means for you

Instead of typing every instruction, you can now explain a change the way you would to a coworker and hear a spoken answer back. On iOS, you can start a call with a new agent by asking Siri to call Cursor, and you can mute or end the call from the Lock Screen through a Live Activity.

If you only ever use dictation, nothing changes for you. That feature works the same as before.

## How to try it

Update Cursor first, then look for the waveform button labeled Start voice chat. It appears when the agent is idle and the chat input is empty, sitting where Send usually is, next to the microphone button for dictation. Details are in the changelog post.

## What it costs

As of November 5, 2026, the pricing page lists Grok Chat, Voice, Imagine, and Build under AI features on the Plus plan at $8 /month, and the Free plan shows limited AI usage. Every tier includes a pool of AI usage shared across Cursor and Grok, and within Grok the pool covers Chat, Imagine, Voice, and Bot. The allowance refreshes weekly.

## Questions people ask

### Can I talk to a Cursor agent out loud?

Yes. Cursor added a voice chat feature on November 6, 2026. You can speak with an agent in a realtime call, and the agent can answer back in spoken words while it works on your code.

### Where does Cursor voice chat work?

According to the changelog, voice chat works in the Agents Window, in the IDE, on the web, and in Cursor for iOS. You start a call from the waveform button in the chat input.

### Is voice chat the same as dictation in Cursor?

No. Dictation turns your speech into text in the chat input, and Cmd+Shift+Space still toggles it in the IDE. Voice chat is a two-way call where the agent replies out loud.

### Does Cursor voice chat cost extra?

As of November 5, 2026, the Cursor pricing page lists Grok Chat, Voice, Imagine, and Build under AI features on the Plus plan at $8 /month. Every tier includes a pool of AI usage shared across Cursor and Grok, and the allowance refreshes weekly.

### Is my voice data kept when I use voice chat?

If you turn on Privacy Mode, Cursor says voice chat runs with zero data retention. The pricing page also states that Privacy Mode keeps your code data out of training.

### How do I start a voice chat on iPhone?

On iOS you can ask Siri to call Cursor to open a call with a new agent. You can also mute or end the call from the Lock Screen using a Live Activity.
