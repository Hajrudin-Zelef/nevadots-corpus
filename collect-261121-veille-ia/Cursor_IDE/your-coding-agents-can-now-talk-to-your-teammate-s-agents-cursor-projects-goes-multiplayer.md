# Your coding agents can now talk to your teammate's agents: Cursor Projects goes multiplayer

Cursor rebuilt Projects, its system for directing a fleet of cloud agents through one coordinator, so a whole team can work in the same Project. Each teammate keeps their own chat with their own coordinator and worker agents, but everyone shares a task board showing who and which agent is on each task, plus a shared context store for specs, diagrams and decisions. When two people's work overlaps, their coordinators message each other directly and agree on the order of work, and in-progress tasks can be handed to a teammate's agent.

## Why it matters

Merge conflicts and duplicated work usually show up at the end. Here agents spot overlap while the work is still being planned, and new teammates join with context already set up.

## Who it's for

Engineering teams on Cursor who already use cloud agents or Projects for bigger features and migrations.

## How to try it

1. Update Cursor, open the Agents Window and create a Project from the left-hand nav.
2. Use the Project's menu to invite teammates; they click Accept Invite and get their own coordinator chat.
3. Put specs and decisions in the shared Context so every member's agents read the same requirements.
4. Watch the task board, and review side chats titled 'Chat with {name}'s agent' to see what the coordinators agreed.

**Plan & availability:** Rolling out in beta to all Cursor users from November 10, 2026. Sharing a Project needs a Cursor team account and Cursor 3.26.13 or later; people on personal accounts or other teams can't join. Each member's chat runs and bills as that member. Messages from another teammate's agent are treated as untrusted input. Checked on cursor.com on November 11, 2026.
