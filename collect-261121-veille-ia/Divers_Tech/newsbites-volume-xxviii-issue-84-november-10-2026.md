Three security issues affecting Anthropic's Claude AI tools and features have been reported in the last week, none of which the company has addressed at the time of this writing. **Claude Dispatch** is a tool allowing users to send instructions to Claude Desktop via phone or browser. On November 4, Gal Weizman with Forever Security published research revealing that any browser extension that can control Claude Dispatch could cause Claude Desktop to run code on the local machine, or "even a different machine signed into the same Claude account." Weizman describes a possible scenario in which "an employee signs into their personal Claude account on a work laptop. A malicious extension on their home browser now runs code on your corporate endpoint," effectively escalating privileges and allowing cross-machine remote code execution (RCE). Anthropic acknowledged the issue as valid when Weizman reported it in May 2026, confirming that it was already known internally, but did not take further action. Weizman notes that while Anthropic aimed to retire Dispatch by the end of October 2026, the underlying design principle causing this issue — an authenticated web session allowed to control a local agent — is still present elsewhere, such as in Claude Code Remote Control and Claude Cowork. Agentic coding tool **Claude Code** leaked over 2,500 secrets in nearly 2,000 public GitHub repositories due to how the program stores a user's configuration preferences, according to researchers at Apiiro. Claude Code will prompt a user to approve an automated shell command, including a "Yes, and don't ask again" option; if this is selected, a local settings .json file stores not only the response but also the command in question and any sensitive information it contains. Apiiro found database passwords, cloud keys, API tokens, SSH root logins, and other secrets exposed. The researchers give instructions for developers and security teams to address exposure and impact, and mentions responses from Boris Cherny, Head of Claude Code, expressing interest in prototyping fixes. Official **Claude skills for handling Microsoft Office document formats** can be abused "to execute malicious code on a user's Linux machine by exploiting an unverified file path used during document conversion," according to Air Security. When Unix sockets are blocked for any reason, a helper script loads a shim library from a fixed path in order to run LibreOffice; an attacker can substitute a malicious file at that location to make the skill run code on Linux systems. Air Security reported the vulnerability to Anthropic, who deemed it "outside [Anthropic's] security boundary, since the vulnerable code only runs inside a sandbox." 

Blockchain data and analytics company Chainalysis has disclosed that it experienced a cybersecurity incident. On Friday, October 30, 2026, the company emailed affected customers, informing them that in October 2026, "Chainalysis detected an external actor using offensive agentic techniques to gain unauthorized access to Chainalysis systems and internal tools." Compromised information includes "non-sensitive customer data, such as user IDs, full names, email addresses, and organization role labels for users provisioned on [the Chainalysis] platform." In a Monday, November 2 update, Chainalysis said it had "proactively taken certain products offline, including Reactor and Data Solutions, and [is] working alongside ... third-party cybersecurity experts to complete additional security assessments before restoring service." Subsequent updates on November 4 revealed that the incident included "an 'on-path attack' [that] exposed a subset of customer passwords" and that affected individuals were notified by email. Anomalous activity led Chainalysis to "[take] KYT (the user interface and API) offline alongside other address screening products and the login page." As of Saturday, November 7, Chainalysis has restored access to Reactor, KYT (UI and API), and Address Screening.

Certificate Authority DigiCert has posted an incident report on Bugzilla regarding "unauthorized access to an internal business system which is used to archive information provided by customers." In February 2025, DigiCert moved an "internal business system … from a VPN-restricted network segment to a different availability zone." The Register writes that "the archive used the same account management platform as DigiCert's customer-facing products, including a self-registration feature that was never supposed to be available on the internal system. This allowed outsiders to create accounts without multifactor authentication, and thanks to a separate permissions flaw, allowed use of the accounts to browse archived customer records." DigiCert became aware of the issue in June 2026 and fixed the problem the following month. In October 2026, "DigiCert confirmed unauthorized access to a subset of archived data." The compromised information includes names, email addresses, phone numbers, addresses associated with business customers; in some cases, documents used as identity verification, including driver's licenses, passports, and utility bills, were also compromised. The incident did not affect any certificates, nor were any "certificates were issued, modified, or revoked as a result of this incident."

On Monday, November 9, Apple released out-of-cycle security updates that address vulnerabilities across iOS and iPadOS 27.2.1, 26.7.3, and 18.7.12; macOS Golden Gate 27.2.1, Tahoe 26.7.2, and Sequoia 15.8.3; watchOS 27.2.1 and 26.6.1; and visionOS 27.2.1. Five of the flaws affect components in all nine OS versions: One high-severity flaw in Bluetooth allows an attacker to corrupt process memory (CVE-2026-113970); two medium-severity flaws in CoreUtils would allow an attacker to establish Bluetooth pairing without user interaction (CVE-2026-113964 and CVE-2026-113965); one medium-severity flaw in AirPlay allows an attacker in Bluetooth range to bypass the rate limit on pairing code attempts (CVE-2026-113968); and one flaw in rapportd allows an attacker on the same network to bypass the rate limit on AirPlay pairing code attempts (CVE-2026-113969, CVSS score not yet assigned). Two flaws in Messages are addressed in the updates for iOS and iPad OS 26 & 27, for all three updated macOS versions, and for watchOS 27: One high-severity flaw allows a remote attacker to join an iMessage group chat and receive its messages (CVE-2026-113961), and another flaw allows a user added to an iMessage group to access messages that were sent before the user joined (CVE-2026-113960, CVSS score not yet assigned). One medium-severity flaw in App Intents affects version 27 of iOS, iPadOS, watchOS, and visionOS, allowing an app to access sensitive user data (CVE-2026-113963). The last flaw is low-severity and affects MediaRemote in iOS and iPadOS 18, allowing an attacker with physical access to pair a device with an AirPlay receiver from the lock screen (CVE-2026-113971). The recent critical buffer overflow vulnerability in the brotli compression library (CVE-2026-111497, described in NB 28.80) was also addressed in the updates for iOS, iPadOS 26 & 27, all three updated macOS versions, and watchOS and visionOS 27.

A critical authentication bypass vulnerability in OpenSSH allows attackers to access privileged accounts on musl-based Linux systems. The vulnerability (CVE-2026-123158, CVSS score 8.1), which was disclosed on Thursday, November 5, lets "an oversized password authenticate to accounts configured to reject password logins." Successful exploitation requires certain conditions on the targeted system: According to NIST's NVD listing, "sshd in OpenSSH before 10.6p2 on Linux, when musl libc is used without PAM, lacks a workaround for a password authentication bypass (related to misinterpretation of whether a string is intended to be a password hash). For some configurations of accounts, any password between 256 and 1024 characters succeeds." Researchers at watchTowr, GreyNoise, Previdian, and other firms are now reporting that the flaw is being actively exploited; researchers at GreyNoise write that CVE-2026-123158 "is trivial to exploit and working exploits are publicly available."

Microsoft's Azure Linux version 3.0.20261105 was released on November 6, 2026, including about 470 security fixes that address 272 unique CVEs. This includes hardening of certificate trust, specifically mentioning measures that follow from the removal and distrust of "root certificates that could validate compromised eMudhra intermediate certificates," which had been issued with trivially weak private keys (described in NB 28.79). Intermediate-certificate rejection was added to Python and Go, SSL.com TLS trust was preserved where needed, and Microsoft trusted root certificates were refreshed. 28 of the flaws mentioned are critical, and an upgrade to Ruby to 3.3.13 addresses the four most severe, which are remote code execution vulnerabilities in GitLab CE/EE, two carrying CVSS score 10.0 (CVE-2026-97229 and CVE-2026-110264, both described in previous issues of NewsBites) and two carrying CVSS score 9.9 (CVE-2026-89078 and CVE-2026-93577). The next most severe is a CVSS 9.8 flaw in libcurl allowing an attacker to send a request over another user's previously authenticated connection due to improper reuse of an HTTP connection setup for a given hostname using Negotiate authentication (CVE-2026-19931).

On Friday, November 6, Japan rolled out a set of emergency cybersecurity measures in response to recent cyberattacks targeting Japanese organizations. "The package is built around four pillars: ensuring the thorough implementation of basic cyberdefense measures through the use of artificial intelligence; strengthening information gathering and sharing as well as investigative and analytical capabilities; strategically responding to cyberattacks; and enhancing support for victims and measures to prevent further damage." The government will establish teams to help implement the measures: A "top gun" team will work against hackers, implement AI to find vulnerabilities, and work with foreign companies and AI developers to keep vulnerability intelligence up to date; a "rescue team" will comprise public and private-sector experts to help organizations manage their initial responses to cyber incidents; and a third team will advise companies on cybersecurity practices. The government also indicated its intent to "strengthen ... its own capability to carry out an Active Cyber Defense (ACD)." Japan has an ACD framework in place, and one element of that framework "allows the police and the Self-Defense Forces to infiltrate computers used by attackers and disable their ability to carry out cyberattacks." The GMO Internet Group Inc., which was recently the victim of a ransomware attack, made a public request for the government to help address the rising tide of cyberattacks, noting that "We believe that this is an extremely important opportunity to ensure that the Proactive Cyber Defense Act, which was just enacted on October 1st, functions as a living, breathing system that protects the property of the people."

Following a series of attacks against industrial cooling systems over the past several weeks, the US Cybersecurity and Infrastructure Security Agency (CISA), Federal Bureau of Investigation (FBI), Department of Health and Human Services (HHS), Department of Agriculture (USDA), and Department of Transportation (DoT) have jointly issued a fact sheet urging organizations in the Healthcare and Public Health, Chemical, Food and Agriculture, and Transportation Systems Sectors to harden industrial refrigeration and cold chain monitoring systems. The fact sheet described the vectors through which threat actors have exploited the vulnerabilities, including authentication bypass, arbitrary code injection, and weak configurations, and the damage those attacks have the potential to cause, including loss of inventory, shortened service life of the systems, and loss of visibility into current system temperatures. Operators are urged to remove these systems from the public internet and take other steps to strengthen their cybersecurity. Attacks with details in common have targeted refrigeration and freezer systems at supermarkets in multiple European countries, several sites that store blood and plasma in France, and refrigeration and freezer systems at commissaries and grocery stores on US military bases.

A ransomware attack has disrupted the systems and services of the Queens Public Library (QPL) in New York City. QPL warned of the disruption via social media and directly to patrons starting on Wednesday, November 4, and while all 66 library locations have remained open through the disruption, the QPL website, mobile app, public computers and printing at some locations, digital media services, and certain virtual and in-person programs have been impacted. Services that have already been restored include the public computers at Central Library, Far Rockaway, Flushing, Glen Oaks, Hunters Point, Jackson Heights, and Kew Gardens Hills, the check-out and return machines, and free Wi-Fi access at all locations. Books can still be borrowed and returned, but renewals are unavailable. QPL encourages patrons to check on the status of services via social media and by local branch, and offers a customer service phone line. QPL CEO Dennis Walcott stated to news sources that the library is working with the New York Police Department and the FBI, and that investigation is ongoing; the official notice cautions patrons that full restoration will take some time.

In documents submitted to the Indiana State Attorney General's Office, **Frontline Education**, a provider of administration software purpose-built for K-12 schools, disclosed that an August breach of its system affected personal information of more than three million individuals. The intruders gained access to Frontline's system through a vulnerability in a third-party software product. The compromised data include name, Social Security number, date of birth, driver’s license number, passport and other government ID number, health insurance information, and student IDs of school district employees and students at school districts that use Frontline Central and School Health Management products. Frontline has notified affected districts and has begun notifying affected individuals. **York University** in Toronto has disclosed a data security breach that resulted in the theft of information submitted through online forms on multiple university websites between 2007 and 2026. Compromised data include academic history, citizenship/origin, date of birth, diet and allergy information, disability/accommodation status, email address, Family/third-party contact, Employment history, financial status, gender/sex, health information, images/photos, Indigenous status, Legal/criminal background, Phone number, Race/ethnicity, sexual orientation, street address, and York identification number. The university is notifying affected individuals. On Monday, November 9, **Vanderbilt University** in Nashville, Tennessee, disclosed an active "cybersecurity incident affecting university devices, systems and cloud-based services." The university has asked "all members of the university community to shut down university devices, disconnect from university WiFi, and remain extremely vigilant." As of 7:15 pm US Central Time, Vanderbilt says that while campus Wi-Fi is once again available, most university systems and applications are still restricted. Classes have continued uninterrupted. Attackers have stolen passwords for all individuals registered with **Technical University of Munich's (TUM)** myTUM portal. The breach was disclosed on Friday, November 6. A compromised admin account was subsequently used to attack TUMonline, TUM's central campus management system. TUM notes that users who had activated multifactor authentication (MFA) on their accounts were unaffected by the incident. As of Monday, November 9, TUMonline is operational; users are required to change their passwords and set up MFA.

Iris Ohyama is an online shopping site based in Sendai City, Japan. It has been taken offline following a breach that may have compromised information of as many as 7.7 million individuals. In an October 29 statement, the company writes that it "discovered a suspicious file in an external cloud service it uses on October 28, 2026," and confirms that it had detected unauthorized access to the e-commerce site. An additional report from the company on November 5 discloses that the company "determined that some personal information may have been leaked." The compromised data include name, address, phone number, gender, email address, date of birth, and password. The incident has been reported to police and to the Personal Information Protection Commission. Customers are being advised to change their passwords and be vigilant for attempts to use the compromised information to conduct phishing attacks.

**SANS Internet Storm Center StormCast Tuesday, November 10, 2026**

SAP NetWeaver Webshells (CVE-2025-31324); N-able N-central Offline; Chrome XML 0-Day (CVE-2026-125350); Outlook DMARC Required

**Today's episode** covers attackers hunting SAP NetWeaver webshells from CVE-2025-31324, N-able taking N-central offline after dozens of unpatched flaws, a Chrome XML use-after-free zero-day, and Outlook rejecting mail without DMARC.

**Attackers Searching for SAP NetWeaver Webshells**

ISC honeypots are seeing probes for ant.jsp and related paths tied to SAP NetWeaver CVE-2025-31324, a CVSS 10 unauthenticated file-upload flaw attackers still use to plant webshells even after recent patches. Watch /irj/servlet_jsp/irj/root/ and other upload endpoints for leftover shells.

**N-able N-central Critical Security Incident**

N-able took Hosted N-central offline after public disclosure of roughly 30+ critical vulnerabilities with no patches yet, and advises on-premises customers to take servers offline if not isolated; no exploitation observed so far, with remediation said to be on track.

**Google Chrome Zero-Day Patch (CVE-2026-125350)**

Chrome stable updates fix nine vulnerabilities, including CVE-2026-125350, a use-after-free in the XML parser that Google says is already exploited in the wild. Update promptly; the advisory does not confirm a sandbox escape.

**Strict Outlook DMARC Policies**

Outlook is rejecting mail with 550 errors when the sending domain lacks a DMARC record, even if SPF and DKIM pass. Publish at least a DMARC record (for example p=none) alongside SPF and DKIM.

**SANS Internet Storm Center StormCast Monday, November 9, 2026**

sshole Scans (CVE-2026-123158); SonicWall SonicOS MFA Bypass (CVE-2026-19868); Entra Device Registration (CVE-2026-109469); Claude Code Secrets Leak

**In today's episode**, ISC honeypots seeing sshole (CVE-2026-123158) exploitation attempts; SonicWall patches seven SonicOS flaws including an already-exploited SSL VPN MFA bypass; Microsoft cloud-fixed an Entra Device Registration elevation-of-privilege bug; Apiiro found Claude Code saving secrets into .claude/settings.local[.]json on GitHub.

**Scans for sshole Vulnerability (CVE-2026-123158)**

ISC honeypots are seeing long letter-A passwords that look like sshole exploitation, with clear attempts starting November 5th after earlier long passwords that were mostly buggy brute-force scripts dumping shell commands into the password field. Honeypots only keep the first 255 characters of each password, which limits what can be measured.

**SonicWall SonicOS Multiple Vulnerabilities (SNWLID-2026-0014)**

On Friday SonicWall released patches for seven SonicOS vulnerabilities; one already-exploited flaw lets attackers bypass multi-factor authentication for SSL VPN logins when an alternate authentication method without MFA is also defined. Patch promptly—press and CISA associate the exploited issue with CVE-2026-19868.

**Entra Device Registration Elevation of Privilege (CVE-2026-109469)**

Microsoft patched an authorization bypass in Entra Device Registration over the weekend that could let an unauthorized attacker elevate privileges. No customer action is required: it is a Microsoft-hosted cloud service, and Microsoft says there was no exploitation at the time of the fix and rates future exploitation less likely.

**Claude Code Leaking Secrets on GitHub**

Apiiro reports that Anthropic's Claude Code can store credentials in .claude/settings.local.json when you tell it not to ask again about an API or command, and that on the order of a thousand-plus of those credential files have shown up on GitHub. ISC web honeypots also saw new requests for the .claude directory this weekend; rotate exposed secrets and watch for Anthropic updates.
