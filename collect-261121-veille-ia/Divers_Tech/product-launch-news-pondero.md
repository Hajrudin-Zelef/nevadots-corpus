## Microsoft folds Azure Migrate into Azure Catalyst, puts GitHub Copilot in the migration loop

At Ignite 2026, Microsoft merged Azure Migrate and GitHub Copilot's app-modernization tooling into one agent-led product called Azure Catalyst, betting legacy code is the real blocker to enterprise AI adoption.
