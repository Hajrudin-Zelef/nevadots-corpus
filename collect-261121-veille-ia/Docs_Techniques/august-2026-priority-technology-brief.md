What matters most

## Security updates and support deadlines lead this month

August delivered important browser, mobile, desktop and Linux security fixes. Microsoft customers also have October support deadlines approaching. Most people do not need to replace working technology today, but they should install supported updates, confirm device versions and identify systems that need an upgrade plan.

The briefing

## Four technology ecosystems worth checking

Each section separates confirmed changes from announcements or previews and explains the practical response for individuals and small businesses.

### Google: update Chrome and verify Android’s patch level

#### What changed

Google’s late-August Chrome 152 desktop release included 327 security fixes. The corresponding Android release carries the same Chrome security fixes unless Google notes otherwise.

Google’s August Android bulletin says a security patch level of **2026-08-05 or later** addresses all issues covered by the month’s bulletin.

#### What you should do

- In Chrome, open **Menu → Help → About Google Chrome** , allow the update to finish and restart the browser.
- On Android, check **Settings → About phone → Android version** and review the Android security update date.
- If a supported phone remains far behind, contact the manufacturer or begin planning a supported replacement.

**Official sources:** Chrome desktop security release August Android security bulletin

### Google Search completed a global spam update

#### What changed

Google’s August 2026 spam update ran from August 18 through August 21 and applied globally across all languages. This matters mainly to businesses, publishers and organizations that rely on Google Search traffic.

#### What businesses should do

- Compare search performance before and after the rollout by page and query—not only by total traffic.
- Review thin, copied, misleading or mass-produced content before changing strong pages.
- Do not treat a few days of normal ranking movement as proof of a penalty.

**Official source:** Google Search Status Dashboard

### Microsoft: install August updates and prepare for October 13

#### What changed

Microsoft released its August 11 security update for supported Windows 11 versions and recommends prompt installation. Two support deadlines are also approaching on **October 13, 2026**: Windows 11 version 24H2 Home and Pro reaches end of updates, and Office 2021 reaches end of support.

Microsoft says Windows 11 version 26H1 is intended for select new hardware and is not an in-place feature update for existing 24H2 or 25H2 computers.

#### What you should do

- Open **Settings → Windows Update** , install the August security update and restart.
- Check **Settings → System → About** . If a Home or Pro PC is still on 24H2, move to a supported version before October 13.
- Inventory Office 2021 installations and choose Microsoft 365 or another supported office suite before support ends.
- Do not force-install Windows 11 26H1 on an existing PC; use the supported update path offered to that device.

**Official sources:** August Windows 11 security update Microsoft products ending support in 2026 Windows 11 release information

### Apple and Mac: August fixes address image, kernel and web risks

#### What changed

Apple released iOS and iPadOS 26.6.1, macOS Tahoe 26.6.2 and Safari 26.6.1 in mid-August. Apple’s advisories include fixes for an image-processing flaw that could allow arbitrary code execution, kernel issues and multiple WebKit problems.

Apple also lists iOS and iPadOS 18.7.10 for certain older supported devices. Apple did not describe these August issues as known to be actively exploited.

#### What you should do

- On iPhone or iPad, open **Settings → General → Software Update** .
- On Mac, open **System Settings → General → Software Update** .
- Update Safari on supported Sonoma or Sequoia Macs even if the Mac is not yet moving to Tahoe.
- Back up important files before a major operating-system upgrade; routine security updates should still be installed promptly.

**Official sources:** Apple security releases iOS and iPadOS 26.6.1 security content macOS Tahoe 26.6.2 security content

### Linux: use distribution updates—not a manual kernel jump

#### What changed

Linux security work continues across supported kernel branches and distribution packages. On August 31, Ubuntu published fixes including OpenZFS and UDisks vulnerabilities that could allow programs to run with administrator privileges, along with updates for OpenSSL, MySQL, libssh, BIND and other packages.

Kernel.org lists Linux 7.2.2 as the latest stable upstream kernel and maintains several long-term branches. That does **not** mean every Linux computer should install the upstream kernel directly.

#### What you should do

- Use Ubuntu Software, Discover, GNOME Software or your distribution’s normal package manager to install supported updates.
- Restart after kernel, OpenSSL or other core-library updates when the updater requests it.
- For servers, review affected services, schedule a maintenance window and confirm they restarted successfully.
- Stay on the kernel supplied by Ubuntu, Debian, Fedora, Red Hat or your hardware vendor unless you have a tested technical reason to change it.

**Official sources:** Ubuntu Security Notices Linux Kernel Archives Red Hat security updates

Christina’s takeaway

## Update first, then plan the systems approaching support deadlines

The best response this month is straightforward: keep browsers and operating systems current, verify that mobile devices are receiving security patches, and identify Microsoft products that need attention before October 13. A calm inventory and tested upgrade plan is more valuable than chasing every new feature announcement.

### What Computer Technologies recommends this week

1. Update and restart Chrome on every regularly used computer.
2. Install the August Windows, Apple and Linux security updates.
3. Check the Android security patch date on phones used for email or business access.
4. Identify Windows 11 24H2 Home/Pro and Office 2021 installations before the October 13 deadline.
5. Back up important data before major operating-system changes.
