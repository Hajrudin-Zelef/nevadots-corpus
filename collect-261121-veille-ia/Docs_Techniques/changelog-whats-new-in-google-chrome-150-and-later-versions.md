## What’s New in Google Chrome 150.0

Google Chrome 150.0 version was released to **Early Stable** channel on **June 17, 2026** and **Stable** channel on **June 30, 2026**. It came with following new features, changes, fixes and improvements:

- **New WebUI Refresh 2026 Visual Update:** Chrome 150.0 version now comes with a modern and refreshing UI to reduce clutter. The first wave of UI updates include redesigned icons, updated button animations, simplified context menus (right-click menus) and color tweaks to built-in pages such as Settings, Downloads, and Bookmark.
- **Always Use Secure Connections (HTTPS) by Default:** If the user has opted in to “Enhanced Safe Browsing” protections in Chrome, the “Always use secure connections” feature will be enabled by default. Starting with Chrome 154, the “Always use secure connections” setting will be enabled by default for public sites only mode. Admins can use the`HttpAllowlist` and`HttpsOnlyMode` policies to override this behavior. Users can also disable the default “Always Use Secure Connections” feature using`--disable-features=HttpsFirstBalancedModeAutoEnable` command-line parameter.
- **Gemini Spark Integration:** In Chrome 150, users will be able to connect their browser to Gemini Spark to allow the AI agent to complete tasks using the active browser session. Admins can use`GeminiSparkSettings` policy to modify the behavior. (**How-to Disable Guide** )
- Security fixes
- Bug fixes and improvements
- New group policies implemented

## What’s New in Google Chrome 151.0

Google Chrome 151.0 version was released to **Early Stable** channel on **July 15, 2026** and **Stable** channel on **July 29, 2026**. It came with following new features, changes, fixes and improvements:

- **Bookmark Bar Auto-Hide on New Tab Page:** If bookmark bar is not being used frequently, it’ll auto-remove from the New Tab Page (NTP). Chrome will show a notification to the user to restore the bookmark bar. Users can change the bookmark bar visibility using Chrome Settings -> Appearance page or by right-clicking on the bookmark bar. (**How-to Enable Guide** )
- **AI Chat Button in Address bar and New Tab Page Search box:** If the user’s preferred default search engine is supported by Chrome, the omnibox (address bar) now displays an AI chat button. Users can control this feature using`ThirdPartyAiChatSettings` policy.
- Safe browsing protections now also work when using Gemini in Chrome.
- macOS 12 is no longer supported. Chrome will continue working on macOS 12 but it’ll not receive any update and a warning infobar will be displayed to alert the user.
- Security fixes
- Bug fixes and improvements
- New group policies implemented

## What’s New in Google Chrome 152.0

Google Chrome 152.0 version was released to **Early Stable** channel on **August 12, 2026** and **Stable** channel on **August 25, 2026**. It came with following new features, changes, fixes and improvements:

- **Process Isolation:** A new security feature that utilizes Access Control Lists (ACLs) functionality present in Windows 10 and Windows 11 operating systems to safeguard Chrome’s memory from unauthorized access and keep user’s personal data secure. (**How-to Enable/Disable Guide** )
- Security fixes
- Bug fixes and improvements
- New group policies implemented

## What’s New in Google Chrome 153.0

Google Chrome 153.0 version was released to **Early Stable** channel on **August 26, 2026** and **Stable** channel on **September 08, 2026**. It came with following new features, changes, fixes and improvements:

- Starting with Chrome 153, Chrome is moving to a 2-week release cycle, from the current 4-week cycle.
- The browser history page now also shows a chronological record of Gemini AI actions such as autobrowse, Gemini Spark, etc.
- Security fixes
- Bug fixes and improvements
- New group policies implemented

## What’s New in Google Chrome 154.0

Google Chrome 154.0 version was released to **Early Stable** channel on **September 09, 2026** and **Stable** channel on **September 22, 2026**. It came with following new features, changes, fixes and improvements:

- **Try on You:** A new AI-powered feature that allows users to virtually try on clothes found on websites and provides shopping insights in Gemini.
- Users can now sign-in using their work or school accounts on their personal Windows device and it’ll not be treated as enterprise-managed device.
- Security fixes
- Bug fixes and improvements
- New group policies implemented

## What’s New in Google Chrome 155.0

Google Chrome 155.0 version was released to **Early Stable** channel on **September 23, 2026** and **Stable** channel on **October 06, 2026**. It came with following new features, changes, fixes and improvements:

- UI Improvements to the new profile creation flows. (**How-to Enable/Disable Guide** )
- Extensions can now prompt users to review and rate them on Chrome web store. Users can disable the feature using `ExtensionReviewPromptsEnabled` policy.
- “Always use secure connections” option is now enabled in public sites only mode by default.
- Security fixes
- Bug fixes and improvements
- New group policies implemented
