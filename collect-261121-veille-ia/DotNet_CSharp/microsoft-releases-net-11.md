Microsoft announced the release of .NET 11 at its .NET Conf 2026 virtual conference today, with improvements across C# 15, ASP.NET Core, .NET MAUI, and Windows development.

“This year’s release makes building modern applications faster, more productive,” the .NET team writes. “With hundreds of runtime optimizations, more responsive SDK tooling, and less overhead in everyday commands, you can spend less time waiting and more time creating. Build richer web and cross-platform applications, take advantage of new C# language features, and explore AI-powered development with improved tools and agentic capabilities.”
