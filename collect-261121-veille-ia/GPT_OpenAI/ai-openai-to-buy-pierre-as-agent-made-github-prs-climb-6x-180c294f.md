OpenAI announced at 14:30 UTC on 4 November that it will acquire Pierre Computer Company, the company behind the Code Storage git service, after Axios reported the deal in an exclusive at 11:29 UTC. “If you’ve browsed files or reviewed a change in the Codex app, you’ve already used Pierre’s Trees and Diffs libraries”, OpenAI wrote.

Financial terms were not disclosed, Axios reported, and OpenAI’s post gives no price. Both say Pierre’s open-source projects will remain open-source.
The deal lands one week after Microsoft said on its earnings call that agent-generated pull requests on GitHub “have increased 6X over the past six months”, and that “agents now open more than a third of all PRs on the platform”.

What Pierre Sells
Pierre describes itself on its own site as “a software company that produces low level, composable product infrastructure for machine work”. Its product is Code Storage, which it says “powers the largest agentic workloads in the industry to store code and other machine generated artifacts at scale using git”.
The Code Storage page names Lovable, Poke, Anything, Bolt, Amp and Parahelp among customers that “rely on Code.Storage to store their generated code, memory files, design artifacts, legal documents, and other product files”. It lists a repository size limit of 32TB and git request rates it has “Seen: 500+/s/repo”.
According to Axios, OpenAI plans to integrate Pierre’s Code Storage function into Codex. OpenAI’s post says “Customers can continue using Code Storage after the acquisition closes while we work to bring its features and functionality into Codex”. Pierre also publishes open-source projects, Diffs, Trees and DiffsHub, on its company site.
OpenAI Already Rebuilt Its Own Git
Days before the deal, OpenAI published Scaling Git at OpenAI, describing Pando, a new backend for Git repositories. OpenAI wrote that “Codex has changed the scale and pace of development at OpenAI, enabling engineers to do far more work in parallel”.
Before Pando, OpenAI wrote, its monorepo systems suffered “slow fetches and pushes along with failed merges, with reliability at times falling below 90%”. It says switching to Pando “reduced the latency of the median push by nearly 80%” and that Pando “can deliver a petabyte of Git data per day with just a handful of CPU cores”.
OpenAI says it built Pando with Codex “moving from kick-off to production, in just 10 weeks”. Axios reported that OpenAI is exploring ways to make the technology available to customers.
The GitHub Side
On Microsoft’s fiscal first-quarter call on 28 October, Satya Nadella said “all major coding agents have showed up to work on GitHub” and “We are very hard at work on reliability as agentic activity on GitHub soars”.
He added that at GitHub Universe Microsoft “shared how we are expanding capacity and rebuilding the core Git architecture for the agentic wave”, and that “Credit consumption from agentic features on GitHub has more than doubled since usage-based billing went into effect”.
Axios reported that Microsoft owns nearly a quarter of OpenAI, and that Cursor, now owned by SpaceX, launched a GitHub rival called Origin in August. Both OpenAI and Microsoft now describe rebuilding Git infrastructure for agent traffic, by our reading of their own texts.
How Each Side Reads the Deal
For readers who see a supplier deal, Pierre’s technology is already inside Codex, Axios reported, and its open-source projects stay open.
For readers who see a platform contest, OpenAI is adding a hosted Git store with outside customers to the coding agent it sells, as GitHub reports agents opening more than a third of its pull requests. We cite no analysts’ views here.

What Is Not Established
The price, the deal structure and the closing timeline are not established; Axios reported that terms were not disclosed. OpenAI says “The closing of the acquisition is subject to customary closing conditions, including receipt of regulatory approvals”, and that until then the two remain separate companies.
OpenAI’s post does not say how long outside customers such as Lovable and Bolt can keep using Code Storage once its features move into Codex, nor whether Pando and Code Storage will be combined. Pierre’s headcount is not stated in the sources we read. We did not contact OpenAI, Pierre or Microsoft.
The Bottom Line
OpenAI says it will acquire Pierre Computer Company, maker of the Code Storage git service and of libraries already used in Codex, on terms Axios reported were not disclosed. It comes a week after Microsoft said agent-generated pull requests on GitHub rose 6X in six months and agents now open more than a third of them.
