# Amazon Bedrock propose désormais des modèles OpenAI, Codex et Managed Agents (version préliminaire limitée)

AWS et OpenAI étendent leur partenariat pour apporter des informations de pointe à l’infrastructure à laquelle des millions d’organisations font déjà confiance. Les entreprises recherchent les modèles et les agents d’IA les plus performants, dotés de la sécurité, de la maturité opérationnelle et de la gouvernance des données qu’exigent les charges de travail de production. Aujourd’hui, nous les rassemblons avec trois nouvelles offres sur Amazon Bedrock, toutes disponibles en avant-première limitée : les derniers modèles OpenAI, Codex et Managed Agents optimisés par OpenAI.

Tout d’abord, les derniers modèles OpenAI sont disponibles sur Amazon Bedrock. Pour la première fois, les clients AWS peuvent accéder aux modèles frontières d’OpenAI via les mêmes services Bedrock qu’ils utilisent déjà pour accéder aux modèles, les affiner et les orchestrer. Les modèles OpenAI sur Bedrock héritent des contrôles d’entreprise dont dépendent les clients, notamment IAM, AWS PrivateLink, les barrières de protection, le chiffrement et la journalisation CloudTrail. Ensuite, Codex sur Amazon Bedrock intègre l’agent de codage OpenAI dans les environnements AWS que les équipes d’entreprise développent déjà. Les clients s’authentifient à l’aide d’informations d’identification AWS et effectuent des inférences via Bedrock. Le Codex sera disponible via Bedrock via la CLI Codex, l’application de bureau et l’extension VS Code. L’utilisation des modèles OpenAI et de Codex peut être appliquée aux engagements cloud AWS existants. Enfin, les agents gérés d’Amazon Bedrock, optimisés par OpenAI, permettent de déployer rapidement des agents OpenAI prêts à être utilisés en production sur AWS. À la base se trouvent les derniers modèles OpenAI Frontier et le harnais d’agents OpenAI, conçus pour une exécution plus rapide, un raisonnement plus précis et un pilotage fiable des tâches de longue durée. Chaque agent possède sa propre identité, enregistre chaque action et s’exécute dans votre environnement avec toutes les inférences possibles sur Amazon Bedrock. Managed Agents fonctionne avec Amazon Bedrock AgentCore, qui fournit l’environnement de calcul par défaut.
