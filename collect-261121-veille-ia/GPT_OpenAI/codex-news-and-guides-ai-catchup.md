## All Codex News and Guides

### ChatGPT’s New Mobile Experience Gives Your Dot Its Own Tab

ChatGPT's new mobile experience gives your dot its own tab and lets you pin favorites such as Codex, Projects, and Images to the tab bar. OpenAI is starting the rollout with Pro users aged 18 or older in regions where dots are available, plus a small group of eligible Plus users. Some eligible Pro users will see it by default. If New ChatGPT design appears in Settings, you can turn it on or off there.

### GPT-6.2 Astra and Sol: Astra Drops to $8/$40, Sol Keeps Its Price

OpenAI released GPT-6.2 Astra and GPT-6.2 Sol on November 17, 2026. Astra costs $8 input and $40 output per million tokens, 20% below GPT-6 Astra, with cached input at $0.40. Sol keeps GPT-6.1 Sol's $2 and $10. Both are in ChatGPT Work, Codex, and the API as gpt-6.2-astra and gpt-6.2-sol.

OpenAI Developers says its plugin now has a Showcase tab with starter projects for agents, creative tools, data visualization, and voice. ### OpenAI Shows How Codex Is Being Used in Engineering Workflows

OpenAI says its teams use ChatGPT and Codex across mechanical design, electrical engineering, CAD, and simulation. It describes a Chip Ganassi Racing workflow test and a research collaboration with Mazda, with partner engineers reviewing outputs as the work develops.

### OpenAI GPT-6.1 Terra: Availability, Computer Use, and API Pricing

OpenAI began rolling out GPT-6.1 Terra on October 26 in ChatGPT Work and Codex, with the API model identifier `gpt-6.1-terra`. ChatGPT rollout includes Plus, Pro, Business, Enterprise, and Edu, with access depending on plan, region, workspace settings, and rollout timing. For requests up to 272K input tokens, standard API rates are $1 per million input tokens, $0.05 per million cached input tokens, and $5 per million output tokens; long-context, Fast-mode, and cache-write rates differ.

### OpenAI Adds Prompt Presets and Inline Controls to Codex CLI

OpenAI's Codex CLI 0.164.0 release adds reusable prompts in ten numbered `/presets` slots, inline settings for model, reasoning effort, speed, and permissions, plus sign-in options for enterprise MCP connections.

### OpenAI Models and Codex Are Coming to Google Cloud

OpenAI and Google Cloud plan to make OpenAI frontier models and Codex agentic workflows available in Google Cloud's Model Garden. ### OpenAI Shares a PHP Version Checker and Codex Skills

OpenAI has published a PHP Version Checker repository with Codex skills for identifying PHP versions that may need security updates. OpenAI's Codex Cloud uses reusable, published environments that package a repository, tools, dependencies, and access settings. OpenAI's Pro 500 costs $500 a month and includes Ultrafast on GPT-6.2 Astra, GPT-6.2 Sol, GPT-6 Astra and GPT-6.1 Sol. As of November 17, 2026, Pro 200 has Ultrafast with GPT-6.2 Sol only. OpenAI released GPT-6 Sol and GPT-6 Luna on September 22, 2026, at $2 and $10 and $0.10 and $0.50 per million tokens, half the price of GPT-5.6. Luna scores 66.6% on DeepSWE for about $0.22 a task. ### Codex Permission Profiles: Least-Privilege Controls for Local Agent Work

OpenAI shipped Codex permission profiles in beta -- reusable, inheritable policies that replace the coarse sandbox_mode/sandbox_workspace_write combo. A profile binds OS-enforced filesystem read/write/deny rules (down to **/*.env) to per-domain network and Unix-socket rules. Enterprise admins get fail-closed allowlists via requirements.toml. Profiles govern local sandboxed command execution only, not MCP servers, app connectors, browser, or cloud.

### Codex CLI vs Claude Code vs Cursor: 2026 Architecture Deep-Dive (Sandboxing, Context, Plugins, Scheduling)

Codex CLI, Claude Code and Cursor now all confine local shell commands in an OS-enforced sandbox and all run hook scripts, so the real split is defaults and composition. Codex sandboxes by default, Claude Code's sandbox is opt-in, and Cursor sandboxes under Auto-review. Choose by default posture, Windows support and how unattended work runs.

### Perplexity Personal Computer vs OpenAI Codex Computer Use vs Claude Computer Use: Which AI Should Run Your Mac?

Pick Perplexity Personal Computer for an always-on desktop agent on Mac or Windows; Max includes 10,000 Computer credits a month. Pick Codex Computer Use if you live in ChatGPT and want one agent driving code, browser and desktop apps. Pick Claude Computer Use to wire it into your own harness on any OS, or in Claude Code.
