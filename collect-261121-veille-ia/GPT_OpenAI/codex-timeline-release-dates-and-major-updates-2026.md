OpenAI first introduced Codex on August 10, 2021, as a model that translated plain-English instructions into code and helped power GitHub Copilot. The original Codex models were retired in March 2023.

In April 2025, OpenAI revived Codex as an open-source coding agent for the terminal. A cloud agent followed in May, and subsequent releases expanded Codex to desktop and mobile apps, remote development, new coding models, and developer APIs.

This timeline records Codex release dates and major updates from 2021 onward. The latest stable CLI release added GPT-6.2 Astra and Sol to the model catalogs and enabled the terminal workspace by default.

**Last updated: Nov 20, 2026.**

## How Codex evolved from a model to a coding agent

The original Codex API model generated code from instructions supplied by an application. It did not manage a repository or execute a sequence of development tasks on its own. Applications built around the model decided which prompts to send and what to do with the generated code. GitHub Copilot was an early example of that model-based coding assistance.

Codex CLI and the cloud agent introduced a different work loop in 2025. The agent could inspect an existing codebase, make changes across files, execute commands, run tests, and revise its work after inspecting the results. Local sessions worked with the developer’s tools and Git state; cloud tasks used isolated environments prepared for the selected repository. Approval controls, sandbox restrictions, and reviewable changes became important parts of the product experience.

Later Codex releases extended this agent loop into editors, desktop projects, remote hosts, pull-request reviews, browser tasks, and team automations. Worktrees made it possible to keep parallel changes independent. The Agents API exposed the managed Codex harness to applications that needed durable sessions, tool calls, context compaction, MCP connections, and parallel agents. These changes expanded the kinds of tasks Codex could perform beyond generating code from a single prompt.

## Codex model generations and major capability changes

The modern cloud agent initially used `codex-1` for software-engineering tasks, while `codex-mini-latest` served lower-latency CLI and API work. GPT-5-Codex focused on an entire coding task, from reading a repository and editing files to running tools and responding to failures. GPT-5.1-Codex-Max introduced longer agent work across multiple context windows through context compaction, which helped with sustained debugging and large refactors.

The GPT-5.2-Codex and GPT-5.3-Codex generations expanded long-context work, tool use, Windows development, vision, and security-related tasks. GPT-5.3-Codex-Spark explored faster interactive coding. GPT-5.4 and GPT-5.5 continued the move toward general models used for both coding and other demanding tasks. The GPT-5.6 family introduced Astra, Sol, Terra, and Luna tiers across different capability and cost needs.

GPT-6 Astra extended long-running Codex work with asynchronous questions and an experimental context system for preserving earlier requirements and results. GPT-6 Sol and Luna expanded model options for different coding workloads, followed by GPT-6.1 Sol.

## Where Codex runs

- Codex CLI runs in a local terminal and works with files, commands, Git, MCP servers, scripts, and non-interactive automation.
- The IDE extension places local sessions, diffs, and cloud task handoff inside VS Code, Cursor, and compatible editors.
- Codex Cloud runs delegated tasks in reusable managed environments with selected repositories, tools, and access settings.
- The ChatGPT desktop app manages projects, parallel threads, worktrees, reviews, terminals, Automations, browser tools, computer use, and plugins.
- The ChatGPT mobile app can start and supervise Codex work on connected local or remote hosts.
- The Agents API runs developer-built cloud agents on the managed Codex harness with OpenAI-hosted sandboxes, developer-managed infrastructure, or integrated sandbox providers.
- The SDK, GitHub Action, Slack integration, hooks, access tokens, and non-interactive CLI connect Codex with team systems and automation.

## Codex FAQs

#### Is Codex free?

Codex has included free access for certain ChatGPT plans and features. In 2026, OpenAI expanded desktop access to Free and Go users and made Auto-review free for ChatGPT-signed-in sessions. Paid subscriptions have offered additional models and usage allowances. API-key usage is billed separately.

#### Does Codex run code locally?

Local Codex sessions can read files and run approved commands on the selected computer or SSH host. Sandbox rules, writable folders, and approval settings limit those actions. Codex cloud uses an OpenAI-managed environment. A cloud task receives only the files, dependencies, credentials, and services configured for that environment.

#### Is Codex CLI open source?

Yes. OpenAI publishes Codex CLI at github.com/openai/codex. The repository contains the agent implementation, installation instructions, source changes, and numbered releases. Hosted models and managed Codex services are separate from the open-source CLI code.

#### Does Codex require GitHub?

No. Codex CLI and the desktop app can work with local folders and Git repositories without a GitHub connection. GitHub is important for cloud repository tasks, pull requests, code review, and the GitHub Action. A local session can also use another Git host through ordinary command-line tools if the environment has access.

#### Is there a Codex API?

Yes. OpenAI released the Agents API in public beta on September 10, 2026. It exposes the managed harness behind Codex and handles orchestration, long-running sessions, context compaction, and recovery. Developers choose the model, tools, and execution environment and can connect MCP servers, custom functions, and built-in tools. The Agents API also supports computer use. It has no additional platform fee. Model token and tool charges apply. The Codex SDK and non-interactive CLI provide separate automation options.

#### Can Codex use browser pages and desktop applications?

Supported Codex app versions can operate an in-app browser and use desktop applications through computer use. The Chrome extension can supply signed-in browser context for approved sites. Availability depends on the operating system, region, plan, administrator controls, installed plugin, and permission settings.

#### When did GPT-6 Astra arrive in Codex?

OpenAI announced GPT-6 Astra availability in Codex and the API on September 9, 2026. Codex CLI 0.154.0 included Astra in the model picker and Amazon Bedrock catalogs.

#### When were GPT-6 Sol and Luna released for Codex?

GPT-6 Sol and GPT-6 Luna arrived in Codex and the API on September 22, 2026. GPT-6.1 Sol followed on September 29, 2026, along with Codex CLI 0.159.1.
