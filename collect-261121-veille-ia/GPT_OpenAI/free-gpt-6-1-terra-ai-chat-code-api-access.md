## GPT-6.1 Terra API: OpenAI and 1min.AI

Developers have two routes. OpenAI’s own API serves the model as gpt-6.1-terra through Chat Completions and Responses, and tool calling requires the Responses API. The 1min.AI API also lists gpt-6.1-terra in its unified Chat with AI endpoint, so you can reach it with the same request format you use for other models. It supports streaming, web search, image and file attachments, conversation history and memory.

```
curl -X POST "https://api.1min.ai/api/chat-with-ai" \
  -H "API-KEY: <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "UNIFY_CHAT_WITH_AI",
    "model": "gpt-6.1-terra",
    "promptObject": { "prompt": "Summarize this report in 5 bullets" }
  }'
```
Add ?isStreaming=true to the URL for streaming responses. Swapping models is as simple as changing the model value, which is handy for testing Terra against others such as the one covered in this **Gemini 4 Argon API guide**.
