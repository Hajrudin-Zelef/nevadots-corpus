# GitHub Copilot retires several Claude and GPT models

As of November 16, 2026, GitHub has deprecated several models across most GitHub Copilot experiences, including Copilot Chat, inline edits, and code completions. Claude Opus 4.8 and Claude Opus 5 are replaced by Claude Opus 5.5, and GPT-5.6 Terra is replaced by GPT-6.1 Sol or GPT-6 Luna. Claude Opus 4.8 remains available to individual Copilot subscribers on annual plans, and GitHub announced the deprecations on October 15, 2026.
