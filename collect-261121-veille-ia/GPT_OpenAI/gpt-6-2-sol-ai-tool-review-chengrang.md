## Overview

GPT-6.2 Sol is the everyday model OpenAI shipped on November 18, 2026, alongside the GPT-6.2 Astra flagship. The name comes second, but this is the tier most requests will actually hit. The pricing decision is straightforward: token rates are identical to GPT-6.1 Sol at $2 input and $10 output, with more capability on top. Existing users can move up without touching their budget.

The benchmark position is more interesting than the price. On FrontierCode 2.0 it sits within 0.5 points of the Astra flagship at roughly a fifth of the cost. LifeVal comes in above GPT-6 Astra, the previous flagship, at about a seventh of the cost. GDPval v2 improves 5.3 points over GPT-6.1 Sol, and AA-3D puts it third at 1,259 Elo. Read together, those numbers say the gap between Sol and Astra has shrunk to the point where paying four times more for it rarely makes sense on ordinary work.

Sol also gets a launch perk Astra does not. Ultrafast reaches Pro 200 subscribers for the first time, starting with this model. Ultrafast is 50% cheaper for three months and costs API and Enterprise users 3x standard. For a daily driver, response speed shapes the experience more than peak capability does, so this handoff matters more in practice than a few benchmark points.

One thing to note: it carries the same Critical cybersecurity rating as Astra. That is OpenAI's own system card grade, applied to both models and printed in the release notes, which makes it a neutral data point rather than a warning. The launch page also omits the context window and maximum output token count, and no third-party parameter table fills them in, so those two fields should stay empty rather than guessed.

Choosing between the two is simple. Daily work, code, research cleanup, routine agent pipelines, use Sol. Switch to Astra only for genuinely hard projects that span a dozen tools and run for half an hour or more. The signal is output length and tool-call count per run, not how impressive the task sounds.

- **Within 0.5 points of the flagship** : FrontierCode 2.0 lands within 0.5 points of GPT-6.2 Astra at roughly a fifth of the cost. Paying four times more for half a point rarely pays off on everyday coding.
- **LifeVal above the last flagship** : LifeVal scores higher than GPT-6 Astra at about a seventh of the cost. Last generation's flagship capability now sits at this generation's mid tier.
- **Ultrafast reaches Pro 200 first here** : Pro 200 subscribers get Ultrafast for the first time, beginning with Sol. It runs 50% cheaper for three months and costs API and Enterprise users 3x standard.
- **Third on AA-3D** : 1,259 Elo on AA-3D for third place, in the same band as the flagship's 1,318. 3D and design work does not automatically need the top tier.
- **All four subscription tiers on day one** : Live in ChatGPT Work and Codex for Plus, Pro, Enterprise and Edu, with the API model name gpt-6.2-sol. OpenRouter lists it at the same $2 and $10.
