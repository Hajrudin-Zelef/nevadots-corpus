# Les agents gérés Amazon Bedrock, optimisés par OpenAI, sont désormais disponibles en version préliminaire

Développés conjointement par AWS et OpenAI, les agents gérés Amazon Bedrock (BMA) reposent sur une version personnalisée de l’API Agents d’OpenAI conçue pour être native d’AWS et intégrée aux ressources AWS. Vous pouvez désormais créer des agents optimisés pour les modèles OpenAI, qui s’exécutent entièrement dans AWS avec les identités, les autorisations et les contrôles de gouvernance que vous utilisez déjà.

Les BMA gèrent la manière dont le modèle préserve l’état, sélectionne et utilise les outils, exécute le code et coordonne le travail sur plusieurs étapes et décisions. Les sessions durables conservent les messages, les appels d’outils et les résultats intermédiaires afin que vous puissiez y revenir plus tard, fournir de nouvelles informations et poursuivre sur la base des progrès déjà réalisés. Vous pouvez ajouter des compétences réutilisables pour des procédures spécialisées et connecter des agents à des outils, notamment via des serveurs MCP (protocole de contextualisation des modèles). Chaque agent exerce son propre rôle IAM, prend en charge l’approbation humaine avant toute action consécutive et enregistre les activités d’API prises en charge avec AWS CloudTrail.

Pendant la version préliminaire, aucun frais supplémentaire ne sera facturé aux BMA au-delà des ressources AWS sous-jacentes consommées par vos agents. Les prix sont sujets à modification en fonction de la disponibilité générale.

Commencez à utiliser les agents gérés Amazon Bedrock dès aujourd’hui grâce aux API prises en charge. Les BMA sont disponibles dans les Régions suivantes : USA Est (Virginie du Nord), USA Ouest·(Oregon) et USA Est (Ohio). Pour en savoir plus, consultez la documentation Amazon Bedrock.
