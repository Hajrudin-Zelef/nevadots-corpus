Microsoft is getting serious about developing its own AI models, and the latest announcement shows that OpenAI and Anthropic have some new competition. At Ignite 2026, the company unveiled two new AI coding models that promise performance comparable to some of the industry’s most powerful offerings, but at considerably lower costs.

Called MAI Code 2 and MAI Code 2 Flash, the models are designed for everything from complex software development to everyday coding tasks. And according to Microsoft’s official announcement, they’re already available through GitHub Copilot.

## Nearly the same performance, for a fraction of the price

MAI Code 2 is Microsoft’s more capable model, designed to handle demanding programming tasks such as debugging complicated code, implementing changes across multiple files, and understanding entire code repositories. Microsoft claims the model delivers 98% of GPT-6.1 Sol‘s performance at just 40% of its cost, averaged across four coding benchmarks. Against Anthropic’s Claude Opus 5.5, the company claims 96% of the performance at only 5% of the price.

This is a big claim when you consider Microsoft’s longstanding partnership with OpenAI. The company also added that developers preferred MAI Code 2’s frontend designs over those generated by GPT-6 Sol in 64% of blind comparisons, covering interfaces, visualizations, and other graphical projects.

Meanwhile, MAI Code 2 Flash prioritizes speed and efficiency. It’s built for everyday tasks such as explaining code, fixing minor bugs, and making targeted edits. Microsoft states that it delivers comparable performance to GPT-6 Luna and Claude Haiku 5.5 at 65% and 20% of their respective costs.

It is worth noting, though, that these comparisons come from Microsoft’s evaluations of specific coding tasks and use promotional pricing for its models. The company also acknowledges that the models aren’t yet optimized for particularly complex scientific research or extremely long-running agentic tasks.

## Microsoft’s AI dreams are getting bigger

Both models are now available in GitHub Copilot, but access depends on your subscription. MAI Code 2 is available to eligible Copilot Pro, Pro+, Max, Business, and Enterprise subscribers. The lighter Code 2 Flash is also accessible through Copilot Free and Student plans, subject to their applicable usage limits.

Developers can select them through GitHub Copilot’s model picker across supported environments, including Visual Studio Code, Visual Studio, and GitHub’s website. MAI Code 2 has also joined Copilot Fusion Standard, which can automatically select models to handle different tasks.

Microsoft is expanding its homegrown AI portfolio beyond coding, introducing new models for cybersecurity, image generation, and real-time voice interactions at Ignite.
