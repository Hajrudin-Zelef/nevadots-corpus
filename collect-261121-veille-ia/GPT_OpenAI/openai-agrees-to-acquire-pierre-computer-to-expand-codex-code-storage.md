Originally published on The Daily Flare.

OpenAI announced on Nov. 4 that it had agreed to acquire Pierre Computer, with plans to bring the startup’s Code Storage service into Codex.

The deal would bring Pierre’s developer tools and team into OpenAI, extending Codex beyond code-generation features into more of the systems used to store and review software. OpenAI said the acquisition is intended to help adapt Git workflows for teams working with coding agents in parallel. The agreement remains subject to customary closing conditions, including regulatory approvals; until it closes, the companies will remain independent.

Financial terms were not disclosed, Axios reported. OpenAI’s acquisition announcement said Pierre’s tools would contribute to its effort to make Codex a place where developers and agents can work on large software projects. The company said it wants to connect the code a business ships with the decisions made during development.

Pierre’s technology is already part of the Codex app. OpenAI said its Trees library helps developers navigate project files, while Diffs displays code changes for review. Diffs also includes an Edit mode that lets reviewers change a line directly where they spot an issue. Pierre’s recently released Highlights tool is a syntax highlighter designed to update quickly as a developer types or an agent streams code.

The planned integration centers on Code Storage, which Pierre describes as a distributed Git-based system with an API designed for machine use. AI Weekly reported that the service supports repositories of up to 32 terabytes and more than 30 concurrent writes. Its other features include Git Large File Storage, software development kits for TypeScript, Python and Go, webhooks, and synchronization with GitHub, GitLab and Bitbucket.

Code Storage is used by AI-focused software companies including Lovable, Poke, Anything, Bolt, Amp and Parahelp, AI Weekly reported. OpenAI said customers will be able to continue using the service after the acquisition closes while it works to bring its features into Codex.

OpenAI also said Pierre’s open-source projects will remain open source and that it will continue contributing to them. They include Trees and Diffs, already used in Codex, and DiffsHub, another project listed by AI Weekly. The acquisition announcement also highlighted Diffs’ review and editing features and Pierre’s work on tools for navigating and understanding large volumes of code.

The agreement follows OpenAI’s unveiling of Pando, an in-house source-control backend for its engineers and coding agents. OpenAI said Pando cut median code-push latency by nearly 80 percent. AI Weekly reported that the system handles nearly a petabyte of Git data each day and that OpenAI engineers put it into production in about 10 weeks, using Codex agents to help with migration work. Axios reported that OpenAI is exploring ways to make Pando available to customers.

The two systems point to a broader build-out of Codex’s infrastructure, although OpenAI has not said in the supplied announcement whether Pando and Code Storage will be combined. Its stated ambition is to advance source control across the industry, from the creation of an agent’s first branch through deployment.

The acquisition also puts OpenAI closer to a part of software development long associated with GitHub. Axios noted that Microsoft owns nearly a quarter of OpenAI and also owns GitHub. The outlet reported that companies are competing to serve developers as AI agents take on more coding work, while critics have raised concerns about GitHub’s reliability and its design for human users.
