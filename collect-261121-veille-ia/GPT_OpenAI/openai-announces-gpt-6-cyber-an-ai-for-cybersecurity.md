# OpenAI announces 'GPT-6 Cyber,' an AI for cybersecurity.


 OpenAI has announced 'GPT-6 Cyber,' a model that boasts high capabilities in discovering and fixing vulnerabilities.

 **GPT‑6 Cyber: Advancing the frontier of aligned cybersecurity agents | OpenAI**

 

Today's GPT-6 Cyber release is a meaningful step for defenders: stronger vulnerability research and better alignment.  GPT-6 Cyber represents a significant improvement over its predecessor, **GPT-5.6 Cyber** , showing a relative 51% performance improvement in the ExploitGym benchmark, which tests whether the model can exploit specified vulnerabilities in remote targets. It has already contributed to ensuring software security, having reportedly discovered and verified nearly 1,000 exploits in Linux and Firefox.

 


 Improvements in alignment (ethics) performance have also been observed, with a greater ability to operate within human-permitted limits and adhere to behavioral restrictions. OpenAI explained that it underwent dedicated training to prevent it from deviating from the scope of its assigned tasks or attempting to abuse unrelated services. When tested without safety prompts, it achieved a 99.93% success rate in avoiding the abuse of external services that humans would not anticipate, an improvement from GPT-5.6 Cyber's 94.49%.

 Even in tests attempting to infiltrate the web, we see a performance improvement of about 8 points.

 


 GPT-6 Cyber is provided for OpenAI's advanced cybersecurity validation environment, ' **Daybreak Red** .' This environment is designed to support advanced security workflows, such as developing working exploits and launching attacks on remote targets.

 Furthermore, concerned that some people might exploit the AI model's high capabilities for malicious purposes, they have implemented robust protection measures to detect and prevent such misuse. For example, a feature called Private Safety Processing (PSP) automatically checks for any unauthorized use in interactions with the AI. Additionally, access to the Daybreak Red API requires an IP allow list, restricting requests to approved networks with few exceptions.

 GPT-6 Cyber will initially be available to a limited group of approved Daybreak Red users via API and Codex. Access will be gradually expanded to all Daybreak Red users in the near future, and GPT-5.6 Cyber will also be made available to all Daybreak Red users. OpenAI is currently accepting applications from new users.
