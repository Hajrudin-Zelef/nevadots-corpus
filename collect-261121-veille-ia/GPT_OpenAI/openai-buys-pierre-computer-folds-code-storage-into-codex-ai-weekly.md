## TL;DR

- OpenAI is acquiring developer-tools startup Pierre Computer and plans to integrate Pierre's Code Storage product directly into Codex; financial terms were not disclosed.
- Code Storage is a Git-based distributed store already used by Lovable, Poke, Anything, Bolt, Amp, and Parahelp; open-source projects Diffs, Trees and DiffsHub remain open.
- The deal lands two days after OpenAI unveiled Pando, its in-house Git backend, which it says cut median code-push latency by nearly 80% and delivers nearly a petabyte of Git data daily.

Pierre Computer describes its flagship product as "a distributed storage system built on Git, with API ergonomics designed for machines." On November 4, Axios reported that OpenAI is buying the developer-tools startup and will fold Pierre's Code Storage product directly into Codex. Terms were not disclosed.

Code Storage already backs a cluster of AI-first builders — Lovable, Poke, Anything, Bolt, Amp, and Parahelp. It supports repositories up to 32TB, more than 30 concurrent writes, Git LFS, TypeScript, Python and Go SDKs, webhooks, and synchronization with GitHub, GitLab and Bitbucket. Pierre's open-source projects, Diffs, Trees and DiffsHub, will remain open source after the acquisition.

The deal lands two days after OpenAI publicly introduced Pando, its own Git backend. OpenAI says Pando reduced median code-push latency by nearly 80% and now delivers nearly a petabyte of Git data daily, and that engineers put it into production in roughly ten weeks using Codex agents to handle the migration work.

The competitive framing is hard to miss. Microsoft owns nearly a quarter of OpenAI and also owns GitHub; pulling source-control plumbing into Codex puts the two closer to head-to-head on an infrastructure layer Microsoft has dominated for over a decade.

It's our second OpenAI-and-Codex alert on the tracker today, after an Astra-era Codex companion device write-up earlier in the day — part of a run of 129 coding-tools stories we've logged over the last 90 days.
