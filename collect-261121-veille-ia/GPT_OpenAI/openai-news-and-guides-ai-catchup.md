## All OpenAI News and Guides

### ChatGPT’s New Mobile Experience Gives Your Dot Its Own Tab

ChatGPT's new mobile experience gives your dot its own tab and lets you pin favorites such as Codex, Projects, and Images to the tab bar. OpenAI is starting the rollout with Pro users aged 18 or older in regions where dots are available, plus a small group of eligible Plus users. Some eligible Pro users will see it by default. If New ChatGPT design appears in Settings, you can turn it on or off there.

### OpenAI Brings GPT-Live-1.1 to the API With Lower-Cost Standby

OpenAI's API changelog lists GPT-Live-1.1 for the Live API, with improvements to pronunciation, accent consistency, and multilingual transcription. A new WebRTC standby configuration works with GPT-Live-1 and GPT-Live-1.1: inference pauses during inactivity, then resumes when the user speaks. OpenAI lists standby at $0.02 per minute versus $0.05 for active session time; backend model and tool usage are billed separately.

### OpenAI Adds Discounted Background Windows to the Responses API

OpenAI's Responses API now supports 2-hour and 8-hour completion targets for eligible background requests. The public beta discounts model-token rates by 30% or 40% on supported models, including GPT-6.2 Astra and Sol, GPT-6.1 Terra, and GPT-6 Luna.

### OpenAI Adds Computer-Use Agents, Clinical Search, and Plugins to ChatGPT for Healthcare

OpenAI is adding computer-use agents, improved trusted clinical search and more than 20 healthcare plugins to ChatGPT for Healthcare. Organizations can control which apps agents access and which steps require human review; the expanded experience is available today subject to workspace settings. Eligible verified U.S. clinicians can also use ChatGPT for Clinicians at no cost.

### GPT-6.2 Astra and Sol: Astra Drops to $8/$40, Sol Keeps Its Price

OpenAI released GPT-6.2 Astra and GPT-6.2 Sol on November 17, 2026. Astra costs $8 input and $40 output per million tokens, 20% below GPT-6 Astra, with cached input at $0.40. Sol keeps GPT-6.1 Sol's $2 and $10. Both are in ChatGPT Work, Codex, and the API as gpt-6.2-astra and gpt-6.2-sol.

### OpenAI Adds 12-Hour Prompt Caching to the Responses API

OpenAI added an optional 12-hour prompt-cache lifetime to the Responses API for GPT-5.6 and later. Developers can keep matching prompt prefixes eligible for cached-input pricing across longer gaps by setting `prompt_cache_options.ttl` to `12h`; the default remains 30 minutes. The longer cache write costs more, so the tradeoff depends on reuse.

### OpenAI Shares a PHP Version Checker and Codex Skills

It is a triage aid, not proof that a system is patched or secure.
