OpenAI is acquiring Pierre Computer, a developer tools startup whose Code Storage technology is already used in Codex, as it seeks a larger role in the infrastructure supporting AI-driven software development.

The company disclosed the acquisition to Axios, while declining to reveal financial terms. Pierre’s open-source projects will remain open-source, according to the report.

Founded in 2023 by Bootstrap creator Jacob Thornton and former Twitter engineer Ian Ownbey, Pierre Computer builds Git storage and code infrastructure for AI agents. Its main product, Code Storage, provides an API-first alternative to parts of GitHub’s underlying storage layer, allowing AI applications to store and manage code, documents, memory files and other generated assets.

The San Francisco-based startup is backed by Y Combinator, with customers including AI application developers such as Lovable, Poke, Anything, Bolt, Amp and Parahelp. Pierre also develops open-source tools for rendering code and managing file interfaces, including Diffs and Trees.

The acquisition comes as AI coding agents challenge GitHub’s position as a central platform for software development. Critics say GitHub was designed around human developers, while the growing volume of AI-generated code requires infrastructure better suited to autonomous agents.

OpenAI has been building its own systems to support AI coding at scale. Its recently announced Pando infrastructure reduced the time needed to push code changes by nearly 80%, according to the company. OpenAI is exploring ways to make Pando available to customers, as it expands from helping developers write code toward managing the systems used to store, review and deliver it.
