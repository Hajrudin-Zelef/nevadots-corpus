## Model Overview

OpenRouter is a unified API gateway that provides access to hundreds of AI models from dozens of providers. It offers automatic fallback, price comparison, and a single API key for all models.

**GPT-6.1 Terra** is a gpt-terra-family model by OpenRouter with a 1.1M token context window and up to 128k output tokens. It is priced at $1.00/1M input tokens and $5.00/1M output tokens.

Key capabilities include: attachments, reasoning, tool calling, structured output, image input, pdf input. It supports advanced reasoning for complex multi-step tasks. It can call external tools and functions for agentic workflows.
