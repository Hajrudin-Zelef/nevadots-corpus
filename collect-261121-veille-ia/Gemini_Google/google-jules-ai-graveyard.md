Google introduced Jules on December 11, 2024 as an experimental code agent for Python and JavaScript, built on Gemini 2.0 and offered first to a select group of trusted testers. The idea was delegation rather than autocomplete: hand over an issue, and Jules would write a multi-step plan, change the files, and prepare a pull request back into GitHub while the developer did something else. It opened as a public beta on May 20, 2025 with no waitlist, and left beta on August 6, 2025, when Google said beta users had produced more than 140,000 publicly shared code improvements and attached higher usage limits to its paid AI plans. A command-line tool and an API followed in October 2025. On October 29, 2026 a changelog entry titled Jules Turndown gave the dates: as part of work to unify its agentic coding efforts, Google said, sessions could be finished until November 11, 2026, Jules would be read-only after that, and it will wind down on December 31, 2026. The same entry described Jules as an experiment whose lessons were shaping other Google products, including Antigravity. The code, branches, and pull requests stay in GitHub, where they always lived; what needs exporting is everything Jules remembered about the work, and the instructions for that have the user install Jules Tools, sign in, and then paste a prompt into a different coding agent.
