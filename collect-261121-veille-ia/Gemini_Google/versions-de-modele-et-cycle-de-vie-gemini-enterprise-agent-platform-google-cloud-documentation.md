## Migrer vers le dernier modèle disponible

Pour savoir comment migrer vers un modèle stable récent, consultez Migrer vers les derniers modèles Gemini. Ce guide vous propose une série d'étapes de migration visant à minimiser certains risques potentiels liés à la migration de modèles et vous aide à utiliser les nouveaux modèles de manière optimale.

Toutefois, si vous n'avez pas le temps de suivre le guide et que vous devez simplement résoudre rapidement les erreurs causées par les modèles arrivant à leur date de retrait, procédez comme suit :

1. Mettez à jour votre application pour qu'elle pointe vers les mises à niveau recommandées.
2. Testez toutes les fonctionnalités critiques pour vous assurer que tout fonctionne comme prévu.
3. Déployez les mises à jour comme vous le feriez normalement.
