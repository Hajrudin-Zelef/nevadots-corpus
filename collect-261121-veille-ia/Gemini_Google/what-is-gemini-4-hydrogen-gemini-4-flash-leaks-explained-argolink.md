## What is Gemini 4 Hydrogen?

Gemini 4 Hydrogen is the codename testers on X use for an unreleased Google model that they describe as Gemini 4 Flash.

Flash is Google's name for its fast, cost-efficient Gemini models. Google's Gemini 3.8 Flash page describes Gemini 3.8 Flash as having "the speed and cost efficiency of Flash".

## Where did the Gemini 4 Hydrogen name come from?

The Gemini 4 Hydrogen name came from posts on X, not from Google. The earliest post naming Hydrogen that we found is by X user White1637402, who wrote on October 27 that "Gemini 4 Flash has just surfaced internally" under the codename Hydrogen, with no screenshot or link.

Pankaj Kumar, who posts as pankajkumar_dev on X, posted the same codename later on October 27: "Gemini 4 Flash is in internal testing under the codename Hydrogen."

Pankaj Kumar's October 27 post also named a model ID, `gemini-3.8-flash-router`, which he wrote "can be related to Gemini 4 Flash". Google's Gemini API documentation has no model with that ID.

## Is Gemini 4 Hydrogen the same as Gemini 3.8 Flash?

No. Gemini 3.8 Flash is a released Google model, and Google's changelog lists it as "Gemini 3.8 Flash generally available (GA)". Gemini 4 Hydrogen is a reported codename for an unreleased model.

The `gemini-3.8-flash` label on Arena does not identify Gemini 4 Hydrogen by itself. Pankaj Kumar reported the same name for a different test model on September 26: "A new Gemini 4 Pro checkpoint came to Arena under the name “Gemini 3.8 Flash.”"

Google has not said which model answers under the `gemini-3.8-flash` label on Arena.

## Has Google announced Gemini 4 Hydrogen?

No. Google has not announced Gemini 4 Hydrogen or any Gemini 4 Flash model, and Google's full Gemini API documentation does not contain the word Hydrogen.

Gemini 4 Argon is the only Gemini 4 model in Google's Gemini API: the Gemini 4 table in Google's model list has one row, Gemini 4 Argon, and the only Gemini 4 model ID in Google's documentation is `gemini-4-argon`.

## How do you call Gemini 3.8 Flash on ArgoLink?

Gemini 3.8 Flash on ArgoLink works with the OpenAI Chat Completions format at one base URL, `https://argolink.io/v1`, with an ArgoLink API key. The model ID is `gemini-3.8-flash`, the same as Google's.

```
curl -sS https://argolink.io/v1/chat/completions \
  -H "Authorization: Bearer $ARGOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.8-flash",
    "messages": [{"role": "user", "content": "Explain what this model is good at in one sentence."}],
    "stream": false
  }'
```
The OpenAI Python SDK calls Gemini 3.8 Flash on ArgoLink with the base URL set to `https://argolink.io/v1`. The model ID sits in an environment variable, so a later Gemini model is a configuration change:

```
import os
from openai import OpenAI
client = OpenAI(
    api_key=os.environ["ARGOLINK_API_KEY"],
    base_url="https://argolink.io/v1",
)
response = client.chat.completions.create(
    model=os.environ.get("ARGOLINK_MODEL", "gemini-3.8-flash"),
    messages=[{"role": "user", "content": "Explain what this model is good at in one sentence."}],
)
print(response.choices[0].message.content)
```
