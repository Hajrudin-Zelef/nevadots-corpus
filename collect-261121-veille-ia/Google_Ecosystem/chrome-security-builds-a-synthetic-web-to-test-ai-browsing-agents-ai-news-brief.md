Google’s Chrome Security team introduced Mirror Dimension on November 19, 2026, a self-contained synthetic web for testing the agents behind Chrome’s auto browse feature. The environment contains thousands of simulated websites inspired by everyday user journeys and is designed to evaluate safety protections without exposing the live web to agent actions.
