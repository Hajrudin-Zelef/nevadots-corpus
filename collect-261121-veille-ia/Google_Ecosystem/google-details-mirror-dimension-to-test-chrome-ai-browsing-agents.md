Google detailed an isolated web environment named the Mirror Dimension on Nov. 19, 2026, designed to train and evaluate autonomous browsing agents inside Chrome without exposing live networks. The controlled network replicates real platforms, including social media feeds, shopping services and banking dashboards, allowing agents to practice web navigation while facing resilience tests such as hidden prompt-injection attacks.

The Chrome team constructed the environment using automated web development agents guided by a dedicated AI harness, populating services with realistic workflows down to entering promotional codes. Because standard Chrome enforces strict security and validity checks, researchers forged web certificates and modified the browser so agents could operate inside an authentic Chrome build without triggering security warnings.

Google director of engineering Doug Turner told Wired that the company plans continued investment in the approach and aims to make the Mirror Dimension available to other research teams across Google. Charles Qian, a software engineer on Chrome's AI security team, told the publication that the testing helps browsing agents judge what information a task requires and when to seek confirmation from users.
