PANews, November 19 — According to Google's official blog, Google Labs has launched an experimental product called Stitch Loop. The agent can connect to code repositories and real-time metrics, write code in an isolated sandbox, and submit GitHub pull requests, which are merged only after human approval. The system provides default cybersecurity, latency, and accessibility loops, with the security loop combining Gemini 4 Carbon and DeepMind's CodeMender. Users worldwide can join the waitlist, and eligible Google AI Ultra users can get priority access.
