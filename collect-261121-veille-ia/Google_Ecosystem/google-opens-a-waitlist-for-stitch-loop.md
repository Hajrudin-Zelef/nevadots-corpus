On Nov. 18, 2026, Google Labs introduced Stitch Loop, an experiment that connects to a GitHub codebase and live product data, writes code in an isolated cloud sandbox, and opens a pull request a person must approve before anything merges. Google said the default loops cover cybersecurity, latency, and accessibility, that the security loop uses Gemini 4 Carbon with DeepMind's CodeMender, and that teams can connect more than 180 integrations. The waitlist is open globally, with priority for eligible Google AI Ultra users, and Google stated no price.
