# Google Tensor G6: specs, phone list, benchmarks and gaming performance

Google Tensor G6 is a 4.11 GHz 7-core processor using the 1x 4.11GHz Arm C1-Ultra + 2x 3.38GHz Arm C1-Pro + 5x 2.65GHz Arm C1-Pro architecture. The GPU is PowerVR C-Series CXTP-48-1536, which supports up to 16 Gb of memory. It was announced on 07/25/2026. It is manufactured using 2 nm technology, so it has good specifications, with a TDP of 10. It has a connection speed up to 4000 Mbps, thanks to the built-in modem. Google Tensor G6 performs better than HiSilicon Kirin 9050 Pro cpu in benchmark tests, which makes it equal in performance with MediaTek Dimensity 8500. Smartphones which use the chip include the Google Pixel 11 Pro XL and Google Pixel 11. You can see more details in the datasheet below.
