# Google Genie 4 Launches with Real-Time Edits, 3-Minute

Google DeepMind officially released Genie 4 to AI Ultra subscribers on November 18, 2026, introducing real-time natural-language scene editing, native adaptive audio, and sessions extending up to three minutes. The launch marks a significant expansion of the world model's capabilities, allowing users to rewrite running scenes through text prompts while maintaining visual and audio coherence.

## Real-Time Scene Editing

Genie 4's headline feature lets users modify generated environments during active sessions. According to Google's launch post, creators can "shift the weather, drop in a character, or redirect the action" without restarting the generation. The model pairs visual changes with real-time native audio that adapts as the scene unfolds, from ambient soundscapes to character dialogue. This dynamic editing capability separates Genie 4 from earlier versions that locked scene parameters at generation start.

## Extended Session Length and 360-Degree Grounding

Sessions in Genie 3 now run up to three minutes per generation, tripling the previous 60-second limit. Users can link multiple worlds together for longer narrative journeys or seed a scene from a 360-degree panorama image. The panorama grounding feature enables creators to build immersive environments from existing spatial imagery, expanding use cases for architectural visualization, game prototyping, and virtual tours.

## Project Genie Conversational Agent

The release introduces Project Genie, a conversational agent that builds environments through natural dialogue. The agent calls Gemini models to surface context-aware suggestions mid-scene, streamlining the creation workflow. Google's post describes the experience as "crafting an interactive universe as effortless as having a conversation," positioning the agent as a co-creative tool rather than a prompt-response interface.

## Release Date and Availability

Officially launched on November 18, 2026, Genie 4 rolls out in tiered access. Eligible Google AI Ultra subscribers receive immediate access to Project Genie, while AI Pro members join a waitlist. All generated video and audio carry SynthID watermarking for provenance tracking. Published creations appear in a community gallery, with featured collaborations from BLVCKL!GHT ("Villa Giallo") and filmmaker Anand Gandhi ("The Life of Ants").

## Known Limitations

Google's launch documentation lists several constraints: camera latency in complex scenes, challenges with intricate physical interactions, audio precision gaps, and scene permanence issues where edited elements may not persist consistently across frames. These limitations reflect the current boundaries of real-time world generation, an area where the model continues to evolve.

**What This Means:** Genie 4's real-time editing capability shifts world models from static generation tools to interactive creative canvases. The three-minute session length and conversational agent lower the barrier for non-technical creators while SynthID watermarking addresses provenance concerns in an increasingly crowded generative video landscape. The tiered rollout suggests Google is monitoring computational load and user behavior before broader release, a pattern consistent with other DeepMind launches this year.
