# SpaceXAI Launches Grok 4.7

SpaceXAI unveils Grok 4.7 for programming and agent tasks.

On September 21, SpaceXAI unveiled Grok 4.7, a new model designed for programming, agent tasks, and knowledge work.

Grok 4.7 features a larger base model than its predecessor. Developers extended reinforcement learning duration and added more complex tasks that take several hours to complete.

SpaceXAI claims Grok 4.7 better verifies its conclusions and handles longer contexts. The model is also trained to work with the Grok Bot agent environment.

## Test Results

In the internal CursorBench 4.0, Grok 4.7 scored 46.3% compared to Grok 4.6’s 40.4%. For comparison, GPT-5.6 Sol scored 41.7%, while Claude Fable 5.1 achieved 51.8%.

In the AA Briefcase test for multi-hour work tasks, the new model scored 1657 Elo points compared to its predecessor’s 1546.

In EEBench, the result increased from 53% to 64%, and in the Harvey Legal Agent Benchmark, from 15.8% to 19.6%. These figures are from SpaceXAI.

Independent Artificial Analysis rated Grok 4.7 at 46 points on the Intelligence Index, two points higher than Grok 4.6. Paired with Grok Build, the model scored 56 points on the Coding Agent Index compared to the previous version’s 47.

Among models in proprietary agent environments, it ranked fourth after Claude Fable 5.1, GPT-6 Astra, and Claude Opus 5.

However, the new version consumes significantly more tokens on complex tasks. In Artificial Analysis tests, Grok 4.7 in xhigh mode used about 81,000 output tokens on average, compared to Grok 4.6’s 36,000.

## Price Unchanged

For requests up to 200,000 tokens, Grok 4.7 costs $2 per million input tokens, $0.50 for cached inputs, and $6 per million output tokens. Rates double for longer requests.

The context window is 500,000 tokens. The model accepts text and images and generates text.

Four levels of reasoning depth are available: low, medium, high, and xhigh.

The company also launched Grok 4.7 Fast, the same model with double the generation speed and twice the cost. This version is available only in Cursor and Grok Build, not via public API.

SpaceXAI stated that they have completely redesigned the model’s security system. In their own HackerBench v0.3, it allowed 3.3% of dangerous queries, and in the LatchBio biosecurity test, it scored 62.4%.

In August, SpaceXAI released Grok 4.6. This model also featured a 500,000-token context window and a base rate of $2 for input and $6 for output tokens.
