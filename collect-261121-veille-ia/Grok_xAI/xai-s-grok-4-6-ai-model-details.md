# Grok 4.6

Grok 4.6 is xAI's frontier model for coding, long-running agents, knowledge work, and ambitious interactive and visual projects. It builds on Grok 4.5 with stronger multi-step task persistence, self-testing, and first-pass application quality. The API model supports text and image inputs, configurable low through xhigh reasoning, function calling, web and X search, code execution, prompt caching, and context compaction across a 500K-token context window.
