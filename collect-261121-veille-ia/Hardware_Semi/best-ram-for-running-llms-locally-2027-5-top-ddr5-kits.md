## How Much RAM Do You Actually Need for LLMs?

Model size in GB decides which models you can load, and long context windows consume memory fast. In 4-bit quantization — the format most people use for local models — an 8B model needs about 5GB, a 13B model needs about 8GB, a 32B model needs about 20GB, and a 70B model needs about 42GB.

Here’s the breakdown: 32GB runs 8B and 13B models in 4-bit comfortably, with a bit of room for context. 64GB handles 32B-class models in 4-bit, plus long context. 96GB+ is for 70B-class models in 4-bit with a generous context window. Alibaba’s Qwen4-Max, launched November 16, 2026, is closed-weight and API-only, so it does not change local RAM needs — the open models you can actually run offline are still Qwen3, Gemma, and Llama.

The most-downloaded open models today are overwhelmingly small to mid-sized: Qwen3 (0.6B to 14B sizes), DeepSeek’s R1 distilled models (7B to 32B), Meta’s Llama 3 (8B and 70B), and OpenAI’s gpt-oss (20B and 120B) — with Qwen3 dominating downloads by a wide margin.
