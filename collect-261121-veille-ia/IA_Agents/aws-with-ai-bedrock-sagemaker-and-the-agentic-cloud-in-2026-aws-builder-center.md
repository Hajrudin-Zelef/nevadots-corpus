# AWS with AI: Bedrock, SageMaker, and the Agentic Cloud in 2026

An overview of how Amazon Web Services has woven AI into its core cloud stack in 2026, from Bedrock's agentic tools and 100+ foundation models to custom Trainium silicon and Cerebras-powered inference. Covers what's new and why it matters for developers building on AWS.

## Agents are the new frontier

**AgentCore**now supports server-side tool use — letting agents perform web searches, execute code, or update databases directly within AWS security boundaries — plus extended prompt caching (up to a 1-hour TTL) to cut costs on long-running, multi-turn agent conversations. AgentCore Evaluations decouples agent testing from whatever framework was used to build the agent, and Web Search within AgentCore now supports filtering by domain and publish date. AWS also previewed

**Bedrock Managed Agents**, a stateful runtime built with OpenAI for running production-scale agentic applications.

## SageMaker: from MLOps to managed infrastructure

**Amazon SageMaker AI**handles the heavier lifting: fine-tuning, reinforcement learning, knowledge distillation, and continued pre-training at scale. Recent updates include optimized generative AI inference recommendations to help pick the right instance and configuration for a workload, managed Ray support on Amazon EKS for distributed training and accelerated inference (with built-in observability and standard Ray APIs), and new Feature Store APIs for batch-writing and listing records across feature groups. NVIDIA's Nemotron 3.5 Lightning, an open model tuned for high-volume agentic workloads, is now available directly through SageMaker JumpStart.
