# Run agents securely and efficiently with the next generation AgentCore runtime

AWS announced updates to the Amazon Bedrock AgentCore runtime that keep each session in its own hardware-isolated Firecracker MicroVM while starting sessions up to 15x faster, scaling to 4x more compute (up to 8 vCPUs and 32 GB, with container images up to 10 GB), and running up to 68% more efficiently. The runtime now reclaims memory within minutes of release and scales idle agents to zero, and agents can dynamically mount and save work to a filesystem such as an Amazon S3 bucket with FUSE support so data stays inside the trust boundary. The next generation runtime is available today in AWS Regions across North America, South America, Europe, and Asia Pacific.

Announces concrete performance, scaling, billing, and data-isolation changes to a managed agent runtime, with customer metrics and availability details useful to teams planning production agent deployments.
