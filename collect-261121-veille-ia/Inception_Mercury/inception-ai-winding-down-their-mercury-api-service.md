# Inception.ai winding down their Mercury API service

Inception.ai emailed customers that it has decided to wind down the Mercury API, which will remain fully available through December 28, 2026, after which users will lose access to the service and any data submitted to the platform. The company urged users to retrieve any necessary data before that date and offered to help with the transition via email reply.
