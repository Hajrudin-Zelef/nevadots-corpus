# Kimi K3.1 Pro follow-up: Huawei Ascend and Alibaba Cloud SuperPoDs offer day-one support for the 2.8T-parameter model (report)

Announced November 5, 2026

## Verified (fact)

According to Pandaily, Huawei said Moonshot AI's 2.8T-parameter model Kimi K3.1 Pro can run from launch day on Atlas 800 A3, Atlas 900 A3 SuperPoD, and Ascend 950 SuperPoD using vLLM Ascend and SGLang. Alibaba Cloud also said it supports the model from launch day on its Lingjun Zhenwu M890 SuperPoD via vLLM and SGLang. That setup includes Zhongwei and Panmai 920 network cards, which are in invite-only testing. These items do not confirm whether the weights are publicly downloadable.

## Needs fact-check (claim)

Both Huawei and Alibaba Cloud touted 'Day-Zero support'.

## Why it matters (interpretation)

A 2.8T-class model running on Chinese-chip-based SuperPoDs as soon as it launches shows China's model and chip ecosystems moving together without NVIDIA. Earlier community rumors of an open-weight release still need official confirmation.
