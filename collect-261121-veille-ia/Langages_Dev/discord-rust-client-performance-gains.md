## Discord Rust client performance gains

Previews of a new Discord build written in Rust show dramatic performance improvements, cutting startup time and memory footprint.

- Startup times reportedly drop from an updateless 5.5 seconds down to just 33 milliseconds
- The new build is reported to be roughly 10 times lighter on RAM usage
- One member noted Cloudflare DNS tooling still integrates more smoothly with Node.js despite Rust's broader performance advantages
