Hi all1 We’re happy to announce that Mojo Pro 2026.1.14 for the JetBrain platform now adds match/case, compile-time matching, conditional patterns, nested destructuring, scoped bindings, and prefixed async syntax. It also adds migration guidance for async spellings and empty tuple types.

Existing projects using Mojo 1.0.0b1, Mojo 1.0 and Mojo 1.1 remain supported.

See JetBrains Marketplace for more info
