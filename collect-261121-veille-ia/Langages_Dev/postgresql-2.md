**2026-11-19 - 
PostgreSQL 19 Released!**
        

	
          The PostgreSQL Global Development Group today announced the release of
          PostgreSQL 19,
	  the latest version of the world's most advanced open source database.
	

  Mission-critical usage of PostgreSQL continues to rapidly rise, and PostgreSQL 19
  responds to this by simplifying both administration and development for these
  workloads at scale. This release introduces the `REPACK (CONCURRENTLY)`
  command so users can optimize tables for their current workload without
  disruption to ongoing operations. PostgreSQL 19 gives users better control over
  plan stability and query performance with the new `pg_plan_advice` extension. Developers will find many delightful features in this release,
  from support for "read-your-writes" consistency on standbys to "get or create"
  behavior that saves a network round trip.

  PostgreSQL, an innovative data management system known for its reliability,
  robustness, and extensibility, benefits from 30 years of open source
  development from a global developer community and has become the preferred open
  source relational database for organizations of all sizes.

        
          For the full list of features in PostgreSQL 19, please review the
          release notes. You can download
          PostgreSQL 19 from the download page.
        

        
          For the full press release
          and translations of the release announcement,
          please visit the press kit.
