# Rust 1.100 Released With The "Never" Type Finally Stable

Phoronix · By Michael Larabel ·

## The Brief · written from 4 sources

- Rust 1.100.0 was released on 2026-11-12.
- The release stabilizes the never type (!).
- Core parts of the Allocator API are stabilized, and Cargo can now report unused dependencies.

### Why it matters

Developers can now use the never type on stable Rust without enabling nightly features, and Cargo can flag unused dependencies to help keep builds lean.

### Who’s affected

- Rust developers
- Teams using Cargo to manage dependencies

### What to do

1. Run rustup update stable to get Rust 1.100.0.
