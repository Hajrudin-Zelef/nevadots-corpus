    Rust 1.100.0 has been released! 🦀💯🌈🎈 This bigger-than-usual Rust release adds the never type (`!`), the Allocator api, DropGuard, Box::map, Vec::from_fn, and more! Cargo now warns for unused dependencies, rebuilds less often, and adds the min-publish-age setting! https://lnkd.in/evsKbUpY

    Rustup 1.29.3 has been released. This is a small release which fixes two minor regressions: one error that only occurs on x86_64 CPUs without SSE4.1, and one error that only occurs on Solaris. See the announcement for details: https://lnkd.in/eh3JvDap

    Check out our latest Maintainer Spotlight for an interview with Anthony Bolden, member of the Rust compiler team: https://lnkd.in/eNBz4C9B This is part of a series of blog posts highlighting our amazing maintainers. 💛

    Rustup 1.29.2 has been released. This is a small release which only updates the rustls-webpki and webpki-root-certs dependencies to remove the compromised eMudhra intermediate certificates. See the announcement for details: https://lnkd.in/e6zwbiYE
- 
              
        
    Rust 1.99.1 has been released. This point release fixes a missing wcslen symbol on some targets, a miscompilation of FFI bool return values on x86_64, and a rust-lld issue on macOS. See the blog post for details: https://lnkd.in/e3kR3S3A

    Check out our latest Maintainer Spotlight for an interview with Alejandra González, member of the Clippy team: https://lnkd.in/eHGHur5J This is part of a series of blog posts highlighting our amazing maintainers. 💛

    Rust 1.98.1 has been released. This release fixes a possible miscompilation in vtable generation. Under certain circumstances, Rust 1.98.0 incorrectly puts a null pointer where a function pointer should be. See the blog post for details: https://lnkd.in/ebAX5u83
