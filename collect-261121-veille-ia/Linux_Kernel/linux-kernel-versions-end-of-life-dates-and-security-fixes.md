## What this page counts

The branches, their dates and the newest release of each are from the product lifecycle data credited under Sources. A later release that a CVE record names as a fix counts as the newest too.

This page reads 18,738 CVE records that the Linux kernel's CVE Numbering Authority published and that name Linux kernel. The fixes are from the 18,736 it places on a branch. A record says a release fixes a flaw when its affected range for a branch ends before that release. A record from any other source gives no version here.

No release of a branch that has ended is called safe here. Some of these branches are still named by records published after they ended.

2 records are not placed on a branch, so no branch or release row counts them: 2 name a release the lifecycle data has no branch for. They are CVE-2020-36775 and CVE-2020-36790.
