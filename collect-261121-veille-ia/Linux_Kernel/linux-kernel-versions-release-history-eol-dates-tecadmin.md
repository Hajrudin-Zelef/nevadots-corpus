Linus Torvalds announced his hobby kernel in August 1991 and released it under the GPL the following year. Thousands of developers and companies now contribute to each release, and the kernel runs on everything from phones and routers to supercomputers. A new mainline version arrives roughly every nine to ten weeks. Each is maintained as a stable kernel until the next one, and one kernel a year is picked for long-term support. Major version numbers change when the minor number gets large, not to mark big changes.

## Frequently asked questions

## What is the latest version of Linux kernel?

The newest Linux kernel release is Linux kernel 7.3, released on 18 Oct 2026. Its latest update is 7.3.5 (17 Nov 2026).

## What is the latest LTS version of Linux kernel?

Linux kernel 6.18 LTS is the newest long-term support release (released 30 Nov 2025), supported until 31 Dec 2028.

## Which Linux kernel versions are still supported?

As of 21 Nov 2026, 7 versions are supported: Linux kernel 7.3; Linux kernel 6.18 LTS (until 31 Dec 2028); Linux kernel 6.12 LTS (until 31 Dec 2028); Linux kernel 6.6 LTS (until 31 Dec 2027); Linux kernel 6.1 LTS (until 31 Dec 2027); Linux kernel 5.15 LTS (until 31 Dec 2026); Linux kernel 5.10 LTS (until 31 Dec 2026).

## Is Linux kernel 7.2 still supported?

No. Linux kernel 7.2 reached end of life on 1 Nov 2026 and no longer gets free security updates. Upgrade to Linux kernel 6.18 LTS.
