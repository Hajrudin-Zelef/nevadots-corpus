# Microsoft ships Decision-1.1 and new MAI models, SiliconANGLE reports

The November 17 rollout pairs first-party models for coding, imaging and cyber work with Foundry changes that let teams set baselines for agent quality, safety, latency and cost, according to SiliconANGLE.

New generative artificial intelligence models and a set of updates to Foundry, Microsoft Corp.' s enterprise platform for grounding, testing and deploying AI applications and autonomous agents, went out on November 17, according to a report by SiliconANGLE's Kyt Dotson. Among the changes, Foundry IQ, part of Microsoft IQ, now ships an enterprise knowledge graph out of the box, pulling together unstructured and application data across an estate to provide context for building applications.[1]

Microsoft said Foundry now uses its existing transparency and observability features to build learning loops, with internal evaluations letting autonomous agents set baselines for quality, safety, latency and cost. Human annotations, now in preview, allow experts to rate and comment on agent traces based on business judgment, feeding results back into an improvement cycle alongside optimization tests and comparisons against real-world outcomes. Foundry can also adapt supported models to organizational data using reinforcement learning while it runs the compute, with each improvement becoming the next baseline.[1]

On the model side, Decision-1.1 is now generally available. Microsoft describes it as a fast, low-cost model for making routing, classification, prioritization, verification and workflow control decisions in software, returning calibrated confidence scores so applications can defer when uncertainty is high rather than reasoning through each step the way a large language model would. It follows Microsoft-Decision-1, released in October, and is built on a new base, Google LLC's Gemma 4 26B A4, adding multimodal support for images in instructions.[1]

Microsoft also extended its first-party MAI family. MAI-Code-2, aimed at demanding agentic coding, and MAI-Code-2-Flash, for high-volume everyday coding, are generally available on GitHub, with Code-2-Flash in private preview in Foundry. MAI-Image-2.7 and MAI-Image-2.7-Flash are in preview for editing and image generation, and MAI-Cyber-2-Flash is in preview inside Codename MDASH, the company's agentic code security system available to eligible organizations. Foundry's model pool now features a top 50 selection supported by a model router and AI Gateway, alongside more than 11,000 models from OpenAI Group PBC, Anthropic PBC, Meta Platforms Inc., Mistral AI SAS and the open-source community, which Microsoft said can be evaluated and deployed through the same continuous improvement workflow used for agents.[1]
