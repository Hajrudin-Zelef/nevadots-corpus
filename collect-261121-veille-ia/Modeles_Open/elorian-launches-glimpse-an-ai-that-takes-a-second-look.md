Elorian introduced **Glimpse** on October 16, a research-preview model built to revisit visual evidence while working through a problem.

Instead of relying on its first interpretation, it can zoom into images, inspect video intervals and use code to investigate details. Elorian says it is available through an API and chat interface.

## Looking again can change the answer

The launch page includes examples involving object tracking, motion and counting. One photograph asks for open pliers, requiring a distinction between the right tool, its state and similar-looking scissors.

Elorian lists prices of **$0.60 per million input tokens and $3 per million output tokens**. It reports competitive visual benchmark performance, but those scores come from the companyâs evaluations. It also acknowledges that repeated visual inspection takes time and tokens.

That trade-off matters: a lower token price does not automatically mean a cheaper completed task. The practical test is whether extra inspection catches mistakes that would otherwise require a person to redo the work.
