# Kling AI launches Kling Image 4.0, supporting native 8K image generation.

On November 18, Keling AI officially launched the image creation model Kling Image 4.0 late on November 17, upgrading image realism, text rendering, prompt understanding, and consistency, and for the first time supporting native 8K image generation.

The model supports generating up to 2,000 characters within a single image, offering over 70 preset fonts; users can also generate up to 10 images in a series from a single prompt, and produce e-commerce detail pages and long-form web design graphics.
