Kuaishou launched Kling Image 4.0 on Tuesday night, adding native 8K image generation and the ability to produce up to 10 coordinated images from a single prompt. The model is also available through an API for developers and enterprise customers. It combines visual understanding and image generation in one architecture, targeting work such as advertising, storyboards and e-commerce design.

Kuaishou says the model can render up to 2,000 characters within a single image, with support for seven languages and more than 70 preset commercial fonts. Users can upload references to guide typography, lighting and color, or generate long images for product pages and website layouts. For multi-image projects, the model can plan the content of each image while maintaining a shared visual style. [Leiphone, in Chinese]
