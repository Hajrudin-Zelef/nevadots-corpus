microsoft/Aion-1.0-Instruct-2.3B · Hugging Face


# Model Description


Aion Instruct is the base small language model for Windows, built for on-device AI, text handling, and OS functions. The 2.3B parameter model offers enterprise-level understanding and generation right on the device, enabling fast, private, and low-cost AI use without relying on cloud connections.


A tuned version with Microsoft’s content safety model will become the default SLM in Windows OS by end of Jan 2027. This Hugging Face release is a preview to show what’s coming and gather user input. We’re releasing the unquantized version first, then adding quantized ones.


# Model Details


* **Languages:** English, German, Spanish, Portuguese, Italian, French, Chinese, Japanese

* **License:** MIT

* **Libraries:** PyTorch, ONNX, GGUF

* **Task:** Text generation

* **Features:** Summarization, rewriting, chat

* **Authors:** Applied Sciences Group @ Microsoft Windows & Devices

* **GitHub:** [microsoft/Aion-Instruct-Preview-Sample](https://github.com/microsoft/Aion-Instruct-Preview-Sample/)
