# NVIDIA and Microsoft Expand Azure Accelerated Computing and Foundry AI Capabilities

NVIDIA and Microsoft are expanding their collaboration across Azure infrastructure, Microsoft Foundry, industrial systems and Windows PCs. Announced at Microsoft Ignite, the work includes broader access to Azure virtual machines powered by NVIDIA Vera Rubin NVL72 systems, customer availability of NVIDIA open models and customization capabilities through Foundry, and additional options for running AI at the edge. Microsoft is also using NVIDIA technologies in its own services, including NVIDIA Dynamo inference software for post-training and NVIDIA RTX PRO 6000 Blackwell GPUs for Bing search models.

The collaboration addresses infrastructure performance, data protection and enterprise model customization. NVIDIA Vera Rubin NVL72 systems are running in Azure data centers for demanding reasoning, agentic applications, and large-scale training and inference. The companies are extending confidential computing to bare-metal and rack-scale AI infrastructure, with NVIDIA Confidential Computing and attestation enabling customers to verify environments before releasing sensitive models, data or keys. In MLPerf Training v6.1, Azure scaled to 10,240 NVIDIA GPUs on DeepSeek-V3; in Inference v6.1, Azure GB300 NVL72 systems led cloud submissions on DeepSeek-R1 interactive throughput by more than 10%, according to Signal65.

Microsoft Foundry’s Programmed Training lets developers control post-training workflows while Microsoft manages infrastructure, and Foundry Managed Compute supports deployment of custom model weights. EY used Programmed Training to adapt NVIDIA Nemotron open models for corporate purchasing-record classification, improving accuracy on its evaluation dataset by 55% and lowering cost 15x versus proprietary frontier models. Further availability details for the expanded capabilities were not disclosed.
