### OpenRouter Adds Scoped Access Controls to Management API Keys

OpenRouter now enables management keys to be scoped to specific workspaces and set to read-only access. These controls limit the impact of leaked or misused keys by restricting them to necessary tasks. Workspace-scoped keys cannot access other workspaces, while read-only keys prevent unauthorized changes. These settings are available today for all organizations on every plan.
