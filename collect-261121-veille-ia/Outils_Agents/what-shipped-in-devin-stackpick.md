# What shipped in Devin

Devin is Cognition's cloud software-engineering agent. You give it a task and it works on a machine of its own, then opens a result you review. It is a different job from a local CLI: longer tasks, more autonomy, and a bill to match. Pricing: check site.

Devin scores 6.9 in Coding and CLI agents. Best for: Delegating a task to a cloud agent. 5 releases, newest first.

## Releases

1. ## Devin release notes for November 16On November 16, 2026, the sidebar shows sessions you are subscribed to. Mark done replaces Archive: it moves a session to the Done folder while the session keeps running and stays in the sidebars of its other subscribers. Devin keeps a phonebook of each member's linked identities across Devin, Slack, Microsoft Teams, git providers, Jira, Linear, and Pylon, and a mention in Devin tags the person in Devin and in Slack at the same time. Typing # in a cloud session composer picks a Slack channel. The Share dialog can import contacts from Slack. Searching a session's events matches each word on its own. Security Findings can be exported to CSV. Security > Configure is renamed Customize, where security-profile plugins are managed, a profile's skills can set scan paths and include or exclude globs, a threat-model rule can be limited to chosen repositories, and skills and rules stay writable when shared uploads are off. The browser tab is named after the open finding, severity is spelled out in the finding title, and the finding sheet crossfades between findings. Enterprise Knowledge managers can read and maintain skills migrated from Knowledge. Customize > Skills lists the layers skills can be written to, and malformed plugin content says what is wrong. Tagging Devin in a Slack thread whose session is too old to resume starts a new session. !ultrafast is an alias of !fastultra in Slack and Teams. On Microsoft Teams, @user mentions are written back as native mentions, a quoted message names the mentioned person, and message headers name Slack or Teams. 2. ## Devin release notes for November 13On November 13, 2026, Deutsch can be selected as the display language in Preferences, using the terms engineers use for session, merge, push, prompt, logs, service user, and secrets. The session file editor no longer saves automatically: press Cmd/Ctrl+S to save, a dot on the tab marks unsaved files, a cloud icon in the editor header confirms each save to Devin's machine, and closing a tab or leaving a session with unsaved edits asks first. Devin is told which files you saved so it can take your edits into account. The sessions sidebar Filter menu no longer has the Machine type and Skill filters; both remain available on the Sessions page. The session title menu lists the sessions above the current session's parent. Workspace tabs no longer open on their own as Devin works. What a session produces, including pull requests, Changes, previews, the Desktop and Agents views, Plan, citations, and attachments, is listed in a compact rail to the right of the chat. Hover to see the labels, and click a row to open it. The workspace pane remembers per session whether it was open, and a session starts with it closed. Tabs that are not artifacts, such as Findings, Inbox, and Todo, stay in the add-tab menu, and a ?tab= link still opens the tab it names. The Agent / Ask switch moves from the header into a dropdown inside the composer. The same dropdown holds the modes for each side, Agent modes (Code, Data) or Ask modes (Auto, Q&A, Plan), and switching Agent/Ask flips the composer immediately with that side's default mode selected. Analytics > Review shows what became of Review's findings (fixed, rejected, ignored) for the built-in review and for each custom reviewer, and how each version of a custom reviewer's instructions performed. Devin Review can add GitLab merge requests to their project's merge train. Editing a pending inline comment on a GitLab merge request keeps it at its original location. Find in Devin Review skips collapsed files by default. Turn off Skip collapsed files in the find filter menu to search them; the choice is remembered. Review's chapter guide lists changed files in chapter order with clearer filenames and directory paths, and individual files or entire chapters can be marked viewed without leaving the guide. Selecting View as sections restores the guide's chapters even if you previously saved File tree view. Pressing m in standalone Devin Review enables auto-merge when the button offers it, and the Review keyboard shortcuts dialog no longer repeats identical key combinations. Devin Review distinguishes a newly pushed commit from an existing commit that is ready to view and from analysis updates that leave the code unchanged. When GitHub will not accept a Review comment because the file or line is no longer in the diff, Review says so instead of a generic error. When a code host is slow or not answering, Review and the session's pull request tab say the code host did not respond and keep retrying after one attempt, not three, instead of saying you have no access to the repository. You can unlink Devin from a security finding from the findings table or the finding's details, so it can be fixed again. Copy as Markdown on a finding includes the sandbox validation result and evidence, and the reason the finding was reviewed or dismissed. A board-backed sealed finding can be edited through the content tool, with the changes shown in Activity. Fix sessions are listed in their own Sessions section below Scans instead of nested under each scan or connection, with Scans showing 5 rows at a time. Org admins can turn off Devin's automatic CI follow-up under Settings > Customization > Pull requests, and reach the switch from the CI checks tile on Cost Breakdown. It stays on by default, and asking Devin directly still works. Admins can turn off the automatic session links and requester details in Devin-generated pull request descriptions from Devin Sessions settings. The setting is on by default and takes effect when sessions start or resume. Admins of non-enterprise organizations can upload or remove an organization picture in Settings > General. A plugin can offer a choice of regions for its MCP server, and Datadog uses this for its sites. That choice is shown before the first sign-in instead of defaulting to one region. The Server URL field shows the part you type as its own input and lists long query parameters one per row. When a plugin moves its server to a new URL, existing installations connect at the new URL without reconnecting. When adding an MCP server from the catalog that needs your own OAuth client, such as Google Calendar, for the whole enterprise, the form opens the OAuth credentials section, shows the setup steps, and asks for the client ID before the server can be created. 3. ## Devin release notes for November 12On November 12, 2026, when Devin asks for several things of the same kind at once, such as credentials, approvals, or network access, they appear together in one compact card. A reminder Devin sets for itself shows a Reminder set row with the time or schedule and a link to the reminder. Bare links to a file on github.com or gitlab.com appear in chat as a short pill naming the file, lines, and commit. An open session can be dragged by its pane header onto a sidebar folder, Recent, or another session. Attaching a folder no longer fails when one file cannot be read; the rest is attached and you are told what was left out. Uploads blocked by a network security policy say so and give the reason. The redesigned Devin Review page is available to all organizations: merge controls, the actions menu, and the diff-size pill live in the top bar, the sidebar collapses, and findings use the redesigned cards and panels. Whether Devin fixes Devin Review findings on pull requests from its sessions is its own setting, separate from Responding to bots. The account default is in Settings > Review, and each person can change it for their own sessions in Settings > Preferences, under Devin sessions. A Security scan can sync findings to several connections. The Source filter on the Findings page lists each connection separately. A Custom security connection asks for a display name. Hover a tag in the Findings filter and click the X to delete it from every finding. The chat button on a finding opens that finding's own chat. Dismissing a finding or marking it reviewed can be undone. Enterprise admins can stop Devin from using seven more optional GitHub permissions: code quality, deployments, pages, discussions, repository projects, repository hooks, and packages. Anyone who can write to a session can approve a request to use a personal secret they shared with a service user. Organization settings show agent modes the enterprise has disabled and say who can enable them. Signing in from outside an organization's IP allowlist explains the denial and shows the current IP. MCPs signed in with several accounts list each installation, and another installation can be added from the marketplace card. Admins can connect a Pylon workspace hosted in Pylon's EU region. Clones through Devin's git proxy work with Bitbucket Data Center /scm/ clone URLs and on instances with Basic authentication disabled. Each MCP tool can be set to Allow, Needs approval, or Block from Customize, and enterprise admins can limit individual tools to specific organizations. A Slack thread mode, Reply in the same thread, only when mentioned, is available as the organization default and as a personal override. Archiving a session also archives its dedicated Slack code channel. In Microsoft Teams, a message Devin edits is updated in place. In Slack threads with several people, Devin shows its working status when you @mention it, and after it starts acting on an untagged reply. Automation cards show a readable schedule. Oncall report notifications in Slack open with the report period and list action items as bullets, and the report's pull requests panel shows each pull request's state, repository, and date. 4. ## Devin release notes for November 11On November 11, 2026, selecting an element in Devin Design Mode opens a compact prompt bar with per-property editing. You can draw spotlight boxes or pencil annotations in five colors and send the annotated page image with a note, pick colors from the preview with the eyedropper, and search and use the page's CSS variables in property controls. Devin can set itself reminders to wake up in the future, including in sessions started by automations or service users. The keys for Option-hold sidebar session navigation can be changed in Settings › Keyboard shortcuts. The sessions list's Created by filter includes service users, and a session created by a service user shows its name in Properties. Stacked pull requests are easier to see, with a stack order preference shared with Devin Review. Adjacent repository setup suggestions can be approved together, or each diff can be reviewed and approved separately. Mark unread is available in the sidebar menu for the session that is open. Bulk add secrets accepts export KEY=value lines and keeps a # that is part of a value (put a space before # to add a note). A threat can be created from a finding's Threat menu, a finding can be removed from the threat it is linked to, and saved threats can be found by title or number when filtering findings or starting a scan. Start scan opens as its own page. Links can preselect a repository or threat, and the page includes a Focus on threats section with a searchable table. Findings use C/H/M/L letter badges instead of severity icons, and repositories show medium and low counts separately. Dismissing a finding can record a reason or note, shown in the finding detail sheet. New auto-scans show their schedule before launch and keep their local time when daylight saving time changes. When a scan fails before finding anything, the scan page, the session's Findings tab, and the per-scan history say why and offer Recover scan or Start new scan. Session security profiles gain an Ask before loading external content option. In sessions it governs, images from other sites and HTML/PDF attachment previews load only after you click them. Perforce setup guides you through server details and depot selection, reusing known details from a saved connection or importing the server address from the local Perforce configuration. Enterprise admins can edit an active plugin MCP's Access, OAuth client, and secrets in place. Oncall alerts with many occurrences can load older ones, and the events view shows whether each event was investigated, forwarded, grouped, or skipped, with a link to the session. 5. ## Claude Mythos 5.2 in Devin SecurityOn November 11, 2026, Claude Mythos 5.2 became available in Devin Security for eligible enterprise customers. Devin runs managed scans with frontier cyber models, so a security team does not need separate access to the models. Cognition is giving $100M+ in credits to enterprises to find and fix vulnerabilities with Claude Mythos 5.2, and says it is committing hundreds of millions of dollars in Devin credits, including free scans with frontier cyber models for current and future enterprise customers. Eligibility criteria and conditions apply. On Cognition's internal cyber benchmark, Mythos 5.2 scored 73.5, up from 56.9 for Mythos 5.1 and above Claude Opus 5.5's 32.7. The benchmark covers 25 repositories, including C, Python, Go, PHP, and TypeScript codebases built on Django, Flask, Laravel, and Next.js, pinned to commits where 1,781 publicly reported vulnerabilities are still present. The score is an F2 on a 0-100 scale, weighted toward recall, from the mean of three runs on every repository. Source for Claude Mythos 5.2 in Devin Security (opens in a new tab)
