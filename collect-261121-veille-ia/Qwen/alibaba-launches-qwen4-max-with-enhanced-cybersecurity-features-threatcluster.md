On November 16, 2026, Alibaba introduced Qwen4-Max, a new AI model boasting 2.4 trillion parameters and a 62% reduction in task costs compared to its predecessor, Qwen3.8-Max. The model is designed for coding and professional tasks, featuring a one-million-token context window and native vision capabilities. Alibaba claims improvements in cybersecurity by filtering training data to focus on defensive tasks, enhancing the model's ability to detect and remediate vulnerabilities. The model's performance was evaluated using Work360, which assesses tasks across 721 specialized fields. However, industry analysts caution that the cost reductions should be viewed as vendor benchmarks rather than guaranteed savings for enterprises. Alibaba's security enhancements reportedly improved the success rate of code security checks from 22% to 31.8%. The model is now available on QwenCloud, with a focus on reducing manual programming time in various applications.
