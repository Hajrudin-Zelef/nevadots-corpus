Welcome to Flight Hub! Use this dashboard to quickly identify the latest Windows Insider Preview Builds.

Latest ISO downloads can be found for each channel at Windows Insider Preview Downloads.

Preview builds for Windows 11 in the Experimental (Future Platforms) channel. These experimental builds are not aligned to any retail release of Windows.

## Windows 11, version 26H2

Preview builds for Windows 11, version 26H2 (Build 26300). For more information on this year's annual feature update for Windows 11 - see this blog post.

Important

*These builds are delivered on top of Windows 11, version 25H2 (Build 26200) with an enablement package that increments the build number to Build 26340 for the Experimental channel and Build 26320 for the Beta channel.

 
## Windows 11, version 26H1

Preview builds for Windows 11, version 26H1 (Build 28000). 26H1 is not a feature update for version 25H2 and only includes platform changes to support specific silicon. There is no action required from customers. See this blog post for more details.

Important

*These builds are delivered on top of Windows 11, version 26H1 (Build 28000) with an enablement package that increments the build number to Build 28020 for the Beta (26H1) channel and 28120 for the Experimental (26H1) channel.

 
## Windows 11, version 25H2

Preview builds for Windows 11, version 25H2 (Build 26200). For more information on this year's annual feature update for Windows 11 - see this blog post.

Important

*These builds are delivered on top of Windows 11, version 25H2 (Build 26200) with an enablement package that increments the build number to Build 26300 for the Experimental channel and Build 26220 for the Beta channel.

 
## Windows 11, version 24H2

Preview builds for Windows 11, version 24H2 (Build 26100).

Important

*These builds are delivered on top of Windows 11, version 24H2 (Build 26100) with an enablement package that increments the build number to Build 26120 for the Beta Channel.

 
Older Windows Insider Preview Builds are archived. Visit the archive to see information on Windows 11, version 23H2 (Build 22631) and earlier.
