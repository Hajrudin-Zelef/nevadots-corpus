Microsoft released the November preview updates for Windows 11 versions 26H2, 26H1, and 25H2 today. This is happening a week earlier than usual, probably because of the Thanksgiving holiday break. There will also be no December 2026 preview updates in the second part of the month, as the Windows team will be on minimal operations during the holidays.

The optional KB5132057 update for Windows 11 versions 26H2 and 25H2 was made available for Insiders on the Release Preview Channel last week. It includes the following new features, which will be rolling out gradually to users who install the update:

**New Windows Search experience with inline actions**: It’s now possible to complete common tasks such as changing Windows settings right from the Windows Search window. The new experience also displays richer results with file previews.

**File Explorer improvements**: Searching from ‘This PC’ is now indexer-based, and the experience now matches the speed of searching from File Explorer Home.

**Windows Hello improvements**: A new option in Facial recognition settings can temporarily brighten the screen to help users in dark environments to sign in.

**Xbox mode improvements**: Quick settings are now available from the Gaming Task View navigation bar.

**Live captions improvements**: New options in Live captions settings let users choose to caption system audio, microphone audio, or both.

**Screen capture**: This update changes the border displayed during screen capture from yellow to a more visible red color.

**Pointer indicator**: This new accessibility feature makes it easier for people with low vision to locate and use the mouse pointer.

**Widget notifications**: Windows 11 will now show a notification when a new widget becomes available after installing an app.

For ARM-based PCs running Windows 11 version 26H1, the optional KB5132265 update is available today. It includes the updated context menu in File Explorer, the Cloud Rebuild recovery option, and other new features from the November Patch Tuesday update for Windows 11 versions 26H2 and 25H2.
