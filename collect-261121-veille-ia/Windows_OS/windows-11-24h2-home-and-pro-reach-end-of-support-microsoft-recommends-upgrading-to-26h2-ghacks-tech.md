Microsoft has confirmed that Windows 11 version 24H2 Home and Pro reached the end of updates on October 13, 2026, according to a new entry in the Windows release health message center. The October 2026 monthly security update is the last update these editions will receive.

The same notice covers Windows 10 Enterprise LTSB 2016, which also reached end of updates on October 13. Devices that stay on these editions no longer get monthly security updates or the optional non-security preview updates, so they lose protection against the latest security threats from November onward.

Business editions follow a different schedule. Under the Microsoft lifecycle policy, Windows 11 24H2 Enterprise and Education stay in mainstream support until October 12, 2027.

## Windows 11 26H2 Is the Recommended Upgrade Path

Microsoft advises affected users to move to Windows 11 26H2, also known as the Windows 11 2026 Update. Version 26H2 became generally available in September 2026 as an enablement package, and consumer editions of 26H2 are supported until October 2029.

The rollout is phased. Microsoft says it is currently offered to eligible devices where the "Get the latest updates as soon as they're available" option is turned on, and that availability "will expand over the next few months." When the update is ready for a device, it downloads and installs automatically, and a single restart completes the process.

Home and Pro users still on 24H2 can check their version and request the upgrade manually:

1. Open Settings and go to System, then About, and check the Version entry under Windows specifications.
2. If it shows 24H2, open Settings, then Windows Update.
3. Turn on "Get the latest updates as soon as they're available."
4. Select Check for updates and install the Windows 11, version 26H2 feature update if it is listed.
5. Restart the PC when prompted.

Users who do not see the offer yet should leave the toggle on. The phased rollout means some eligible devices will only receive 26H2 later, at which point it installs automatically.

## Other Windows End of Support Dates

The 24H2 deadline is not the only Windows cutoff coming up. Microsoft has already set November 10 as the final security update for Windows 11 23H2 Enterprise and Education, along with IoT Enterprise. Windows 11 23H2 Home and Pro lost support in November 2025.

Windows Server 2022 also left mainstream support on October 13, although it remains in extended support until October 2031. Earlier this year, Microsoft extended the free Windows 10 Extended Security Updates program for home users to October 2027.

Microsoft has separately warned that PCs running unsupported Windows versions will stop receiving security updates after next year's Windows Update certificate rotation.

Microsoft has not said how long the phased 26H2 rollout will take to reach all eligible Windows 11 24H2 Home and Pro devices.
