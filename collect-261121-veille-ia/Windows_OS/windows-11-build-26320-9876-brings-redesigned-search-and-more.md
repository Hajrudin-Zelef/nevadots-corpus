**Windows 11 build 26320.9876** is now rolling out to the Beta channel for the **Windows Insider Program**, moving 25H2 testers to version 26H2 through an enablement package (eKB). The update introduces a redesigned Windows Search experience built on WinUI 3.

The update also improves accessibility and gaming features. Live Captions now lets users choose whether to transcribe system audio, microphone input, or both. In addition, XBOX mode now offers full Quick Settings access directly from the Gaming Task View navigation bar.

Other changes include expanded passwordless web sign-in support for Microsoft Entra hybrid-joined devices, automatic screen brightness adjustments during Windows Hello facial recognition in dim environments, and updated Sticky Keys and Filter Keys prompts that make it easier to permanently dismiss unwanted notifications.

The company is also bringing Microsoft 365 Family shared cloud storage information to the Settings app, allowing subscribers to view their family’s combined storage usage. In addition, File Explorer now supports the `~` character in the address bar.

## What’s new on Windows 11 build 26320.9876 (Beta)

These are the new features and improvements rolling out in the Beta channel:

### Windows Search gets a redesign with inline actions

Microsoft is beginning to roll out a redesigned Windows Search experience built on WinUI 3 to this channel, promising faster performance, greater efficiency, and a cleaner interface that makes results easier to scan.

The biggest addition is inline actions, which let you perform tasks directly from Search without opening the Settings app. You can enable dark mode or Bluetooth, adjust screen brightness, mute your device, and arrange windows.

Search is also getting better at understanding queries, including recognizing typos and matching synonyms. The initial rollout supports English only.

### Settings adds shared Microsoft 365 cloud storage details

This update also brings shared storage information for Microsoft 365 Family subscriptions to the Settings app. The new view lets subscribers check their family’s combined cloud storage usage under **Settings** > **Accounts** > **Cloud storage**, with a breakdown for individual family members planned for a future update.

Availability depends on when you purchased your subscription. If you subscribed after October 8, 2026, you can access the new view now. Those who purchased their subscription before that date will get access after their first subscription renewal on or after May 2, 2027.

### XBOX mode adds Quick Settings access

Gaming in XBOX mode is becoming more convenient as Microsoft brings Quick Settings to the Gaming Task View navigation bar.

This addition gives you access to the full set of Quick Settings controls available from the Taskbar without leaving the gaming interface, making it easier to adjust system settings while staying in your game.

### Windows Hello improves facial recognition in low light

Signing in with Windows Hello should become easier in dim environments. Microsoft is adding an option that temporarily increases screen brightness during facial recognition, helping the camera recognize your face when lighting conditions aren’t ideal.

To enable it, open **Settings** > **Accounts** > **Sign-in options** > **Facial recognition (Windows Hello)** and turn on **“Automatically adjust screen brightness during face recognition.”**

### Live Captions gains audio source controls

The Windows team is making Live Captions more flexible by letting users choose exactly what audio gets transcribed.

Previously, the feature captured system audio and let you include microphone input. Starting with this update, you can select system audio, your microphone, or both independently. This makes it easier to caption an in-person conversation without capturing PC audio or to follow what’s playing on your computer during a meeting or video.

### Web sign-in expands passwordless support

Microsoft is expanding Windows web sign-in to Microsoft Entra hybrid joined devices, extending a feature previously limited to Microsoft Entra joined devices.

Users can now sign in directly from the lock screen without a password by using a FIDO2 security key, a passkey stored on their phone, or a Temporary Access Pass (TAP).

After authentication, Windows obtains a Kerberos ticket, allowing users to continue accessing on-premises file shares and internal websites without losing access to organizational resources.

### Sticky Keys and Filter Keys prompts become less intrusive

The company is updating the Sticky Keys and Filter Keys dialogs to make them less disruptive.

If you don’t use these accessibility features, you can now choose directly from the prompt not to be asked again, helping prevent unwanted interruptions while typing or working.

## Download Windows 11 update 26320.9876

To download and install these Windows 11 builds, enroll your Devices in the **Beta** channel through the “Windows Insider Program” settings from the “Update & Security” section. Once you enroll the computer in the program, you can download the build from the “Windows Update” settings by turning on the **“Get the latest updates as soon as they’re available”** option and clicking the **“Check for Updates”** button.

Alternatively, you can also download the ISO files from the **Windows Insider Preview Downloads** page. Specific preview builds are available for a limited time only.
