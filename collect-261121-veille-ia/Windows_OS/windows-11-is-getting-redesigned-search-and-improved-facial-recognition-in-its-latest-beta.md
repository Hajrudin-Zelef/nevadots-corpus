Microsoft has spent much of 2026 fixing some of the annoying things that have plagued Windows 11 for years. There is now a customizable right-click menu, recovering a broken Windows installation no longer requires a USB drive, and the company is even making Windows run better on PCs with just 8GB of RAM. Plenty of much-needed improvements, considering how long users have been dealing with these problems.

Microsoft has another batch of changes lined up. The latest Windows 11 Insider Beta Build 26320.9876, released November 6, brings improvements to Search, Windows Hello, and a few other features. The Beta channel also moves to Windows 11 version 26H2. But Microsoft says the version change alone doesn’t bring anything significant.

## Windows Search has more to offer

Microsoft has already been experimenting with Windows Search, trying to make it useful beyond finding files and apps. The latest build introduces a redesigned interface using WinUI 3, which apparently offers faster results and better navigation.

There are a whole bunch of things users can do directly from Search. Turning on Bluetooth, switching to dark mode, adjusting screen brightness, muting audio, and even arranging open windows. Some of these capabilities were already being tested.

Search is also getting better at understanding typos and synonyms. A fairly useful addition, given how Windows sometimes struggles to find something unless you know exactly what to type. Unfortunately, English is the only supported language for now.

## Some more fixes around Windows 11

Windows Hello can now temporarily brighten the screen during facial recognition. Quite handy when trying to unlock a laptop in a dark room. Live captions can now capture microphone audio, system sounds, or both. Microsoft is also bringing Quick settings to Xbox mode, allowing gamers to access system controls without leaving the interface.

Unfortunately, there’s no word on when these Insider features will reach regular Windows 11 users.
