Microsoft’s release notes show a rebuilt Windows 11 Search reaching Beta testers in build 26320.9876 on 6 November. It can turn on dark mode or Bluetooth straight from the results.

Instead of digging through Settings, testers can adjust screen brightness, mute the device, or arrange windows from the same place they search for files and apps.

Microsoft built the new search on WinUI 3.

It’s faster, more efficient, and features a streamlined design that makes results easier to scan.

Microsoft, Windows Insider release notes

Matching should also improve. Microsoft says Search now handles typos and synonyms better, and it will keep fine-tuning results over the coming weeks. English is the only supported language for this initial release, and the rollout is gradual, so not every Beta PC will get the new design straight away. Experimental builds 26340.9843 and 28120.3393 added filters and Phone Link actions on 30 October; these Beta notes don’t list them.

The same build also brings a Windows Hello setting for dark rooms. Face sign-in can temporarily brighten the screen to help you sign in, under Settings > Accounts > Sign-in options > Facial recognition (Windows Hello). Microsoft doesn’t describe any change to the recognition itself.

Other additions are smaller:

- Live captions can use system audio, the microphone, or both.
- XBOX mode gets the full set of taskbar Quick settings in the Gaming Task View bar.
- Web sign-in now works on Microsoft Entra hybrid-joined devices.
- Microsoft 365 Family shared cloud storage shows up in Settings.
- File Explorer’s address bar accepts ~ shortcuts, such as ~\AppData.
- Beta moves to Windows 11 version 26H2 through an enablement package, which Microsoft says shouldn’t bring significant changes on its own.

The rebuild follows Microsoft’s local-first Search overhaul in July, which ranked files and apps above web suggestions. Digital Trends notes that Microsoft spent much of 2026 fixing long-standing Windows 11 annoyances, and the rebuilt Photos app reached Insiders in October.

Digital Trends reports there’s no word on when the new Search will reach regular Windows 11 users, and Microsoft’s notes warn that Insider features might never ship beyond testers.
